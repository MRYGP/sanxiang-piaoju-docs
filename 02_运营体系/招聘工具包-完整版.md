## 第一部分：招聘总览

### 招聘流程

```
发布职位 → 筛选简历 → 约面试 → 面试评分 → 发offer → 入职培训
```

### 招聘原则

1. **快速筛选**：简历筛选重点看关键指标，不纠结细节
2. **标准化面试**：使用统一的面试评分表，确保公平公正
3. **快速决策**：90分以上当天发offer，75-89分1-2天内决定
4. **话术统一**：使用标准话术模板，确保专业和一致性

### 招聘渠道

- **运营专员**：
  - BOSS直聘
  - 拉勾网
  - 猎聘网
  - 朋友圈转发

- **实习生**：
  - BOSS直聘
  - 实习僧
  - 牛客网
  - 知乎/小红书/B站
  - 长沙高校AI社团/创业社团
  - 学生推荐学生

## 第四部分：通用招聘技巧和注意事项

### 4.1 面试前准备

**运营专员**：
1. 打印面试评分表
2. 准备企业微信（让候选人现场演示）
3. 准备公司介绍PPT或文档
4. 准备2-3个业务案例（用于测试理解能力）

**实习生**：
1. 打印面试评分表
2. 准备好手机或电脑（让候选人演示AI工具）
3. 准备1-2个实际场景（测试候选人能否用AI解决）
4. 准备公司介绍和岗位说明

---

### 4.2 面试流程建议

**运营专员**（总时长：约1小时）：
1. 自我介绍（5分钟）
2. 公司和岗位介绍（5分钟）
3. 核心能力提问（30分钟）
4. 候选人提问（10分钟）
5. 填写评分表（5分钟）

**实习生**（总时长：约45分钟）：
1. 自我介绍（5分钟）
2. 公司和岗位介绍（5分钟）
3. AI工具能力测试（15分钟）
   - 现场演示prompt
   - 讨论学习方法

   - 讲解一个AI概念
   - 说明教学思路
5. 候选人提问（5分钟）
6. 填写评分表（5分钟）

### 4.4 面试后处理

**运营专员**：
1. 当天完成评分
2. 90分以上：当天或次日发offer
3. 75-89分：1-2天内决定
4. 60-74分：再面试一次或不录用
5. 60分以下：礼貌拒绝

**实习生**：
1. 当天完成评分
2. 90分以上：当天发offer，给4000元
3. 75-89分：次日发offer，给3500元
4. 60-74分：试用1周，给3000元
5. 60分以下：礼貌拒绝

### 4.5 注意事项

1. **保持专业**：面试过程中保持专业和礼貌，给候选人良好印象
2. **快速决策**：不要拖太久，优秀候选人会被其他公司抢走
3. **统一标准**：使用统一的评分表，确保公平公正
4. **记录详细**：详细记录候选人的回答和表现，便于后续对比
5. **及时反馈**：无论是否录用，都要及时给候选人反馈
