# 岗位说明 - 业务运营与客户成功中枢

> 面向对象：业务运营 / 客户成功岗位候选人 & 全体核心成员  
> 版本：v1.0（后续根据实战不断迭代）

---

## 一、我们在做什么？（整体棋盘）

一句话：

> **三湘票据 = 做企业"资金与票据"的中介平台，用专业方案帮企业省钱、省时间、少踩坑。**

整体结构是一个"**前端获客平台 + 中台方案设计 + 多后端合作方**"的轻资产模式：

* **前端（网络运营 + 兼职网络）**

  * 通过官网、短视频、朋友圈、社群等，吸引：

    * 兼职业务员
    * 有需求的企业老板
    * 潜在后端服务商

* **中台（三湘总部）**

  * 统一接单、识别需求
  * 设计 A/B/C/E/F 等业务方案
  * 做风险把关、客户管理、对账结算

* **后端（合作伙伴）**

  * 冷部：票据 / 远期支票 / 电子债权凭证收出
  * 姜部 / 陈部：债券投资 / 债券配置顾问（E 业务）
  * 资金方：摆账 / 亮资（F 业务）
  * 其他合作方：冲存款、专利实缴、带量等

你的位置在"中台"的心脏地带：

> **负责把：线索 → 机会 → 订单 → 回款 → 长期关系  
> 这条链路盯住，不漏、不乱、不断。**

---

## 二、岗位定位：业务运营 / 客户成功中枢

一句话定位你：

> **你是整个项目的"订单管家 + 客户成功负责人"。**  
> 负责线索流转、订单推进、后端协同、客户体验和经验沉淀。

和其他核心岗位的关系：

* **网络运营负责人**：

  * 把"人和机会"搞进来（流量、兼职、企业线索）
* **AI 赋能与知识工程**：

  * 把"工具和知识"搞好（AI 助手、自动化、知识库）
* **你（业务运营 & 客户成功）**：

  * 把"每一单事情"从头到尾给盯完（不烂尾、不飞单、不乱套）

## 三、核心职责

### 1. 线索流转与机会管理（线索 → 机会 → 项目）

* 接收来自以下渠道的线索：

  * 兼职业务员报备
  * 网络运营获取的企业线索
  * 松阳/合作方的直接介绍
* 对线索进行初步整理和分级：

  * 明确：是哪类业务（A/B/C/E/F…）
  * 明确：当前状态（仅咨询 / 有需求 / 紧急 / 已对接后端）
* 维护一套**统一的线索 & 项目看板**：

  * 状态字段示例：

    * 新线索 / 已联系 / 需求确认中 / 已转后端 / 报价中 / 跟进中 / 成交 / 暂缓 / 放弃
  * 每周汇总给松阳：

    * 本周新增多少线索
    * 当前在跑的重点项目有哪些
    * 有哪些机会值得你亲自下场

### 2. 订单推进与节点跟进（机会 → 成交 → 回款）

* 对于明确进入"方案/报价/执行"的项目：

  * 明确每个项目的：

    * 对接人（企业那边）
    * 对接后端（冷部 / 姜部 / 资金方等）
    * 当前节点（资料齐不齐、方案到了没、企业反馈如何）
* 主动推进关键节点：

  * 催资料 / 催反馈 / 催确认
  * 提醒时间点（比如投标时间、授信评审时间等）
* 跟进回款和费用结算进度：

  * 与财务/合作方核对：

    * 这单的钱什么时候到？
    * 应收/已收是多少？
  * 收集和记录"本单实际收益"，为后续复盘提供数据

### 3. 后端协同与问题处理

* 与各类后端服务商建立稳定协作关系：

  * 冷部、姜部、陈部、资金方等
* 保障"信息不丢、节奏不停"：

  * 在资料、需求、方案三方之间做翻译和校对
  * 避免：企业说一套，后端理解一套
* 第一时间发现问题并反馈给松阳：

  * 后端响应慢？
  * 某类业务经常卡在某个环节？
  * 某些客户类型总是出问题？

### 4. 客户成功与体验管理

* 关心的不只是"成没成这单"，更是：

  * 客户是否愿意再合作？
  * 客户是否愿意介绍新客户？
* 做简单的客户分级：

  * 一次性客户 / 有潜力的长期客户 / 重点维护客户
* 收集客户真实反馈：

  * 对价格、效率、沟通、风险提示的感受
  * 哪些地方可以改进
* 把正向案例/好评整理出来，供运营做素材，供知识工程写进知识库。

### 5. 数据与 SOP 沉淀（和 AI & 运营一起）

* 从实际项目中抽象出：

  * 哪些客户画像转化率高？
  * 哪些话术常被问？
  * 哪些坑反复踩？
* 和 AI 赋能同学合作：

  * 把这些经验写成 SOP / FAQ / 模板表单
  * 供新业务员 / 新兼职 / 新同事学习使用
* 和网络运营合作：

  * 把好的案例包装成：

    * 对外的故事（文章、短视频、话术）
    * 对内的培训素材（培训 PPT、一页纸说明）

## 四、第一阶段（0–3 个月）：打底 + 建立秩序感

**目标：**  
从"散点线索"进入"有看板、有节奏的运营状态"。

重点做三件事：

1. **梳理现有线索 & 项目**

   * 把目前在谈的 A/B/C/E/F 等业务线索，全部整理进一个统一表或看板
   * 补齐缺失信息：客户是谁、是谁报的、当前进度、下一步是谁负责

2. **跑通 2–3 个典型项目的"端到端闭环"**

   * 从线索进来 → 方案讨论 → 对接后端 → 成交/不成 → 记录原因
   * 至少掌握：1 个 A/B 项，1 个 E/F 项

3. **输出第一版《业务运营周报》**

   * 每周固定一次，向松阳汇报：

     * 本周新增线索 / 在跑项目 / 成交项目 / 放弃原因
     * 问题清单：前端、后端、内部协同
     * 下周建议重点跟进的项目/方向

---

## 五、第二阶段（3–12 个月）：标准化 + 可复制

**目标：**  
从"你盯得住"变成"系统跑得动，别人也能接手"。

重点方向：

1. **标准化线索 & 项目管理流程**

   * 固化一套：

     * 线索录入标准
     * 线索分级标准
     * 项目状态标签
   * 让兼职和运营都知道：

     * "怎么报线索、报了去哪儿了、最后结果是什么"

2. **搭建简单培训与协作机制**

   * 面向兼职 / 新业务员：

     * 做一份《如何报备线索》《线索报备后会发生什么》
   * 面向后端合作方：

     * 整理一份《与三湘合作需要准备的东西》《常见问题和回答》

3. **协助松阳识别"值得放大的业务 & 客户类型"**

   * 哪些项目最赚钱、最稳、最易复制？
   * 哪些项目费劲不讨好，应当收缩？

## 六、工作原则

1. **对结果负责，不对情绪负责**

   * 别人着急、催、抱怨是常态，
   * 关键是：信息别乱、事别掉地上。

2. **凡事留痕迹，避免口头主义**

   * 重要节点尽量有：表格记录 / 简短纪要 / 关键截图
   * 避免事后没人说得清楚发生了什么。

3. **能清晰说"不"，也能清晰说"为什么"**

   * 对明显不合适的客户或项目，要敢于建议放弃；
   * 同时解释逻辑：风险在哪里、机会成本在哪里。

4. **和 AI & 外包合作，而不是"一个人硬扛"**

   * 整理资料、催进度、做记录，早晚要部分交给 AI / 自动化 / 外包；
   * 你的价值在于：**看全局、做判断、定优先级。**

## 七、成长路径与合伙人预期

这个岗位非常适合成长为：

> **项目总负责人 / 业务线总负责人**

长期预期：

* 当你能：

  * 看懂每条业务线的收益与风险；
  * 协调前端、后端、AI、运营各条线；
  * 在关键项目上独立决策、带团队跑完；
* 那下一步，就不仅仅是"高级员工"，  
  而是会向"项目总负责人 + 股东待遇"的方向演进。

这是期望，不是今天就签字的承诺，  
但会真实影响我们未来的用人和分配逻辑。
