## 1. 开场话术

### 1.1 一句话版（10秒）

**适用场景**：微信/电话首次接触

**话术模板**：

```
【版本A - 价值导向】
"我们有个免费的贷款体检器，3分钟就能知道你的企业能贷多少钱、成本多少，要不要试试？"

【版本B - 痛点导向】
"很多老板不知道自己企业能贷多少钱，我们有个免费体检工具，帮你3分钟诊断一下，要不要看看？"

【版本C - 对比导向】
"别人家贷款要跑一个月才知道能不能批，我们有个工具3分钟就能出结果，要不要试试？"
```

**使用建议**：
- 首次接触用版本A（温和、价值明确）
- 客户提到"缺钱"用版本B（痛点共鸣）
- 客户提到"之前贷过"用版本C（对比优势）

- ✅ 解释逻辑（为什么做这个工具）

## 3. 引导使用话术

### 3.1 发送链接前的话术

**话术模板**：

```
"好的，我把体检器链接发给你。

**使用流程很简单：**
1. 点开链接
2. 填几个基本信息（大概2-3分钟）
3. 系统自动生成体检报告
4. 我把报告发给你，我们再看下一步

**需要准备的信息：**
- 公司注册时间
- 年营收规模（大概范围就行）
- 有没有抵押物（房产、设备等）
- 行业类型
- 现有贷款情况（有/没有，大概多少）

准备好了吗？我把链接发给你。"
```

---

### 3.2 客户填写中的跟进话术

**话术模板**：

```
"填得怎么样了？有什么问题随时问我。

**常见问题：**
- 年营收不知道准确数字？→ 填大概范围就行，比如500-1000万
- 抵押物不确定？→ 有就填有，没有就填没有，不确定的可以填"不确定"
- 行业类型找不到？→ 选最接近的就行

**关键提醒：**
- 信息尽量真实，这样体检结果才准确
- 不确定的可以填"不确定"，系统会按保守方案匹配
- 填完提交就行，3分钟出结果"
```

## 4. 体检后跟进话术

### 4.1 发送报告时的话术

**话术模板**：

```
"体检报告出来了，我发给你看看。

**报告包含：**
- 你的企业能贷多少钱（额度范围）
- 大概成本是多少（年化利率范围）
- 哪些地方需要优化（比如流水不够、缺少抵押物等）
- 推荐哪些业务能帮你改善

**简单解读：**
- 如果你的企业能贷XXX万，成本在XX%-XX%之间
- 如果你的企业暂时贷不了，原因是XXX，我们可以通过XXX业务帮你改善

**下一步：**
- 如果你觉得方案合适，我们可以深入聊一下具体怎么操作
- 如果你觉得还需要优化，我们可以看看哪些业务能帮你改善

你先看看报告，有什么问题随时问我。"
```

---

### 4.2 从体检结果到业务推荐的衔接话术

**话术模板**：

```
"看了体检报告，我简单说一下：

**你的情况：**
- 能贷XXX万，成本在XX%-XX%之间
- 需要优化的地方：XXX

**我们能帮你做什么：**
- 如果流水不够 → H业务能帮你养流水（6万养到300-400万贷款）
- 如果缺少抵押物 → A/B业务能帮你用票据/凭证做融资
- 如果成本太高 → D业务能帮你做贸易套利，降低资金成本
- 如果资质不够 → 我们可以帮你优化资质，再申请贷款

**具体方案：**
- 如果你想快速拿到资金 → 推荐A/B业务（票据/凭证，3-5天到账）
- 如果你想优化成本 → 推荐D业务（贸易套利，收益率15-25%）
- 如果你想长期改善 → 推荐H业务（养流水，6万→300-400万贷款）

你想先从哪个开始？"
```

## 📝 使用建议

### 话术选择原则

1. **首次接触**：用一句话版，降低压力
2. **深度沟通**：用30秒版或3分钟版，建立信任
3. **需求明确**：直接引导使用，不要过度铺垫
4. **需求不明确**：先用需求识别话术，再引导使用

### 关键成功要素

1. ✅ **强调免费**：消除客户顾虑
2. ✅ **强调快速**：降低时间成本
3. ✅ **强调不强制**：降低压力
4. ✅ **强调价值**：说明能得到什么
5. ✅ **强调专业**：建立信任

### 常见错误避免

1. ❌ 不要过度推销，让客户有压力
2. ❌ 不要夸大效果，保持真实
3. ❌ 不要强制客户，尊重客户选择
4. ❌ 不要信息过载，保持简洁
