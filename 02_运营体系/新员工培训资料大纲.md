### 模块2：8个业务详解

#### 2.1 A业务：票据/凭证贴现

**业务逻辑**：企业有票，我们收票变现

**客户痛点**：等到期太慢，急需现金

**我们的价值**：快速变现（10分钟-2小时）

**收益**：票据买卖差价（年化3-8%）

**风险点**：票据真伪、到期兑付

**话术要点**：快速、安全、各种票都收

**实操练习**：角色扮演，客户问"多久到账""安全吗"，如何回答？

------

#### 2.2 B业务：承兑/凭证销售（企业付款）

**业务逻辑**：企业要付钱，我们卖票给他

**客户痛点**：付现金成本高（贷款5%）

**我们的价值**：省钱（0.4-8%）+延期付款

**收益**：票据买卖差价

**风险点**：供应商不收票、票据流转

**话术要点**：省钱、灵活、可分拆

**实操练习**：客户说"我们供应商不收票"，如何回答？

------

#### 2.3 G业务：专利实缴

**业务逻辑**：用专利作为无形资产完成实缴

**客户痛点**：注册资本没实缴，影响招投标和融资

**我们的价值**：快速完成实缴，避免后续压力

**收益**：服务费（1-3%）

**风险点**：合规性、专利质量

**话术要点**：合规、快速、避免风险

**实操练习**：客户问"这个合法吗"，如何回答？

------

#### 2.4 H业务：贸易带量（做大规模）

**业务逻辑**：通过真实贸易做大账面

**客户痛点**：账面规模小，影响融资

**我们的价值**：快速做大规模，提升融资能力

**收益**：服务费

**风险点**：贸易真实性、税务问题

**话术要点**：真实贸易、合规、快速见效

**实操练习**：客户问"会不会有税务问题"，如何回答？

------

#### 2.5 C/D/E/F业务（简要了解）

- C业务：冲存款（帮银行冲存款，我们拿返点）
- D业务：套利指导（教企业用票据套利）
- E业务：债券投资（帮企业投资债券）
- F业务：摆账/亮资（招投标、融资展示）

这4个业务暂时不是重点，了解即可，客户问起能简单介绍。

### 模块3：客户需求识别

#### 3.1 如何判断客户需要哪个业务？

- 手里有票/凭证 → A业务
- 要付货款 → B业务
- 注册资本没实缴 → G业务
- 账面规模小 → H业务
- 有套利需求 → D业务

#### 3.2 如何挖掘客户多重需求？

- 做A业务的客户，问"你们平时付款用什么方式？" → 可能需要B业务
- 做B业务的客户，问"你们注册资本实缴了吗？" → 可能需要G业务
- 做A/B业务的客户，问"你们账面规模多大？融资顺利吗？" → 可能需要H业务

**实操练习**：拿一个客户案例，练习挖掘多重需求

### 模块8：合规和风险

#### 8.1 话术禁用词

- 不能说"10分钟到账""秒到""实时到账"
- 不能说"保证年化X%""固定省X%""确保收益"
- 不能说"100%安全""零风险""绝对合规"
- 不能说"私卡""内部秘密""线下结算"

#### 8.2 合规话术

- 时效："通常10分钟-2小时，以票种/额度/通道为准"
- 收益："示例：半年期银承约省0.2%-0.8%，具体以成交时为准"
- 安全："基于银行承兑/合同化机制，合规边界内可控"

#### 8.3 风险识别

- 什么样的客户要小心（过度承诺、要求违规操作）
- 什么样的订单要小心（金额异常大、要求异常快）
- 遇到问题找谁（先找老板，不要自己做主）

**实操练习**：识别风险案例

## 四、合伙人运营培训（核心，第4-5天）

> **核心定位说明**：
> - 你的核心工作对象是：**兼职合伙人**（会计/代账/企业服务中介）
> - 你的工作目标：**让合伙人持续带来企业客户**
> - 你不是：**传统电销，天天打电话拉终端客户**
> 
> **合伙人vs传统业务员**：
> - 合伙人：有企业资源，我们赋能他们
> - 传统业务员：从0开始拉客户
> 
> **我们的模式**：
> 内容+工具→赋能合伙人→合伙人带来客户→公司成交→合伙人分成

### 模块9：如何招募合伙人（业务员）

#### 9.1 招募渠道

- 朋友圈转发
- 社群发布
- 同行推荐
- 短视频引流

#### 9.2 招募文案

- 标题怎么写（吸引人）
- 内容怎么写（说清楚）
- 利益点怎么说（高收入、灵活时间）

#### 9.3 筛选标准

- **A类合伙人（重点发展）**：有稳定的企业客户资源（会计/代账/企业服务中介），客户数量5个以上，执行力强
- **B类合伙人（培养对象）**：有少量企业资源或渠道，愿意学习和执行
- **C类合伙人（观察对象）**：暂无资源，但执行力强，愿意发内容、建立影响力
- **不适合的人**：纯小白、不靠谱、只想躺赚、无执行力

------

### 模块10：如何培训合伙人（业务员）

#### 10.1 培训内容

- 业务基础（简化版，30分钟）
- 工具使用（企业微信、话术库、素材库）
- 防飞单规则（必须用企业微信、必须用公司素材）

#### 10.2 培训方式

- 线上培训（录制视频，发给业务员看）
- 文档培训（给业务员文档自学）
- 一对一答疑（微信/电话）

#### 10.3 考核标准

- 30天内必须出单（否则淘汰）
- 必须用企业微信（否则没提成）
- 必须用公司素材（否则没提成）

#### 10.4 合伙人分层管理

- **A类合伙人（重点维护）**：每周至少沟通1次，优先提供新业务信息，优先提供优质素材
- **B类合伙人（正常维护）**：每2周沟通1次，定期发送培训材料，群内统一答疑
- **C类合伙人（观察期）**：每月沟通1次，群内统一培训，3个月后评估

**淘汰标准**：
- 3个月内无任何动作
- 违反公司规则（如私自飞单）
- 不配合培训和指导

### 模块11：合伙人运营核心技能（核心）

> **这是运营专员的核心能力模块，必须重点掌握！**

#### 11.1 理解合伙人商业模式

**为什么要做合伙人网络？**
- 轻资产扩张：不需要自己养大量销售团队
- 快速覆盖：合伙人自带客户资源，快速触达
- 成本可控：按结果付费（分成），不养闲人

**合伙人和传统业务员的区别？**
- 合伙人：有企业资源，我们赋能他们（内容+工具+培训）
- 传统业务员：从0开始拉客户，需要大量培训

**我们的竞争优势是什么？**
- 8个业务（一站式解决企业多种需求）
- 内容支持（朋友圈文案、话术、素材）
- AI工具赋能（降低合伙人学习成本）
- 专业后端（公司负责成交和交付）

**实操练习**：用一句话向合伙人解释"为什么要加入我们？"

------

#### 11.2 识别优质合伙人

**A类合伙人（重点发展）**：
- 身份：会计/代账/企业服务中介
- 资源：有稳定的企业客户资源（5个以上）
- 特点：执行力强，按SOP执行
- 标准：每月至少报备2条有效线索

**B类合伙人（培养对象）**：
- 身份：有少量企业资源或渠道的人
- 特点：愿意学习和执行
- 标准：每月至少报备1条有效线索

**C类合伙人（观察对象）**：
- 身份：暂无资源，但执行力强的人
- 特点：愿意发内容、建立影响力
- 标准：3个月内转化为B类

**如何在微信聊天中快速识别？**
- 问："您平时主要服务哪些企业？"
- 问："您手上有多少企业客户？"
- 问："您之前做过类似业务吗？"
- 观察：朋友圈是否经常发企业相关内容

**实操练习**：角色扮演，模拟识别3种不同类型的合伙人

#### 11.3 合伙人激活技能

**如何让合伙人愿意发第一条朋友圈？**
- 提供现成的朋友圈文案（降低门槛）
- 告诉他"发圈就能带来咨询"（明确价值）
- 给他看成功案例（建立信心）
- 承诺"有问题随时找我"（降低顾虑）

**如何让合伙人愿意问第一个客户？**
- 提供标准话术（降低沟通难度）
- 告诉他"问一下不损失什么"（降低心理负担）
- 承诺"有咨询我帮你对接"（降低后顾之忧）
- 给他看其他合伙人的成功案例（建立信心）

**如何让合伙人愿意持续干？**
- 及时反馈：有咨询立即对接，有成交立即分成
- 持续赋能：定期提供新内容、新话术、新业务
- 建立社群：让合伙人看到"别人在动"，产生压力
- 定期激励：月度总结、优秀合伙人表彰

**案例：成功激活的3个典型场景**

**场景1：会计合伙人**
```
背景：某会计有10个企业客户，但从未做过票据业务
激活步骤：
1. 第一天：给他发A业务朋友圈文案，让他转发
2. 第二天：问他"有没有客户问？"，他说"没有"
3. 第三天：给他发私聊话术，让他主动问1个客户
4. 第四天：客户有咨询，我立即对接，成交后立即分成
5. 结果：合伙人看到"真的能赚钱"，开始主动推广
```

**场景2：代账合伙人**
```
背景：某代账公司有50个企业客户，但不知道怎么做
激活步骤：
1. 给他发完整的"合伙人工具包"（话术+素材+FAQ）
2. 拉他进合伙人小群，让他看其他合伙人怎么做的
3. 每周一对一沟通1次，解答他的问题
4. 第一个月：他发了10条朋友圈，问了5个客户，成交1单
5. 结果：合伙人看到"真的有效"，开始持续推广
```

**场景3：宝妈合伙人**
```
背景：某宝妈有3个企业资源，但执行力一般
激活步骤：
1. 给她发最简单的朋友圈文案（1句话）
2. 告诉她"每天发1条就行，不费时间"
3. 第一个月：她发了20条朋友圈，问了2个客户，0成交
4. 第二个月：继续鼓励，给她发新话术
5. 结果：第二个月成交1单，她开始有信心，持续推广
```

**实操练习**：选择一个场景，设计激活方案

#### 11.4 合伙人维护技能

**如何维护20-30人的合伙人小群？**

**群内容策略**：
- **频率**：每天1-2条，不要刷屏
- **类型**：
  - 业务信息（新业务、新政策）
  - 成功案例（其他合伙人成交案例）
  - 培训内容（话术、素材、FAQ）
  - 激励内容（月度总结、优秀表彰）
- **话术**：
  - 不要用"大家注意"这种命令式
  - 用"分享一个好消息"这种分享式
  - 用"有合伙人问XX，统一回复"这种答疑式

**如何处理合伙人的常见问题和抱怨？**

**问题1："我发了朋友圈，但没人问"**
- 回答："正常，不是每条朋友圈都有咨询。建议每天发1-2条，持续发1周，通常会有咨询。"
- 提供：给他看其他合伙人的发圈频率和效果数据

**问题2："客户问的问题我答不上来"**
- 回答："没关系，把客户的问题发给我，我帮你回答。或者直接让客户加我微信，我来对接。"
- 提供：给他发常见问题FAQ，让他先自己看

**问题3："分成太少了"**
- 回答："分成是30%，这是行业标准。重点是持续带来客户，累计起来收入很可观。"
- 提供：给他看其他合伙人的月度收入案例

**问题4："我没时间"**
- 回答："理解，兼职确实时间有限。建议每天花10分钟发1条朋友圈就行，不费时间。"
- 提供：给他发"10分钟发圈SOP"

**如何定期激励合伙人？**

**每周激励**：
- 周一：发本周目标（"这周我们一起努力，争取X个咨询"）
- 周五：发本周总结（"这周有X个合伙人发圈，X个合伙人报备，X个咨询"）

**每月激励**：
- 月度总结：发本月数据（发圈数、报备数、咨询数、成交数）
- 优秀表彰：表彰本月表现最好的3个合伙人
- 下月目标：设定下月目标，激励大家继续努力

**实操练习**：
- 角色扮演：在模拟群里发3条激活内容
- 案例分析：为什么这个合伙人3个月没动作？如何激活？

#### 11.5 合伙人分层管理

**A类合伙人（重点维护）**：
- **沟通频率**：每周至少沟通1次
- **支持内容**：
  - 优先提供新业务信息
  - 优先提供优质素材
  - 一对一答疑和指导
- **目标**：每月至少报备2条有效线索

**B类合伙人（正常维护）**：
- **沟通频率**：每2周沟通1次
- **支持内容**：
  - 定期发送培训材料
  - 群内统一答疑
  - 常规素材支持
- **目标**：每月至少报备1条有效线索

**C类合伙人（观察期）**：
- **沟通频率**：每月沟通1次
- **支持内容**：
  - 群内统一培训
  - 基础素材支持
- **目标**：3个月内转化为B类

**淘汰标准**：
- 3个月内无任何动作（不发圈、不问客户、不报备）
- 违反公司规则（如私自飞单、用个人微信对接）
- 不配合培训和指导（不回消息、不参加培训）

**实操练习**：给3个不同类型的合伙人设计维护方案

#### 11.6 防飞单机制

**为什么合伙人可能飞单？**
- 想绕过公司，直接对接客户，拿更多分成
- 觉得公司分成太少，想自己找渠道
- 不信任公司，担心公司不给他分成

**如何通过企微+内容依赖防飞单？**
- **必须用企业微信**：所有客户对接必须通过企业微信，不能用个人微信
- **必须用公司素材**：所有朋友圈和话术必须用公司提供的，不能自己编
- **必须报备**：所有客户必须提前报备，不能私下对接
- **建立依赖**：让合伙人依赖公司的内容、话术、培训，离开公司就做不好

**如何处理飞单事件？**
- **发现飞单**：立即停止合作，不再提供任何支持
- **追责**：如果造成损失，追究责任
- **预防**：加强培训和沟通，让合伙人理解"合作共赢"的道理

**实操练习**：设计一个防飞单的完整流程
