# 三步傻瓜式业务员招募模式 v1.0

**版本**：v1.0  
**创建日期**：2025-11-21  
**适用对象**：运营专员、运营助理、实习生  
**核心理念**：让完全不懂业务的人，通过三步傻瓜式操作，也能招募和管理业务员

---

## 🎯 核心理念

让运营专员按照"三步傻瓜式"操作：

1. **发广告**（八句话，直接发）
2. **回复咨询**（对着话术大全念）
3. **拉群**（后台处理）

**这个模式先在招运营时测试，验证可行后复制到招兼职业务员！**

---

## 📢 第一步：发广告（八句话广告）

```
【兼职副业项目，0投资，时间自由】

我们是三湘票据，做企业票据服务10年。

现招兼职业务员，推荐企业客户给我们，
成交后你拿30%利润。

8个业务线：
票据变现 / 付款省钱 / 存款理财 / 注册资本实缴 / 
招投标显账 / 套利指导 / 做大规模 / 流水包装

单笔收入：500-5000元（示例区间，不构成承诺）*
月入：兼职5000-20000元（示例区间，受多因素影响）*

2小时培训即可上手，提供全套工具包。

感兴趣加我微信：[微信号]

*以上收入为示例区间，实际收益受个人能力、市场环境、投入时间、客户资源等多因素影响
```

---

### 发布渠道

#### 线上渠道
- **朋友圈**：每天1次，早上9点或晚上8点
- **微信群**：相关社群，3天1次（避免刷屏）
- **小红书 / 知乎**：文章形式，周更
- **抖音 / 视频号**：短视频，周更

#### 线下渠道
- **财税代理公司**：留传单
- **会计培训机构**：合作推广
- **创业园区**：张贴海报

### 遇到不会答的问题 → 立即拉群

**运营说：**
```
"这个问题很好！

我拉个群，让我们业务负责人（常松阳）详细给你解答，
他更专业。"
```

**然后：**
1. 创建微信群
2. 拉候选人 + 常松阳
3. @常松阳："阳哥，这位是XX，想了解[具体问题]，麻烦您详细说明一下"

**常松阳接管回答**

## 👥 第三步：拉群（后台处理）

### 什么时候拉群？

#### 立即拉群的情况
- ✅ 候选人问的问题你不会答
- ✅ 候选人质疑项目真实性
- ✅ 候选人要跟负责人聊
- ✅ 候选人说"我要认真考虑"

#### 不急着拉群的情况
- ⚠️ 候选人只是随便问问
- ⚠️ 候选人明确表示不感兴趣
- ⚠️ 候选人说"我再看看"

---

### 拉群标准话术

**运营说：**
```
"XX您好，我拉个群，
让我们业务负责人常总详细给您介绍。

他做这个业务10年了，
可以解答您所有疑问。"
```

**群里@常松阳：**
```
"@常松阳  
阳哥，这位是XX，[简单介绍候选人背景]

他想了解：
1. [问题1]
2. [问题2]

麻烦您详细介绍一下我们的项目！"
```

**然后：**
运营在群里不再说话，让常松阳专业处理。

## 💡 常见问题

### Q：运营完全不懂业务怎么办？
A：不需要懂！严格照着话术念，不会答的立即拉群。

### Q：候选人问的问题不在话术库里怎么办？
A：立即拉群，让常松阳答。同时记录这个问题，更新到话术库。

### Q：拉群后常松阳不在线怎么办？
A：提前和常松阳约定：拉群后30分钟内必须响应。

### Q：测试失败了怎么办？
A：不要急，收集问题，优化流程，再测试。模式是迭代出来的。
