## 💬 三、激活话术库

### 3.1 H业务话术（最重要）

**开场白**：
```
"张总，好久不见！上次帮您做的票据贴现还顺利吧？"
```

**切入正题**：
```
"最近我们新增了一个更有价值的服务，想跟您分享一下。
很多企业不知道，通过3-6个月的流水养成，
可以申请到年开票额5-30%的发票贷。"
```

**案例引入**：
```
"我们有个客户，和您情况类似，
养了4个月流水，在交行申请到300万，
年化才3点几，比票据贴现还便宜很多。"
```

**价值强调**：
```
"这不是普通的贷款中介服务，
是帮企业'做手术'，改造财务体质。
做好了，以后任何融资都会容易很多。"
```

**行动引导**：
```
"要不我们约个时间详聊？
或者我先给您发个详细方案？"
```

### 3.2 B业务话术

**开场白**：
```
"李总，您平时付款应该不少吧？"
```

**价值点**：
```
"如果用票据付款，1000万能省50-60万。
就是用票据代替部分现金，供应商也愿意接受。"
```

**消除顾虑**：
```
"这个很常见，很多大企业都这么做。
我们提供票源，您直接用就行。"
```

### 3.3 D业务话术（选择性使用）

**适合对象**：资金充裕的企业

**开场白**：
```
"王总，如果您有闲置的发票和资金，
有个15-25%年化收益的机会。"
```

**简单说明**：
```
"就是用真实发票去银行贴现，
我们提供票据和渠道，
很多企业都在悄悄做这个。"
```
