# 7个业务基础资料包制作指南

**版本**：v1.0  
**创建日期**：2025-12-04  
**制作目标**：为Week 0-4测试做好准备，2个兼职业务员能直接用  
**制作周期**：2-3周（每个业务2-3天）  
**制作人**：实习生（AI驱动）或常松阳自己

---

## 🎯 为什么要做这个？

### 当前问题

**现状**：
- 7个业务只有"业务详解"文档（很长，3000-10000字）
- 2个兼职业务员拿到手不知道怎么发朋友圈
- 没有标准化素材
- 每次都要临时写文案，效率低

**应该是什么样**：
- 每个业务有"开箱即用"的素材包
- 业务员拿到就能直接发朋友圈
- 客户问什么都能快速找到答案
- 3-5步标准流程，不用动脑

---

## 📦 标准资料包格式

### 每个业务的资料包包含6个文件+1个文件夹

```
【业务X资料包】/
├─ 01_一句话介绍.txt（30字）
├─ 02_三句话说明.txt（痛点+方案+效果，100字）
├─ 03_广告文案3版本.md（痛点型+案例型+对比型）
├─ 04_FAQ问答集.md（10-20个问答）
├─ 05_简化版SOP.md（3-5步）
├─ 06_合规检查清单.md（必须检查的禁用词）
└─ 素材/
   ├─ 海报1张.png（或设计稿）
   ├─ 案例模板.docx（可选）
   └─ 报价模板.xlsx（可选）
```

---

## 📋 各文件详细说明

### 文件1：一句话介绍.txt

**用途**：最简单的业务描述，30字以内

**示例（A业务）**：
```
企业手上有票据/凭证，我们帮变现，通常10分钟-2小时到账（以票种/额度/通道为准）
```

**制作方法**：
1. 从业务详解文档中提取"一句话定义"
2. 确保包含：业务是什么+解决什么问题+核心价值
3. 控制在30字以内

---

### 文件2：三句话说明.txt

**用途**：快速讲清楚业务，100字以内

**格式**：
```
【痛点】客户遇到什么问题？
【方案】我们怎么解决？
【效果】客户能得到什么好处？
```

**示例（A业务）**：
```
【痛点】企业收到下游的票据/凭证，但资金周转紧张，等到期太慢。

【方案】我们帮您把票据/凭证快速变现，通常10分钟-2小时到账（以票种/额度/通道为准）。

【效果】立即获得现金流，解决燃眉之急，不影响正常经营。
```

**制作方法**：
1. 从业务详解文档中提取"目标客户画像"和"典型使用场景"
2. 按照痛点-方案-效果的结构重写
3. 控制在100字以内

---

### 文件3：广告文案3版本.md

**用途**：朋友圈/海报/视频的文案，可以直接复制使用

**包含3个版本**：
- 版本1：痛点型（强调客户痛点）
- 版本2：案例型（用真实/虚拟案例说话）
- 版本3：对比型（和传统方式对比）

**每个版本200-300字**

**示例（A业务-痛点型）**：
```
【A业务-广告文案版本1：痛点型】

您的企业是不是也遇到这些问题？

✗ 收到下游的票据/凭证，但资金周转紧张
✗ 等到期要3个月、6个月，太慢了
✗ 银行贴现利率高，手续繁琐
✗ 找小贷公司又担心不安全

我们提供票据/凭证快速贴现服务：

✓ 通常10分钟-2小时到账（以票种/额度/通道为准）
✓ 费率合理，比银行更灵活
✓ 全流程公对公，合同+发票对齐
✓ 已服务XXX家企业，累计贴现XX亿

如果您手上有票据/凭证需要变现，欢迎加我微信咨询。

回复【贴现】了解详情

*以上到账时效为示例区间，以票种/额度/通道为准
```

**制作方法**：
1. 搜索"展业话术大全"和"极简运营流程"
2. 提取现有文案作为参考
3. 用AI生成3个版本
4. **必须加合规脚注**

---

### 文件4：FAQ问答集.md

**用途**：客户常问的10-20个问题，业务员能快速回答

**格式**：
```
## A业务常见问题（FAQ）

### Q1：什么是票据贴现？
A1：[100字以内的回答]

### Q2：多久能到账？
A2：[100字以内的回答]

...
```

**必须包含的问题类型**：
- 业务定义（什么是XX业务）
- 到账时效（多久能到账）
- 费用成本（怎么收费）
- 安全合规（安全吗/合法吗）
- 适用条件（什么客户能做）
- 操作流程（怎么操作）
- 风险提示（有什么风险）
- 案例说明（有成功案例吗）

**制作方法**：
1. 搜索"展业话术大全"中的FAQ部分
2. 提取10-20个最常见的问题
3. 用AI优化回答（简洁、合规）
4. 每个回答100字以内

---

### 文件5：简化版SOP.md

**用途**：3-5步标准流程，业务员照着做就行

**格式**：
```
## A业务简化版操作流程

### Step 1：识别客户需求
**怎么识别**：
- 聊天中问："您公司收到票据/凭证吗？"
- 如果客户说"有"，继续问

**话术**：
"X总，您公司手上有票据/凭证的话，我们可以帮您快速变现，通常10分钟-2小时到账（以票种/额度/通道为准）。您现在有需要吗？"

---

### Step 2：收集基本信息
**需要问什么**：
- 票据类型（银承/商承/凭证）
- 票据金额（多少钱）
- 到期日期（什么时候到期）
- 企业信息（企业名称/行业）

**话术**：
"麻烦您提供一下：
1. 票据类型和金额
2. 到期日期
3. 企业全称
我帮您问一下报价。"

---

### Step 3：拉群移交
**操作**：
1. 建群：【企业名称-A业务贴现】
2. 拉企业老板进群
3. @办公室人员："X老师，这是XX企业X总，他们有票据贴现需求，麻烦您对接。"

**注意**：
- 不要在群里讨论价格细节
- 移交后可以不管，等办公室成交

---

### Step 4：办公室成交（你不用管）
办公室会：
- 详细沟通
- 报价
- 成交

---

### Step 5：等结算
成交后办公室会通知你结算提成。
```

**制作方法**：
1. 参考"极简运营流程"的5步流程
2. 针对具体业务细化
3. 每步包含：怎么做+话术+注意事项
4. 控制在3-5步

---

### 文件6：合规检查清单.md

**用途**：发任何内容前，必须检查的禁用词和合规要求

**格式**：
```
## A业务合规检查清单

### ✅ 推荐使用（白名单）

**到账时效**：
- ✅ "通常10分钟-2小时到账（以票种/额度/通道为准）"
- ✅ "具体到账时间以实际情况为准"

**费率/成本**：
- ✅ "费率示例：X%-X%，具体以成交时为准"
- ✅ "成本受多种因素影响"

**安全/合规**：
- ✅ "基于银行承兑/合同化机制，合规边界内可控"
- ✅ "全流程公对公，合同+发票对齐"

---

### ❌ 禁止使用（黑名单）

**到账时效**：
- ❌ "10分钟到账"
- ❌ "秒到"
- ❌ "实时到账"

**费率/成本**：
- ❌ "保证年化X%"
- ❌ "固定省X%"
- ❌ "确保收益"

**安全/合规**：
- ❌ "100%安全"
- ❌ "零风险"
- ❌ "绝对合规"
- ❌ "保证XX"

**其他禁用词**：
- ❌ "保证"
- ❌ "承诺"
- ❌ "确保"
- ❌ "100%"
- ❌ "零XX"
- ❌ "绝对"

---

### 📋 发布前检查（3步）

**Step 1：搜索禁用词**
- 用Word/WPS的"查找"功能
- 搜索所有黑名单词汇
- 全部替换成白名单表述

**Step 2：检查数据标注**
- 所有效果数据加脚注："*以上数据为示例值，受XXX影响*"
- 所有时效数据加脚注："*到账时效受票种/额度/通道影响*"

**Step 3：最终检查**
- 读一遍，听起来是不是太绝对？
- 有没有"打包票"的感觉？
- 如果有，继续修改

---

✅ 检查完成，可以发布！
```

**制作方法**：
1. 参考"系统指令4.3"中的合规检查清单
2. 针对具体业务细化
3. 增加"发布前检查3步"

## 📊 7个业务的优先级

### P0：立即做（Week 0前完成）

**A业务**：票据/凭证贴现
- 原因：核心业务，用得最多
- 预计：2天

- 原因：核心业务，与A配套
- 预计：2天

- 原因：业务量大，容易成交
- 预计：1天

- 原因：战略重心，需要完整SOP
- 预计：3天

- 原因：增值服务，与H配套
- 预计：2天

- 原因：特定场景使用
- 预计：1天

**E业务**：债券投资服务
- 原因：延伸业务
- 预计：1天

**G业务**：专利实缴
- 原因：延伸业务
- 预计：1天

## 📝 更新维护

### 何时更新？

**触发条件**：
- 业务政策变化（费率调整、流程优化）
- 合规要求变化（禁用词更新）
- 客户反馈（FAQ不够用）
- 成功案例积累（补充真实案例）

**更新频率**：
- 合规检查清单：每月检查1次
- FAQ问答集：每月补充1-2个新问题
