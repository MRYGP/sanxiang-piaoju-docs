## 💰 第二章：B业务话术（付款省钱）

### 话术1：简洁版（1分钟讲清楚）

```
"X总，我简单说一下这个省钱的方法：

您公司付货款的时候：
- 传统方式：转账100万现金出去
- 我们的方式：花99.5万买票，用票付款

结果：
- 供应商收到100万的票（他满意，账面没变）
- 您实际只花了99.5万（省5000元）
- 省了0.5%

为什么能省钱？
因为票要未来才能兑现（有时间成本），
所以比现金便宜。

如果您每月付款100万，
一年能省6万块！

您要不要试试？"
```

---

### 话术2：详细版（3分钟深度讲解）

```
"X总，我给您详细讲讲这个业务：

【第一步：了解现状】
请问您公司每月大概付多少货款出去？
主要付给哪些供应商？

【第二步：介绍方案】
我们是这样帮您省钱的：

比如您要付100万货款给供应商：

传统方式：
- 您从账上转100万现金出去
- 供应商收到100万现金
- 您花了100万

我们的方式：
- 您花99.5万从我们这买一张100万的银行承兑汇票
- 您把这张票付给供应商
- 供应商收到100万的票（可以到期兑现或提前贴现）
- 您实际只花了99.5万

【第三步：算账】
您省了：100万 - 99.5万 = 5000元（0.5%）

如果您每月付100万，一年付1200万：
一年能省：1200万 × 0.5% = 6万元

【第四步：解答疑问】
您可能担心：
1. 供应商愿意收票吗？
   - 大部分企业都接受票（这是常见的支付方式）
   - 票可以到期兑现，也可以提前贴现变现
   - 供应商收到100万票，账面没有损失

2. 票安全吗？
   - 我们提供的是银行承兑汇票（承兑人是银行）
   - 基于银行承兑/合同化与留痕机制，合规边界内可控
   - 受《票据法》保护

3. 流程复杂吗？
   - 跟转账一样简单
   - 通常 10 分钟—2 小时完成（以票种/额度/通道为准）
   - 我们手把手教您

【第五步：促成交】
您看，这个方法：
✅ 能省钱（常见区间示例：0.5%-5%，具体以票种/期限/市场为准，非承诺）
✅ 安全可靠（基于银行承兑/合同化与留痕机制，合规边界内可控）
✅ 操作简单（跟转账一样）

要不您试一次？
可以先从小额开始，比如10万、20万，
您觉得好再继续合作。

您觉得怎么样？"
```

## 📋 话术使用tips

### Tip 1：话术要灵活使用

```
不要死记硬背！
- 话术是参考，不是照本宣科
- 根据实际情况调整
- 用自己的语言表达
- 关键是把意思讲清楚
```

### Tip 2：多听少说

```
先听客户说：
- 了解客户需求
- 找到客户痛点
- 再介绍对应方案

不要一上来就推销！
```

### Tip 3：建立信任最重要

```
客户不信任你，说什么都没用。

怎么建立信任？
- 专业（懂业务）
- 真诚（不夸大）
- 耐心（解答疑问）
- 案例（讲真实故事）
```

### Tip 4：遇到困难,请求支持

```
如果客户问的问题您答不上来：
- 不要胡说
- 老实说"我不确定,我帮您问总部"
- 然后立即联系总部
- 给客户专业答复

诚实比装懂更重要！
```
