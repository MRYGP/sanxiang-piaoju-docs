## 💰 第二章：B业务话术（付款省钱）

### 开场判断

**话术：**
```
「老板，我简单问一句：
您公司平时付货款给供应商，
是一定要全现金，还是可以接受一部分用**远期支票**来付？

如果可以接受，我们可以帮您优化付款结构，
通常能节省0.4%-8%的付款成本（具体以市场为准），
比银行贷款便宜多了。」
```

### 话术1：简洁版（1分钟讲清楚）

```
"X总，我简单说一下这个省钱的方法：

您公司付货款的时候：
- 传统方式：转账100万现金出去
- 我们的方式：花99.6万买远期支票（企业先付现金给我们），用远期支票付款

结果：
- 供应商收到100万的远期支票（他满意，账面没变）
- 您实际只花了99.6万（省4000元）
- 省了0.4%（半年期，年化节省0.8%）

为什么能省钱？
因为远期支票要未来才能兑现（有时间成本），
所以比现金便宜。

⚠️ 重要提醒：
- 企业必须先付现金给我们，我们才给远期支票
- 节省成本为示例区间（通常节省0.4%-8%，具体以市场为准），不构成刚性承诺

您要不要试试？"
```

---

### 话术2：详细版（3分钟深度讲解）

```
"X总，我给您详细讲讲这个业务：

【第一步：了解现状】
请问您公司每月大概付多少货款出去？
主要付给哪些供应商？

【第二步：介绍方案】
我们是这样帮您省钱的：

比如您要付100万货款给供应商：

传统方式：
- 您从账上转100万现金出去
- 供应商收到100万现金
- 您花了100万

我们的方式：
- 您先付99.6万现金给我们（企业必须先付现金给我们，我们才给远期支票）
- 我们给您一张100万的远期支票（银票、商票或凭证）
- 您把这张远期支票付给供应商
- 供应商收到100万的远期支票（可以到期兑现或提前贴现）
- 您实际只花了99.6万

【第三步：算账】
您省了：100万 - 99.6万 = 4000元（0.4%半年期，年化节省0.8%）

如果您每月付100万，一年付1200万：
一年能省：1200万 × 0.8% = 9.6万元（年化）

⚠️ 重要提醒：
- 企业必须先付现金给我们，我们才给远期支票
- 节省成本为示例区间（通常节省0.4%-8%，具体以市场为准），不构成刚性承诺

【第四步：解答疑问】
您可能担心：
1. 供应商愿意收票吗？
   - 大部分企业都接受票（这是常见的支付方式）
   - 票可以到期兑现，也可以提前贴现变现
   - 供应商收到100万票，账面没有损失

2. 票安全吗？
   - 我们提供的是银行承兑汇票（承兑人是银行）
   - 基于银行承兑/合同化与留痕机制，合规边界内可控
   - 受《票据法》保护

3. 流程复杂吗？
   - 跟转账一样简单
   - 通常 10 分钟—2 小时完成（以票种/额度/通道为准）
   - 我们手把手教您

【第五步：促成交】
您看，这个方法：
✅ 能省钱（常见区间示例：0.5%-5%，具体以票种/期限/市场为准，非承诺）
✅ 安全可靠（基于银行承兑/合同化与留痕机制，合规边界内可控）
✅ 操作简单（跟转账一样）

要不您试一次？
可以先从小额开始，比如10万、20万，
您觉得好再继续合作。

您觉得怎么样？"
```

### 移交流程

**业务员需要收集的信息：**
- 企业基本信息
- 付款金额、付款时间
- 供应商是否接受承兑/凭证
- 企业和供应商是否开通凭证账户
- 偏好哪种承兑/凭证类型（银承/商承/凭证）

**禁止事项（红线）：**
- 禁止说："保证年化X%/固定省X%"、"100%安全/零风险/绝对合规"
- 禁止承诺"固定收益、绝对安全"、"肯定能省多少钱"
- 禁止使用"私卡/内部秘密/线下结算"等不合规表述
- 禁止承诺"企业不用先付现金"（核心要求：企业必须先付现金给我们）

## 🏦 第四章：C业务话术（冲存款）

### ⚠️ 业务特点提示（业务员必知）

- **季节性强**：月末/季末是旺季，平常需求较少
- **金额波动大**：单笔金额100万-10亿不等
- **利润率极低**：走量为主，主要靠冲量
- **收益模型示例**：1亿业务，资金方收益约10万，我们收益约1万

**最佳推广时机**：
- 每月25-31号
- 每季度末月（3月/6月/9月/12月）

**话术：**
```
「老板，我简单问一句：

维护银行关系，获得银行支持。
服务费市场价万5-千1/天（具体以市场为准）。」

```

### 话术1：简洁版

```
"X总，我简单说一下这个服务：
```
