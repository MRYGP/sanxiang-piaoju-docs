# 面试提纲-运营专员-含反向测试

**总时长**：60-75分钟

**流程结构**：
1. 自我介绍（5分钟）
2. 公司和岗位介绍（10分钟）
3. 核心能力提问（30分钟）
4. **反向测试环节（20分钟）⭐**
5. 候选人提问（10分钟）

---

## 📋 面试前准备（5分钟）

### 准备材料

- [ ] 打印《A业务极简说明-面试用》1份
- [ ] 打印《面试评分表-运营专员》1份
- [ ] 准备笔记本和笔
- [ ] 准备企业微信（用于现场演示测试）

### 环境准备

- [ ] 安静的会议室
- [ ] 水/茶
- [ ] 手机静音

---

## 🎯 面试流程（60-75分钟）

### 第一部分：开场与业务介绍（15分钟）

#### 1.1 暖场（3分钟）

```
"你好，我是常松阳，三湘票据的创始人。
感谢你过来面试。

今天我们聊聊这个岗位，也了解一下你的情况。
你先简单介绍一下自己吧，3-5分钟就好。"
```

**观察要点**：

- 表达是否清晰有逻辑
- 有没有突出重点
- 时间控制能力

---

#### 1.2 公司和岗位介绍（10分钟）

**使用3分钟话术**（参考《【最终版】业务运营专员-BOSS直聘JD.md》）：

```
"我简单介绍一下我们公司和这个岗位：

【我们做什么】（1分钟）
我们是做"企业资金便利店"的，帮企业老板在收钱、付钱这块省钱省心。

比如：
- 企业手里有票据要等6个月才能拿钱，我们帮他今天变现
- 企业要付100万货款，我们帮他设计更划算的付款方式，能省几万块

有8个业务线，类似滴滴的"一站式出行"。

【岗位定位】（1分钟）
这个岗位，核心不是让你自己拉客户，
而是招募和管理一批有企业资源的兼职合伙人（会计/代账/中介），
让他们持续带客户，成交后分成。

就像滴滴平台：你不是司机，你是管理司机的运营。

【为什么找你】（1分钟）
我们要测试8个业务，需要有人：
1. 招募和激活兼职合伙人
2. 用AI工具生成内容和话术
3. 测试哪些内容有效，哪些合伙人质量高
4. 整理成标准化流程

你会大量使用AI工具（Claude/ChatGPT/Cursor），
我们会系统教你，但你要有执行力和学习能力。
```

**候选人提问**（2分钟）：

```
"你有什么想了解的吗？"
```

**观察要点**：

- 候选人问什么问题（关心薪资/发展/工作内容/公司前景？）
- 是否理解岗位定位（合伙人运营 vs 客户开发）
- 听的时候有没有记笔记、有没有眼神交流

---

### 第二部分：行为面试（30分钟）

#### 2.1 执行力考察（10分钟）

**问题1：过往执行力案例**

```
"能讲一个你印象最深的任务吗？
从接到任务到完成，你是怎么做的？"
```

**追问**：

- 遇到什么困难？
- 怎么解决的？
- 完成时间和预期有差距吗？

**评分标准**（详见评分表）：

- 优秀：说得出完整流程，有具体方法，遇到问题会主动想办法
- 及格：能说出大概过程，但不够细致
- 不及格：说不出具体案例，或全程被动等指示

---

**问题2：假设任务测试**

```
"如果明天让你用5个微信号测试我们的8个业务，
你会怎么做？"
```

**观察要点**：

- 是否能说出一个基本计划（准备-测试-记录-复盘）
- 还是说"我需要先培训"（被动等待）
- 有没有问关键问题（比如：测试对象是谁？要达到什么目标？）

---

#### 2.2 合伙人运营能力考察（15分钟）

**问题3：合伙人运营理解**

```
"假设我给你50个兼职业务员的联系方式，
这些人有会计、代账、宝妈、学生等不同背景。

你会怎么做分层管理和激活？"
```

**追问**：

- 怎么分类？
- 怎么激活？
- 如果3个月都不活跃，怎么办？

**评分标准**：

- 优秀：能说出分层逻辑+针对性激活方法+淘汰标准
- 及格：知道要分类和激活，但方法比较单一
- 不及格：没有思路，或想着"我帮他们做"

---

**问题4：过往运营经验**

```
"你以前有没有维护过一群人（客户/学员/代理）？
怎么让他们持续活跃的？"
```

**观察要点**：

- 有没有真实经验
- 是用制度激励，还是靠人情维护
- 有没有数据化思维（知道活跃率、流失率）

---

#### 2.3 学习能力考察（5分钟）

**问题5：AI工具使用**

```
"你会用AI工具吗？用过哪些？
能举个实际应用的例子吗？"
```

**评分标准**：

- 优秀：会用，能举出实际案例
- 及格：听说过，简单用过
- 不及格：不会也不想学

---

**问题6：快速学习能力**

```
"如果让你1周内学会企业微信的高级功能，
你会怎么学？"
```

**观察要点**：

- 是否有学习路径（官方文档/教程/实践）
- 还是说"问同事"或"边用边学"（没有主动性）

---

### 第三部分：实战测试 - A业务调研 + 反向测试（20分钟）

#### 3.1 发材料并讲解任务（2分钟）

```
"现在给你一个实战任务：

【第一步：调研A业务】（10分钟）
我给你这份《A业务极简说明》，
你花10分钟看一下，可以用手机、AI工具查资料。

【第二步：反向测试（挑刺）】（5分钟）
看完后，告诉我：
1. 如果你是客户，你觉得这个业务说明里，
   有哪3个地方你可能看不懂或不买账？
2. 为什么你觉得这些地方有问题？

【第三步：制定计划】（5分钟）
如果让你招募合伙人来推广A业务，
你会怎么在第一周开始？每天做什么？
会用AI做什么？
```

**发材料**：

- 递上《A业务极简说明-面试用》
- 提醒可以用手机、AI工具

**⚠️ 关键操作：解除防御信号**

说完"可以用手机、AI工具"后，刻意停顿5秒，自己拿起手机或起身倒水，给候选人"解除防御"信号。

---

#### 3.2 观察阶段（10分钟）

**重点观察**：

- [ ] 是否第一时间掏出手机用AI搜索？（AI敏感度）
- [ ] 还是只用百度搜索专业术语？
- [ ] **是否主动问问题？（关键测试点！）**
  - 平庸候选人：看完就完了，根本不问
  - 优秀候选人：会主动问"老板，这里没写具体贴现几个点啊？客户肯定会问这个，我该怎么回答？"
  - **能问出这个问题的，才是有销售直觉的人**
- [ ] **是否质疑数字合理性？（高阶测试点！）**
  - 看第23行时有没有皱眉？
  - 有没有拿手机算年化收益率？
  - 有没有问"这个利润率合理吗？"
  - **能质疑的，才是合伙人苗子！**
- [ ] **是否发现数字矛盾？（顶级测试点！）⭐**
  - 看第53行时有没有停顿或疑惑？
  - 有没有翻回第23行对比？
  - 有没有问"前面说年化2%，这里说年化1%，是不是有矛盾？"
  - **能发现矛盾的，是合伙人苗子中的极品！**
- [ ] 是否记笔记？
- [ ] 表情：是困惑、自信，还是焦虑？

**陷阱1：贴现率信息缺失**
- 文档故意没有明确写"贴现率具体是多少"
- **测试目的**：测试候选人的销售直觉和客户思维
- **如果候选人主动问贴现率**：这是加分项，可回答"根据票据类型和市场行情，一般在0.5%-3%之间"

---

**陷阱2：利润率数字不合理（财商过滤器）⭐**
- 文档写"99万半年赚1万"（年化约2%），实际我们转卖赚500-1000元
- **隐藏呼应点**：第53行说"年化约1%"，与第23行形成矛盾
- **测试目的**：测试数字敏感度和商业思维

**如果候选人质疑数字**：强烈加分项，标准回答："你说得对，这个数字是为了简化理解。实际情况是我们转卖出去，赚500-1000元差价。这个业务的核心是规模化和周转速度。"

---

#### 3.3 反向测试环节（5分钟）

**⚠️ 关键操作：先问利润率测试（如果候选人没主动质疑）**

如果候选人在观察阶段没有质疑数字，先问这个：

```
"在看文档的时候，我注意到第23行写的是：
'企业立即拿到99万，我们等6个月收100万，赚1万差价'

你觉得这个生意怎么样？99万出去，半年回100万，赚1万。"
```

**根据回答判断段位**（见上方"陷阱2"的实战SOP）

**然后再问反向测试问题**：

```
"时间到，你能说说你的发现吗？

先说第一个问题（岗位定位测试）：
如果你是运营专员，你会怎么找到有这种需求的客户？

（如果候选人犹豫，可以给一些引导性提问作为隐形提示）
- 你的重点是找企业客户（制造企业、贸易公司等）还是找兼职中介合伙人（会计、代账、企业服务中介）？
- 为什么？这两种方式各有什么优缺点？"
```

**岗位定位测试（关键筛选点）**：

**正确答案**：找兼职中介合伙人（会计/代账/企业服务中介）

**判断标准**：
- ❌ 错误：说"找企业客户" → -5分（没理解岗位定位）
- ✅ 正确：说"找合伙人"，能说出理由 → +5分
- 🥇 优秀：说"找合伙人"，能说出具体方法和理由 → +10分（合伙人苗子）

**如果候选人答对了**，可确认："你说得对，这个岗位的核心是'合伙人运营'，不是'客户开发'。"

**然后再问第二个问题**：

```
"第二个问题：
你觉得这个业务说明里，哪3个地方客户可能看不懂或不买账？"
```

**评分标准**：
- **10分（优秀）**：能指出3个以上有价值的问题，站在客户角度思考
- **7分（及格）**：能指出1-2个问题，理由基本合理
- **4分（勉强）**：只能找出表面问题
- **0分（不及格）**：找不出问题

**追问1：改进方案**

```
"如果你是运营专员，你会怎么改进这3个地方？"
```

**追问2：AI实操验证（更狠的追问）⭐**

```
"如果现在就要你用AI改这一段，你会用什么Prompt（提示词）？

比如，你想改进'贴现费用根据市场行情确定'这句话，
让客户更清楚，你会怎么跟AI说？"
```

**评分要点**：
- **优秀**：能说出具体的Prompt（包含要求、范围、语言风格等）
- **及格**：能说出大概思路，但Prompt不够具体
- **不及格**：说"我不会用Prompt"或"我直接问AI怎么改"

---

#### 3.4 方案制定环节（3分钟）

```
"第二个问题：
如果让你第一周开始招募合伙人推广A业务，
你会怎么做？每天做什么？会用AI做什么？"
```

**评分标准**：

- 能说出基本计划（目标人群、渠道、话术、时间安排）
- 有没有提到用AI（生成话术、分析数据）
- 是否有数据思维（招多少人、测试多少次）

**追问：AI实操验证（如果前面没问）**

如果候选人在"反向测试"环节没有展示AI实操能力，可以在这里追问：

```
"如果现在就要你用AI生成招募合伙人的朋友圈文案，
你会用什么Prompt？能现场演示一下吗？"
```

**目的**：直接验证AI工具的实操深度，区分"嘴炮"vs"真练家子"

---

### 第四部分：互相提问 + 薪资沟通（10-15分钟）

#### 4.1 候选人提问（5-10分钟）

```
"你还有什么想问的吗？"
```

**常见问题及回答**（参考《招聘全流程手册》）：

- 试用期多久？薪资怎么算？
- 需要加班吗？
- 公司未来发展如何？

**观察要点**：

- 问题质量（打工者思维 vs 操盘手思维）
- 是否关心成长和发展空间
- 是否关心业务逻辑和数据

---

#### 4.2 薪资和到岗时间（5分钟）

```
"关于薪资，我们的范围是8-12K底薪，
根据你的经验和能力定薪。

试用期3个月，试用期工资是转正工资的80%-90%。

另外有渠道绩效奖金和完成奖金。

你期望的薪资是多少？
什么时候能到岗？"
```

**记录**：

- 候选人期望薪资
- 到岗时间
- 是否需要考虑

---

## ✅ 面试结束后处理（5分钟）

### 1. 立即填写评分表

- 不要凭印象，现场打分
- 记录候选人的亮点和疑虑点

### 2. 快速决策

- 90分以上：当天或次日发offer
- 75-89分：1-2天内决定
- 60-74分：再面试一次或不录用
- 60分以下：礼貌拒绝

### 3. 及时反馈

- 录用：当天/次日通知
- 不录用：2天内礼貌拒绝

---

## 🚨 面试中的红旗信号

**立即警惕**：

- ❌ 频繁打断你说话
- ❌ 对AI完全不感兴趣、明确抗拒学习新工具
- ❌ 说"这个我不会"、"需要培训"（被动等待）
- ❌ 只关心薪资福利，不关心工作内容
- ❌ 简历造假（现场问细节答不上来）
- ❌ 对"合伙人运营"完全没概念，一直在想"怎么直接拉客户"

**观察信号**：

- ⚠️ 说话啰嗦，没重点
- ⚠️ 不记笔记，不提问
- ⚠️ 过分强调"稳定"、"不想拼"

---

## 💡 面试技巧提示

### 1. 守住"老板"的边界

- ❌ 不要变成"你在给候选人培训"
- ✅ 你讲业务最多15分钟
- ✅ 剩下的时间，多问、多听、多观察

### 2. 看态度，而不只是能力

- 不会AI工具 → 可以教
- 不愿意学AI工具 → 不合适

### 3. 相信第一印象

- 如果面试过程中总觉得"不对劲"
- 不要因为"找不到人"而降低标准
