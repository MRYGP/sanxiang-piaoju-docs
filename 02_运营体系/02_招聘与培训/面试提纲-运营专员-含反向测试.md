# 面试提纲-运营专员（完整版）

**版本**：v2.2  
**更新日期**：2025-11-28  
**总时长**：60-75分钟  
**核心目标**：先筛选，后推销——高效识别合适候选人，仅对通过者展示吸引力

---

## 📌 面试前准备

### 必备材料（打印3份）

1. **《A业务极简说明-面试用》** - 给候选人看
2. **《面试评分表-运营专员》** - 自己打分
3. **白纸或小白板** - 手画商业模式图（仅对通过筛选者使用）

### 心态调整

> **不是你在求人才，是人才在求一个"靠谱且强大"的平台。**

>
> 你有三张王牌：
>
> - 资金能力（一天调动2000万）
> - AI能力（自己写论文、几十篇文章）
> - 后端团队（徒弟+深度合作伙伴）

---

## 🎯 面试流程总览

| 环节 | 时长 | 核心目的 | 关卡机制 |
|------|------|---------|---------|
| 1. 开场冷启动提问 | 5分钟 | 快速筛选，测试岗位理解 | ⚠️ 表现不佳直接结束 |
| 2. 核心能力深挖与实战 | 40分钟 | 深度测试（实战+行为+商业逻辑+估算） | ⚠️ 一票否决项出现即淘汰 |
| 3. 亮底牌与吸引（仅通过者） | 15分钟 | 展示优势，促成成交 | 仅对通过筛选者展示 |
| 4. 候选人提问+薪资沟通 | 15分钟 | 双向选择+驱动力深挖 | - |

**总时长**：75分钟（如提前淘汰，可能只需20-30分钟）

---

## 第一部分：开场冷启动提问（5分钟）⚠️ 第一道关卡

> **目标：快速判断候选人是否理解岗位本质，不合格者直接结束**

### 话术

```
"你好，我是常松阳，三湘票据的创始人。感谢你过来面试。

你先简单介绍一下自己吧，3-5分钟就好。重点说说：
- 之前做过什么
- 为什么对这个岗位感兴趣"
```

### 观察要点（自我介绍阶段）

- [ ] 表达是否清晰有逻辑
- [ ] 有没有突出重点
- [ ] 时间控制能力

---

### 冷启动提问（关键筛选）

**问题1：岗位理解测试**

```
"好，听完你的介绍，我想先问一个问题：

这个岗位叫'业务运营专员'，核心工作是'合伙人招募与管理'。

你觉得'合伙人运营'和'直接开发客户'有什么区别？

你觉得这个岗位最难的点在哪里？"
```

**判断标准：**

| 回答 | 判断 | 行动 |
|------|------|------|
| 完全理解"找合伙人"的逻辑，能说出难点 | ✅ 通过 | 进入下一环节 |
| 模糊理解，但方向对 | ⚠️ 待观察 | 继续测试，但降低期望 |
| 完全理解成"找企业客户" | ❌ 不合格 | **直接结束面试** |

**如果答错，给一次机会：**

```
"我再明确一下，这个岗位的核心是招募和管理兼职合伙人（会计/代账/中介），
让他们带客户，而不是你自己直接找企业客户。

你理解了吗？"
```

**如果还是答错 → 礼貌结束：**

```
"好的，我明白了。这个岗位可能不太适合你，因为核心工作确实是合伙人运营。

感谢你的时间，我们会在一周内给你反馈。"
```

---

### 🚨 关卡提示

**如果候选人在此环节表现不佳（完全理解错岗位定位），直接结束面试，不进入下一环节。**

**结束话术：**

```
"感谢你今天过来，这个岗位可能不太匹配你的预期。
我们会在一周内给你反馈。"
```

---

## 第二部分：核心能力深挖与实战（40分钟）⚠️ 核心筛选环节

> **目标：通过实战测试和行为面试，全面评估候选人能力**

### 2.1 实战测试：A业务调研+反向测试（20分钟）⭐最高效筛子

#### 2.1.1 发材料并讲解任务（2分钟）

```
"现在给你一个实战任务：

【第一步：看材料】（10分钟）
我给你这份《A业务极简说明》，你花10分钟看一下。
可以用手机、AI工具查资料。

【第二步：回答问题】（15分钟）
看完后，我会问你几个问题。"
```

**⚠️ 关键操作：解除防御信号**

说完"可以用手机、AI工具"后，刻意停顿5秒，
自己拿起手机或起身倒水，给候选人"解除防御"信号。

---

#### 2.1.2 观察阶段（10分钟）

**重点观察（在评分表上打勾）：**

- [ ] 是否第一时间掏出手机用AI搜索？（AI敏感度）
- [ ] 还是只用百度搜索专业术语？
- [ ] 是否主动问问题？
- [ ] 是否记笔记？
- [ ] 表情：是困惑、自信，还是焦虑？

**隐藏测试点：**

| 测试点 | 位置 | 优秀表现 |
|--------|------|---------|
| 贴现率缺失 | 全文 | 主动问"贴现率具体是多少？客户肯定会问" |
| 利润率矛盾 | 第23行vs第53行 | 发现"年化2%"和"年化1%"的矛盾 |

---

#### 2.1.3 岗位定位测试（3分钟）⭐一票否决项

**问题：**

```
"看完了？我先问你一个关键问题：

如果你是运营专员，你会怎么找到有这种需求的客户？

你的重点是找企业客户（制造企业、贸易公司）
还是找兼职中介合伙人（会计、代账、企业服务中介）？

为什么？"
```

**判断标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| "找企业客户" | ❌ 没理解岗位定位 | **一票否决，直接结束** |
| "找合伙人"，能说出理由 | ✅ 理解了 | +5分 |
| "找合伙人"，能说出具体方法 | 🥇 完全理解 | +10分（合伙人苗子） |

**🚨 如果答错 → 直接结束面试**

---

#### 2.1.4 冷启动招募测试（7分钟）⭐核心测试

**问题：**

```
"假设你入职第一个月，我给你一个任务：
0预算、全线上、1个月招30个会计合伙人。

你会怎么做？具体说说每一步。"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| "扫楼"/"打电话"/"买名单" | ❌ 线下思维 | **一票否决，直接结束** |
| "加群/混社群/发朋友圈" | ✅ 线上思维 | 10分 |
| 能说出具体步骤+量化目标 | 🥇 有操盘经验 | 20分 |

**满分回答示例：**

```
"我会：
1. 第一周：找10个会计群、代账群，潜伏观察
2. 第二周：在群里输出价值（回答问题、分享资料），建立人设
3. 第三周：私信活跃的会计，送钩子（票据黑名单/工具）
4. 第四周：转化有意向的进合伙人群

目标：每天加10人，30天300人，转化率10%=30个合伙人"
```

---

#### 2.1.5 转化力场景测试（3分钟）

**问题：**

```
"假设我用AI写了一篇'票据避坑'文章，发在朋友圈。
有50个人点赞，其中5个是会计。

接下来你会做什么？说说具体步骤。"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| "分析内容为什么火" | ❌ 小编思维 | 0分 |
| "回复谢谢大家" | ❌ 无效社交 | 0分 |
| "私信问需求" | ⚠️ 方向对但生硬 | 5分 |
| "背调→送钩子→顺势转化" | ✅ 转化思维 | 15分 |

**满分回答示例：**

```
"我会：
1. 先看这5个会计的朋友圈，判断是否活跃在行业里
2. 私信送钩子：'李会计，我有份票据黑名单，发给你避雷？'
3. 通过后聊两句，顺势邀请进合伙人群"
```

---

#### 2.1.6 反向测试-挑刺（3分钟）

**问题：**

```
"最后一个问题：
如果你是客户，你觉得这个业务说明里，
有哪3个地方你可能看不懂或不买账？为什么？"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| "我觉得挺好的，没问题" | ❌ 没有思考能力 | 0分 |
| 能指出1-2个表面问题 | ⚠️ 一般 | 5分 |
| 能指出3个以上有价值的问题 | ✅ 有客户思维 | 10分 |

---

### 2.2 行为面试（20分钟）

#### 2.2.0 商业逻辑测试（5分钟）⭐高潜人才筛选器

**问题：商业敏感度考察**

```
"在开始之前，我想先了解一个能力：

请用最通俗的语言，像教我一样，讲清楚你上一家公司的商业模式：
- 它赚谁的钱？
- 核心利润来源是什么？
- 你在其中起到了什么价值？"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| 完全说不清商业模式，或说"我不清楚" | ❌ 商业敏感度低 | 0分 |
| 能说出大概，但逻辑混乱 | ⚠️ 一般 | 5分 |
| 能清晰说出"赚谁的钱、怎么赚、成本在哪" | ✅ 有商业思维 | 15分 |
| 能说出自己在其中的价值，且有数据支撑 | 🥇 顶级人才 | 20分 |

**观察要点：**

- [ ] 是否能说清楚前公司的盈利模式？
- [ ] 是否理解"成本-收入-利润"的逻辑？
- [ ] 是否能说出自己在商业模式中的位置？

**设计目的：**

S2b2c模式很复杂，如果他连前公司"赚谁的钱、怎么赚的、成本在哪"都说不清，他绝对理解不了我们的模式，更不可能去赋能合伙人。

---

#### 2.2.1 执行力考察（8分钟）

**问题1：过往执行力案例**

```
"能讲一个你印象最深的任务吗？
从接到任务到完成，你是怎么做的？"
```

**追问：**

- 遇到什么困难？
- 怎么解决的？
- 完成时间和预期有差距吗？

**评分标准：**

- 优秀：说得出完整流程，有具体方法，遇到问题会主动想办法
- 及格：能说出大概过程，但不够细致
- 不及格：说不出具体案例，或全程被动等指示

---

**问题2：假设任务测试**

```
"如果明天让你用5个微信号测试我们的8个业务，你会怎么做？"
```

**观察要点：**

- [ ] 是否能说出一个基本计划（准备-测试-记录-复盘）
- [ ] 还是说"我需要先培训"（被动等待）
- [ ] 有没有问关键问题（目标是什么？测试对象是谁？）

---

#### 2.2.2 学习力与AI敏感度考察（7分钟）

**问题3：AI工具使用**

```
"你会用AI工具吗？用过哪些？能举个实际应用的例子吗？"
```

**评分标准：**

- 优秀：会用，能举出实际案例（写文案、做方案、分析数据）
- 及格：听说过，简单用过
- 不及格：不会也不想学

---

**问题4：快速学习能力**

```
"如果让你1周内学会企业微信的高级功能，你会怎么学？"
```

**观察要点：**

- [ ] 是否有学习路径（官方文档/教程/实践）
- [ ] 还是说"问同事"或"边用边学"（没有主动性）

---

#### 2.2.3 逻辑估算测试（5分钟）⭐费米问题（三湘化版本）

**问题：业务相关性估算**

```
"考你一个推算题，不需要准确数据，重点看你的推理过程：

你觉得长沙市大概有多少家'代理记账公司'？

请说出你的推算逻辑。"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| "我不知道"或"没概念" | ❌ 缺乏市场感知 | 0分 |
| 能说出一个数字，但无推理过程 | ⚠️ 一般 | 5分 |
| 有推理过程，但逻辑不够严谨 | ✅ 有逻辑思维 | 10分 |
| 能从多个维度推理（人口→企业数→代账需求→代账公司数） | 🥇 顶级人才 | 15分 |

**满分回答示例：**

```
"我的推理过程：
1. 长沙人口约800万，按家庭算约200万户
2. 假设10%是中小企业主，约20万家
3. 假设50%需要代账服务，约10万家
4. 平均1家代账公司服务100-200家企业
5. 推算：10万÷150≈600-700家代账公司"
```

**观察要点：**

- [ ] 是否有推理过程？
- [ ] 推理逻辑是否合理？
- [ ] 是否对B端市场有概念？

**设计目的：**

不仅考了逻辑推理能力（费米问题），还顺便考了行业认知（他对B端市场有没有概念）。如果他能说出"长沙几百万人口，多少中小企业，平均多少家企业用一个代账..."，这就是顶级人才。

---

### 🚨 关卡提示

**如果候选人在此环节出现以下情况，直接结束面试：**

- 岗位定位测试回答"找企业客户"（一票否决）
- 冷启动测试回答"扫楼/打电话"（线下思维，不匹配）
- 对AI完全排斥、明确不想学（岗位大量用AI）

**结束话术：**

```
"感谢你今天过来，经过刚才的测试，我们发现这个岗位可能不太匹配你的能力模型。
我们会在一周内给你反馈。"
```

## 第三部分：亮底牌与吸引（15分钟）⭐仅针对通过筛选者

> **目标：对通过筛选的候选人，展示公司优势，促成成交**

### 引导话术

```
"刚才听了你的思路，觉得很契合。为了表示诚意，我给你透个底，画一下我们真正的商业版图。

这个岗位，不是让你来'打工'的，是让你来'操盘'的。"
```

---

### 第一层：讲模式（3分钟）

**边说边在白纸上画图：**

```
        [ 老板 (我) ]

      ⚡️ 核心壁垒供给 ⚡️

   ┌──────────────────────┐
   │ 1. 资金/风控 (旧世界)  │
   │ 2. AI内容工厂 (新世界) │
   └──────────────────────┘
              │
              ▼ (输送子弹)
        [ 运营 (你) ]
        👉 你的战场
   ┌──────────────────────┐
   │   分发 / 赋能 / 管理   │
   └──────────────────────┘
              │
              ▼ (指挥打仗)
     [ 合伙人 (会计/中介) ]
        🐜 蚂蚁雄兵
   ┌──────────────────────┐
   │  自带资源 / 精准获客   │
   └──────────────────────┘
```

**话术：**

```
"首先，你要明白，我们不是传统贷款中介，天天打骚扰电话那种。

我们的模式是这样的：（边说边画图）

- 老板（我）负责造子弹——用AI生产内容、话术、工具
- 运营（你）负责指挥打仗——分发弹药、督战、赋能
- 合伙人（会计/中介）负责精准狙击——他们自带企业资源

【好消息】
我们已经有20+合作者在跑业务了，只是之前是'游击队'状态。
你来，是把游击队变成正规军，再从20扩展到100+。"
```

---

### 第二层：讲门槛 + 亮底牌（5分钟）⭐关键

**话术：**

```
"你可能担心：'我不懂票据，不懂财税，能干吗？'

完全不用担心。在这个模型里，我负责给你提供两样核武器。

【第一是'钱'】
我在这个行业摸爬滚打十几年了。
不吹牛地说，如果客户今天急需1000万、2000万的过桥资金，
我打两个电话，资金当天就能到位。
后端团队很多是我的徒弟或者深度合作伙伴，绝对不会掉链子。
你只管让合伙人去冲，后端的资金和风控，我兜底。

【第二是'内容'】
我这几年一直在钻研AI，自己用AI写过论文、产出了几十篇深度文章。
在这个公司，AI不是虚的概念，是我已经跑通的生产力。
以前运营要自己写文案、做海报，现在我们有AI内容工厂。
你输入'今天推贴现业务'，AI自动出10条文案。
你只需要做'搬运工'，把子弹发给合伙人。

所以，前期靠执行力，不靠专业力。AI就是你的超级外挂。"
```

---

### 第三层：讲利益（3分钟）

**话术：**

```
"最后说最实际的，你怎么赚钱？

我们设计了两条路：

【保底路】A业务（贴现）
- 这个业务我们战略性让利给合伙人，用来圈人
- 你拿底薪 + 管理绩效，旱涝保收

【发财路】B-H业务（省钱方案、资产隔离等）
- 这些业务需要你介入，帮合伙人谈大单
- 利润厚，大头给运营团队
- 一单B业务可能顶10单A业务

简单说：
A业务养渠道，B-H业务养你。
前期靠底薪活得好，后期懂业务了，月入2万+不是问题。"
```

---

### 收尾确认

```
"这就是我们的模式。你有什么想问的吗？"
```

### 👀 观察候选人的3个时机

| 时机 | 观察什么 | 好信号 | 坏信号 |
|------|---------|--------|--------|
| 说"不打电话、不跑外勤" | 是否松口气 | 明显放松 | 无反应或失望 |
| 说"AI帮你写文案" | 是否好奇 | 追问细节 | 排斥或不信 |
| 说"后期做大单分大钱" | 是否有野心 | 眼睛发亮 | 只关心底薪 |

## 第四部分：候选人提问+薪资沟通（15分钟）

### 4.1 候选人提问

```
"你还有什么想问的吗？"
```

**观察要点：**

- 问题质量（打工者思维 vs 操盘手思维）
- 是否关心成长和发展空间
- 是否关心业务逻辑

---

### 4.2 驱动力深挖（5分钟）⭐价值观与长期主义测试

**问题：欲望与驱动力测试**

```
"最后，我想了解你的驱动力：

回顾过去的工作，哪一个瞬间让你觉得最有成就感？为什么？

又是什么原因让你决定离开上一家公司？

你希望3年后的自己是什么状态？"
```

**评分标准：**

| 回答 | 判断 | 评分 |
|------|------|------|
| 成就感来自"按时下班"或"老板夸奖" | ❌ 打工者心态 | 0分 |
| 成就感来自"搞定难搞的客户"或"看着数据上涨" | ✅ 操盘手思维 | 10分 |
| 能说出具体案例，且有量化结果 | 🥇 顶级人才 | 15分 |
| 3年规划清晰，且有实现路径 | ✅ 长期主义者 | +5分 |

**观察要点：**

- [ ] 成就感来源是什么？（做事 vs 做人）
- [ ] 离开原因是什么？（逃避 vs 追求）
- [ ] 3年规划是否清晰？（有目标 vs 走一步看一步）

**设计目的：**

通过成就感来源判断他是"做题家"还是"操盘手"。如果他的成就感来自"搞定了一个难搞的客户"或"看着数据上涨"，这是我们要的人。如果来自"按时下班"或"老板夸奖"，那就是打工心态。

### 4.3 薪资沟通

```
"关于薪资，我们的范围是10-15K底薪，根据你的经验和能力定薪。
试用期3个月，试用期工资是转正工资的80%。
另外有渠道绩效奖金，上不封顶。

你期望的薪资是多少？什么时候能到岗？"
```

| 情况 | 判断 | 出现时机 |
|------|------|---------|
| 岗位定位测试回答"找企业客户" | 没理解岗位本质 | 第一部分或第二部分 |
