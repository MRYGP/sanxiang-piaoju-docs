## 🔄 招聘流程

### 第一步：发布职位

1. 打开BOSS直聘
2. 复制 [`【最终版】JD`](../【最终版】业务运营专员-BOSS直聘JD.md) 的"职位详情"部分
3. 按JD中的"使用说明"设置职位信息
4. 发布

---

### 第二步：筛选简历（3分钟判断法）

**必备项**（没有直接淘汰）：
- ✅ 1年以上销售/运营经验
- ✅ 长沙本地或愿意来
- ✅ 简历清晰有条理

**优先约面试**：
- ⭐ ToB销售/渠道/社群经验
- ⭐ 用过AI工具
- ⭐ 有创业公司经历

**谨慎考虑**：
- ⚠️ 频繁跳槽（1年3份以上）
- ⚠️ 明确只想稳定

---

### 第三步：约面试

使用JD中的"约面试话术"（30秒电梯版）

---

### 第四步：面试

**时长**：60-75分钟

**流程**：参考 [`面试提纲-运营专员-含反向测试.md`](./面试提纲-运营专员-含反向测试.md)

**打分**：使用 [`面试评分表-运营专员.md`](../面试评分表-运营专员.md)

**决策标准**：
- 140分以上 → 当天/次日发offer
- 120-139分 → 1-2天内决定
- 100-119分 → 再面试或试用
- 100分以下 → 不录用

---

### 第五步：发Offer

**话术**：
```
你好，关于运营专员岗位，我们决定录用你。

你的[具体优点]很符合我们的要求。

Offer：
- 底薪：XX元/月
- 试用期：3个月，工资80%-90%
- 入职时间：建议XX月XX日

有问题随时问我。
```

---

### 第六步：入职准备

**发给候选人**：
```
【入职准备清单】
1. 身份证原件及复印件2份
2. 学历证书原件及复印件1份
3. 离职证明（如有）
4. 银行卡号
5. 1寸照片2张

入职当天：
- 9:00 签合同
- 10:00 领设备
- 10:30 开始培训
```

## 📌 常见问题

**Q：候选人要求更高薪资？**
A：说明薪资范围8-12K，表现好3个月后可调整

**Q：候选人问加班？**
A：前1-2个月跑通模式会忙，后面正常。创业公司节奏，想稳定的不适合

**Q：候选人犹豫？**
A：给2-3天考虑，了解具体顾虑，针对性解决
