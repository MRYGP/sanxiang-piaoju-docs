#### 1.3 约面试话术

**微信/电话沟通模板：**

```
你好，看到你的简历很符合我们的要求。

我们是做企业财务服务的，现在需要一个运营来帮我们测试业务、管理业务员。

具体就是：
1. 用几个企业微信号测试我们的业务，看客户反应
2. 招募兼职业务员，培训他们
3. 整理有效的推广方法

工作强度前1个月会比较大，因为要快速跑通模式。
但后面就轻松了，主要是管理和优化。

薪资是8-12K底薪，另外有提成和奖金。
你之前的工作经验很适合，有兴趣了解一下吗？

如果感兴趣，我们可以约个时间见面详聊。
你明天/后天哪个时间方便？
```

**候选人常见问题及回答：**

Q："你们公司规模多大？"
A："我们是创业公司，目前核心团队3人，正在搭建兼职网络。适合想在创业公司从0到1做事的人。"

Q："为什么要招运营？"
A："我们要测试8个业务线，需要有人专门负责测试、收集反馈、优化话术，形成可复制的SOP。"

Q："试用期多久？薪资怎么算？"
A："试用期3个月，试用期工资80%-90%。转正后8-12K底薪，另外有渠道绩效奖金和完成奖金。"

Q："需要加班吗？"
A："前1个月会比较忙，因为要快速跑通模式。后面就是正常工作时间，偶尔有紧急情况需要加班。"

### 第二步：筛选简历

#### 2.1 简历筛选清单

**必备项（没有直接淘汰）：**
- ✅ 有1年以上销售或运营经验
- ✅ 年龄在25-35岁
- ✅ 长沙本地或愿意来长沙
- ✅ 简历清晰有条理（反映逻辑能力）

**加分项（有更好）：**
- ⭐ 有to B销售经验
- ⭐ 有社群运营经验
- ⭐ 用过企业微信
- ⭐ 有创业公司工作经验
- ⭐ 会用AI工具（ChatGPT/Claude）

**减分项（需要谨慎）：**
- ⚠️ 工作经历频繁跳槽（1年换3份工作）
- ⚠️ 简历夸大或造假
- ⚠️ 要求薪资明显超出预算（>15K）
- ⚠️ 对创业公司有明显抵触（要求稳定）

#### 2.2 快速筛选方法（3分钟判断法）

**第1分钟：看工作经历**
- 有没有销售/运营经验？
- 有没有to B销售经验？
- 工作经历是否稳定？

**第2分钟：看能力匹配度**
- 会不会用企业微信？
- 有没有社群运营经验？
- 会不会总结复盘？

**第3分钟：看动机和态度**
- 为什么想换工作？（离职原因）
- 为什么想来创业公司？（求职动机）
- 简历是否用心准备？（细节体现态度）

**判断结果：**
- 必备项都有 + 2个以上加分项 → 约面试
- 必备项都有 + 没有减分项 → 可以约面试
- 有明显减分项 → 不约面试

#### 3.2 面试流程建议（总时长：约1小时）

**9:00-9:05（5分钟）：自我介绍**
- 让候选人自我介绍（姓名、工作经历、离职原因）
- 观察表达能力和逻辑性

**9:05-9:10（5分钟）：公司和岗位介绍**
- 简要介绍公司和业务
- 说明岗位职责和期望
- 回答候选人疑问

**9:10-9:40（30分钟）：核心能力提问**
- 按照评分表的问题逐一提问
- 记录候选人回答
- 观察应变能力

**9:40-9:50（10分钟）：候选人提问**
- 让候选人提问
- 观察候选人关心什么（薪资/发展/工作内容）
- 真诚回答，不夸大

**9:50-9:55（5分钟）：填写评分表**
- 现场填写评分表
- 计算总分
- 初步判断是否录用

**9:55-10:00（5分钟）：告知下一步**
- 告知候选人：1-2天内给答复
- 如果非常满意，可以当场表达意向
- 礼貌送别

**调查内容：**

   - 离职原因是否属实
   - 工作表现如何

   - 了解候选人的工作能力
   - 了解候选人的性格特点
   - 了解候选人的优缺点

**注意事项：**
- 提前告知候选人要做背景调查
- 征得候选人同意
- 保护候选人隐私

## 通用招聘技巧

### 一、面试前准备

**运营专员：**
1. 打印面试评分表
2. 准备企业微信（让候选人现场演示）
3. 准备公司介绍PPT或文档
4. 准备2-3个业务案例（用于测试理解能力）

**实习生：**
1. 打印面试评分表
2. 准备好手机或电脑（让候选人演示AI工具）
3. 准备1-2个实际场景（测试候选人能否用AI解决）
4. 准备公司介绍和岗位说明

---

### 二、面试中注意事项

**1. 营造轻松氛围**
- 面试开始前寒暄几句，让候选人放松
- 微笑，保持友好态度
- 不要打断候选人说话

**2. 观察细节**
- 着装是否得体（反映重视程度）
- 是否准时到达（反映时间观念）
- 手机是否静音（反映细节意识）
- 回答问题时是否看着你（反映自信和尊重）

**3. 问开放式问题**
- 不要问"是不是""会不会"这种封闭式问题
- 多问"怎么做""为什么""能举个例子吗"
- 让候选人多说，你多听

**4. 做好记录**
- 重要的回答要记下来
- 填写评分表，不要凭印象打分
- 记录候选人的亮点和疑虑点

**5. 给候选人提问机会**
- 候选人的问题能反映他关心什么
- 关心薪资福利 → 务实
- 关心发展空间 → 有追求
- 关心工作内容 → 专业
- 不提问 → 可能不太感兴趣

---

### 三、面试后处理

**1. 当天完成评分和决策**

**运营专员：**
- 90分以上：当天或次日发offer
- 75-89分：1-2天内决定
- 60-74分：再面试一次或不录用
- 60分以下：礼貌拒绝

**实习生：**
- 90分以上：当天发offer，给4000元
- 75-89分：次日发offer，给3500元
- 60-74分：试用1周，给3000元
- 60分以下：礼貌拒绝

---

**2. 及时给候选人反馈**

**录用话术：**
```
你好，关于[岗位]的岗位，我们决定录用你。
你的[具体优点]很符合我们的要求。
我们会尽快发送offer，请查收。
有任何问题随时联系我。
```

**不录用话术：**
```
你好，感谢你来面试。
经过综合考虑，我们暂时不能录用你。
主要原因是[委婉说明，如：我们需要更多销售经验的候选人]。
感谢你的时间，祝你找到更合适的工作。
```

---

**3. 保存所有面试记录**
- 保存面试评分表
- 保存候选人简历
- 保存面试笔记
- 便于后续对比和复盘

---

### 四、常见问题处理

**Q1：候选人要求更高薪资怎么办？**

**A：**
```
我理解你的期望。
我们目前的薪资范围是XX-XX，你的能力我们评估在XX档。
如果你能在前3个月证明你的能力（比如达到XX目标），我们可以调整薪资。
或者，我们可以在试用期结束后重新评估。
你觉得这样可以接受吗？
```

---

**Q2：候选人问公司未来发展怎么办？**

**A：**
```
我们是创业公司，目标是用3年时间成为长沙最大的企业财务服务平台。
目前我们有8个业务线，正在快速验证和扩张。
如果你加入，你会参与从0到1的过程，这个经验很宝贵。
当然，创业公司也有风险，需要你有创业心态。
```

---

**Q3：候选人问加班情况怎么办？**

**A：**
```
我们是创业公司，工作节奏会比较快。
工作时间是早九晚六，单休（周日休息）。
前1-3个月业务测试期会比较忙，可能需要晚上处理一些事情。
但我们更看重效率，不是看你坐在那里多久。

创业公司就是这样，想赚钱、想成事，就得拼。
如果你想找朝九晚五的稳定工作，可能不太适合我们。
但如果你想在创业公司快速成长、赚到钱，这里是个好机会。
```

## 总结

**招聘核心原则：**
1. **快速行动**：看到合适的候选人，立即约面试，面试后1-2天内决定
2. **标准化**：用统一的评分表，确保公平公正
3. **真诚沟通**：不夸大，不隐瞒，展示真实的工作场景
4. **关注匹配度**：不要只看能力，更要看价值观和动机是否匹配
5. **给成长空间**：创业公司最大的吸引力是成长机会，要充分展示

**避免的坑：**
1. ❌ 拖延决策，错过优秀候选人
2. ❌ 只看简历，不看实际能力
3. ❌ 夸大公司实力，入职后落差大
4. ❌ 只关注能力，不关注价值观
5. ❌ 面试后不给反馈，影响公司口碑

**持续优化：**
1. 记录每次招聘的数据（简历量/面试量/录用率）
2. 复盘成功和失败的案例
3. 优化JD和面试流程
4. 建立候选人库（优秀但暂时没录用的，可以后续联系）
