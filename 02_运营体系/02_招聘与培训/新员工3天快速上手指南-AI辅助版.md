# 新员工3天快速上手指南 - AI辅助版

**文档类型**：培训
 **适用对象**：运营专员 + 实习生
 **创建日期**：2025-11-20
 **培训时长**：6小时（分3天完成）
 **核心理念**：教会使用Claude，而不是背知识
 **版本**：v1.0

------

## 🎯 培训目标

**传统培训（16小时）**：

```
死记硬背8个业务 → 记住所有话术 → 考试 → 上岗后还是不会
```

**AI辅助培训（6小时）**：

```
学会用Claude → Claude实时指导 → 边做边学 → 快速上手
```

**核心差异**：

- ❌ 不要求背知识（Claude就是知识库）
- ✅ 只要求会用Claude（遇到问题立即解决）
- ❌ 不要求一次学完（边做边学）
- ✅ 只要求敢于提问（没有笨问题）

------

## 📅 3天培训计划

### 第1天：认识Claude，学会提问（2小时）

**上午**（1小时）：

**9:00-9:30 公司和业务介绍**

- 老板讲解：我们是做什么的？
- 商业模式简介
- 8个业务一句话总结

**9:30-10:00 认识你的AI助手Claude**

- Claude是什么？（你的工作伙伴）
- Claude能帮你做什么？（10个典型场景）
- 为什么要用Claude？（降低学习成本80%）

------

**下午**（1小时）：

**14:00-14:30 第一次使用Claude**

**实操演练1：表明身份**

```
打开Claude Projects
在对话框输入：
- 运营：工号002
- 实习生：工号003

验证：Claude是否切换到对应模式
```

**实操演练2：搜索文档**

```
练习问题：
"A业务是什么？"
"帮我找B业务的详细说明"
"展业话术在哪个文档？"

验证：能否找到正确答案
```

**实操演练3：生成内容**

```
练习任务：
"帮我生成一条A业务的朋友圈文案"
"客户说太贵了，怎么回答？"
"我需要B业务的开场白话术"

验证：生成的内容是否可用
```

**14:30-15:00 练习提问技巧**

**好问题 vs 坏问题**：

❌ **坏问题**（Claude很难回答）：

- "怎么办？"
- "给我个建议"
- "这个对吗？"

✅ **好问题**（Claude能给出具体答案）：

- "客户说XX，我该怎么回答？"
- "帮我生成一条XXX的朋友圈文案"
- "我写的这段话有没有合规问题？"

**练习**： 把以下"坏问题"改成"好问题"：

1. "客户不买，怎么办？"
2. "给我点建议"
3. "我做得对吗？"

------

**第1天作业**： 用Claude回答10个问题，每个问题都要得到可用的答案。

**作业清单**：

1. A业务是什么？
2. B业务适合什么客户？
3. 生成一条G业务朋友圈文案
4. 客户问"安全吗"，怎么回答？
5. 如何识别客户需求？
6. 展业话术在哪里找？
7. 什么是合规禁用词？
8. 如何使用企业微信打标签？
9. 如何记录客户反馈？
10. 明天我要做什么？

**验收标准**：10个问题都得到可用答案 → 通过✅

------

### 第2天：在Claude辅助下完成真实任务（2小时）

**上午**（1小时）：

**9:00-9:30 任务1：生成朋友圈内容**

**目标**：用Claude生成3条朋友圈文案

**步骤**：

```
Step 1：告诉Claude需求
"工号00X，帮我生成一条A业务的朋友圈文案，重点是快速变现"

Step 2：检查生成内容
- 有没有合规问题？
- 语言是否通顺？
- 是否符合需求？

Step 3：微调优化
"这个文案太长了，帮我精简到100字"
"把这个改成更口语化的表达"

Step 4：保存使用
复制到文档，标注用途
```

**练习**： 生成3条朋友圈文案：

- A业务（票据贴现）
- B业务（承兑付款）
- G业务（专利实缴）

**验收标准**：3条文案符合合规要求 → 通过✅

------

**9:30-10:00 任务2：模拟客户对话**

**目标**：用Claude辅助完成一次客户对话

**情景设定**：

```
客户："你们是做什么的？"

你的操作：
1. 在Claude中输入："工号00X，客户问我们是做什么的，怎么回答？"
2. Claude给出回答模板
3. 你用自己的话表达给客户
```

**完整对话练习**：

```
客户1："你们是做什么的？"
→ 问Claude，得到答案，回复客户

客户2："我有银票，能帮我变现吗？"
→ 问Claude，得到答案，回复客户

客户3："多久能到账？"
→ 问Claude，得到答案，回复客户

客户4："安全吗？会不会有风险？"
→ 问Claude，得到答案，回复客户

客户5："你们比别家贵0.5个点，为什么？"
→ 问Claude，得到答案，回复客户

客户6："好的，我考虑一下"
→ 问Claude，得到答案，回复客户
```

**验收标准**：6个问题都能用Claude找到合适答案 → 通过✅

------

**下午**（1小时）：

**14:00-14:30 任务3：检查工作成果**

**目标**：学会用Claude检查自己的工作

**练习**：

```
你写了一条朋友圈文案：
"老板们！用我们的承兑服务，保证10分钟到账，年化收益3%，零风险！"

把这段话发给Claude：
"工号00X，我写了这段朋友圈文案，帮我检查有没有问题：[文案]"

Claude会指出问题：
- "保证10分钟到账" → 违规
- "年化收益3%" → 错误理解业务
- "零风险" → 违规

然后修改，再让Claude检查，直到合格
```

**验收标准**：能识别并修复合规问题 → 通过✅

------

**14:30-15:00 任务4：记录工作**

**目标**：学会用Claude整理工作记录

**步骤**：

```
Step 1：告诉Claude今天做了什么
"工号00X，我今天完成了：
- 生成了3条朋友圈文案
- 模拟对话练习了6个问题
- 学会了检查合规问题

帮我整理成工作日志"

Step 2：Claude生成格式化的工作日志

Step 3：保存到进度追踪器
```

**验收标准**：能用Claude生成清晰的工作记录 → 通过✅

**第2天作业**： 独立完成3个真实任务（可以用Claude辅助）：

1. 给一个真实客户发朋友圈

### 第3天：综合实战+考核（2小时）

**上午**（1小时）：

**9:00-9:30 综合实战1：完整的客户接待流程**

**任务**： 在Claude辅助下，完成一个客户从接触到成交的完整流程

**流程**：

```
Step 1：客户来源识别
客户说："朋友推荐的，说你们能帮企业解决资金问题？"
→ 问Claude：这是什么场景？我应该问什么？

Step 2：需求挖掘
→ 问Claude：如何了解客户具体需求？

Step 3：方案推荐
客户说："我们有300万银票，想变现"
→ 问Claude：这个客户需要什么业务？话术怎么说？

Step 4：异议处理
客户说："你们比别家贵"
→ 问Claude：怎么回答？

Step 5：推进成交
→ 问Claude：如何推进客户下单？

Step 6：记录跟进
→ 问Claude：帮我记录这个客户的情况
```

**验收标准**：能在Claude辅助下完成完整流程 → 通过✅

------

**9:30-10:00 综合实战2：多任务处理**

**任务**： 同时处理3个不同的任务，学会管理优先级

**场景**：

```
任务1：客户A在等你回复（紧急）
任务2：老板让你写一份工作总结（今天下班前）
任务3：有个新兼职要培训（可以明天）

你会怎么处理？
```

**步骤**：

```
Step 1：问Claude
"工号00X，我手上有3个任务：
- 任务1：客户等回复（紧急）
- 任务2：工作总结（今天下班前）
- 任务3：培训新兼职（明天也行）

应该怎么安排优先级？"

Step 2：按Claude的建议执行

Step 3：用Claude辅助完成每个任务
```

**验收标准**：能合理安排优先级并完成 → 通过✅

------

**下午**（1小时）：

**14:00-14:30 最终考核（实操）**

**考核方式**： 导师/老板模拟客户，你在Claude辅助下完成对话

**考核场景**：

```
场景1：客户询问业务
"你们能做什么？"

"我有票要变现" 或 "我要付款找便宜方式"

"好的，怎么操作？"
```

**考核标准**：

- 能用Claude找到合适答案：✅

- 应对自然流畅：✅
- 客户体验良好：✅

4项都达标 → 通过✅

欢迎加入三湘票据！

你可能会担心："我完全不懂业务，能行吗？"

答案是：**完全可以！**

在我们这里：

- 不需要你一开始就懂所有业务
- 不需要你背大量知识
- 不需要你独自解决所有问题

你需要的是：

- 执行力：交代的事能完成
- 学习力：遇到问题会问Claude
- 沟通力：和客户/同事友好沟通

有Claude帮你，你比传统培训的员工：

- 学得更快（3天 vs 5天）
- 质量更高（有AI把关）
- 压力更小（不用背知识）

**记住**：Claude是工具，不是魔法。 它能帮你快速上手，但不能替代你的思考和执行。

最强的组合是：**你的能力 + Claude的支持**

一起加油！💪

### 给培训导师的话

这份培训计划的核心是：**教会用工具，而不是灌输知识**

**传统培训的问题**：

- 16小时培训，员工记不住
- 大量知识，实际用不上
- 考试通过，上岗还是不会

**AI辅助培训的优势**：

- 6小时培训，只教核心
- 知识在Claude里，随时查
- 边做边学，快速上手

**培训师的角色转变**：

- 从"知识传授者" → "工具教练"
- 从"教业务" → "教如何用Claude学业务"
- 从"考记忆" → "考实操"

**注意事项**：

1. 不要急于灌输知识，让新人先会用Claude
2. 多给实操机会，少讲理论
3. 鼓励提问，没有笨问题
4. 允许犯错，从错误中学习

**验收标准**：

- 不是"记住了多少"
- 而是"会不会用Claude解决问题"

这是一个新的培训模式，我们一起探索和优化！
