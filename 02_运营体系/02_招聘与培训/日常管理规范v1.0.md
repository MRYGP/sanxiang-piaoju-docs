## 运营专员日常管理

### 日常工作SOP

#### 每日标准工作流程

**早上（9:00-12:00）**

**09:00-09:15 启动Claude，加载记忆**
```
标准操作：
1. 打开Claude Projects
2. 输入"工号002"
3. Claude自动加载进度追踪器
4. 查看今日待办任务
```

**09:15-09:30 查看和回复客户消息**
```
检查清单：
□ 5个企业微信号，是否有客户留言？
□ 紧急问题优先处理（客户催单、投诉）
□ 常规问题用Claude辅助回复
□ 记录重要信息到进度追踪器
```

**09:30-11:00 执行今日主要任务**

**任务类型1：业务测试**
```
标准流程：
1. 用Claude生成朋友圈文案
2. 每个微信号发1条朋友圈
3. 私聊2-3个目标客户
4. 记录客户反馈（用Claude整理）
```

**任务类型2：业务员管理**
```
标准流程：
1. 检查业务群，有无业务员提问
2. 用Claude辅助回答问题
3. 鼓励业务员（发激励消息）
4. 统计业务员报备的线索
```

**任务类型3：客户跟进**
```
标准流程：
1. 用Claude查看进度追踪器，找出待跟进客户
2. 按优先级跟进（成交意向高 → 意向中 → 意向低）
3. 用Claude准备跟进话术
4. 记录跟进结果
```

**11:00-12:00 整理上午工作**
```
用Claude整理：
"工号002，帮我整理上午工作：
- 回复了X个客户
- 发了X条朋友圈
- 跟进了X个客户
- 业务员报备了X条线索

遇到的问题：XXX
下午要做：XXX"
```

---

**中午（12:00-14:00）**

**12:00-14:00 午休**
- 吃饭休息
- 可以刷朋友圈，看客户动态
- 如有紧急情况，及时回复

**下午（14:00-18:00）**

**14:00-16:00 执行下午主要任务**

**任务类型1：制作素材**
```
标准流程：
1. 用Claude生成文案/话术
2. 检查合规性（用Claude）
3. 保存到素材库
4. 分享给业务员
```

**任务类型2：数据整理**
```
标准流程：
1. 整理今日测试数据
2. 用Claude生成《每日测试报告》
3. 分析哪些话术有效
4. 优化话术库
```

**任务类型3：培训业务员**
```
标准流程：
1. 准备培训内容（用Claude）
2. 在群里或一对一培训
3. 解答业务员疑问
4. 收集反馈优化培训
```

**16:00-17:30 处理临时任务**
```
可能的临时任务：
- 老板安排的紧急任务
- 客户临时咨询
- 业务员求助
- 后端协调

处理原则：
- 紧急重要：立即处理
- 紧急不重要：快速处理或委托
- 不紧急重要：安排到明天
- 不紧急不重要：暂缓或不做
```

### 问题升级机制

#### 自己能解决的问题（直接处理）

**类型1：常规客户咨询**
```
问题：客户问业务相关问题
处理：用Claude找答案，回复客户
标准：答案准确、符合合规要求
```

**类型2：简单话术生成**
```
问题：需要生成朋友圈/话术
处理：用Claude生成，自己检查
标准：内容合规、符合定位
```

**类型3：日常数据整理**
```
问题：需要整理测试数据
处理：用Claude整理，自己验证
标准：数据准确、分析合理
```

---

#### 需要问Claude的问题（AI辅助）

**类型1：复杂客户需求**
```
问题：客户需求复杂，不确定用什么业务
处理：向Claude详细描述客户情况，获取建议
标准："工号002，客户情况是XXX，应该推荐什么业务？"
```

**类型2：话术优化**
```
问题：当前话术效果不好
处理：用Claude分析和优化
标准："工号002，这个话术XXX效果不好，帮我优化"
```

**类型3：流程优化**
```
问题：某个流程不顺畅
处理：用Claude设计优化方案
标准："工号002，XXX流程有问题，帮我优化"
```

---

#### 需要问老板的问题（向上升级）

**类型1：重大决策**
```
问题：涉及公司战略、资源投入
处理：向老板汇报，征求意见
标准：准备好背景、方案、建议
```

**类型2：客户投诉**
```
问题：客户投诉、不满
处理：立即告知老板，共同处理
标准：客观描述问题，不推卸责任
```

**类型3：合规风险**
```
问题：发现合规风险（话术/流程）
处理：立即告知老板，暂停执行
标准：说明风险点，提出替代方案
```

**类型4：资源需求**
```
问题：需要额外资源支持
处理：向老板申请
标准：说明为什么需要，预期效果
```

**类型5：重要客户**
```
问题：大客户、复杂项目
处理：及时向老板汇报
标准：提供客户背景、需求、建议方案
```

## 通用质量评估体系

### 运营专员质量评估

#### 月度考核表（满分100分）

**一、业务能力（40分）**

**1. 业务熟悉度（10分）**
- 10分：能清楚解释8个业务，能根据客户需求推荐合适业务
- 7分：能解释8个业务，但推荐不够精准
- 4分：只熟悉部分业务
- 0分：业务不熟悉

**评估方式**：
- 随机抽查3个客户对话
- 看是否能准确判断客户需求
- 看是否能推荐合适的业务

---

**2. 客户沟通能力（15分）**
- 15分：沟通专业、回复及时、客户满意度高
- 10分：沟通基本专业，偶有延迟
- 5分：沟通不够专业，客户反馈一般
- 0分：沟通有明显问题

**评估方式**：
- 抽查10个客户对话记录
- 看回复是否及时（2小时内）
- 看话术是否专业
- 看是否有客户投诉

## 问题处理机制

### 常见问题及处理方式

#### 问题1：工作拖延

**现象：**
- 任务经常延迟完成
- 总是说"我在做"但没结果
- 到截止日期才说做不完

**处理方式：**

**第1次：**
- 私下谈话，了解原因
- 是能力问题还是态度问题？
- 能力问题：提供帮助和培训
- 态度问题：明确警告

**第2次：**
- 正式警告，记录在案
- 设定明确的改进期限（1-2周）
- 如果再犯，扣除当月奖金

**第3次：**
- 严重警告，考虑辞退
- 或降低职级，减少底薪

---

#### 问题2：质量低下

**现象：**
- 工作成果经常有错误
- 客户投诉多
- 合规问题频发

**处理方式：**

**第1次：**
- 指出具体问题
- 要求重做
- 培训如何用Claude检查质量

**第2次：**
- 扣除当月奖金10%
- 要求每个工作成果都要Claude检查
- 导师/老板抽查

**第3次：**
- 扣除当月奖金20%
- 如果还不改进，考虑辞退

---

#### 问题3：不会用Claude

**现象：**
- 总是问人，不问Claude
- 进度追踪器不更新
- 工作日志质量差

**处理方式：**

**第1次：**
- 重新培训Claude使用
- 要求每天至少用Claude 10次
- 检查进度追踪器更新

**第2次：**
- 考核时"Claude使用能力"打低分
- 影响月度奖金
- 继续培训

**第3次：**
- 如果还不会用，说明学习能力有问题
- 考虑是否适合这个岗位

---

#### 问题4：团队协作差

**现象：**
- 不愿意帮助同事
- 沟通态度不好
- 团队反馈差

**处理方式：**

**第1次：**
- 私下谈话，了解原因
- 强调团队协作的重要性
- 给改进机会

**第2次：**
- 正式警告
- 扣除当月"团队协作"评分
- 影响月度奖金

**第3次：**
- 如果态度还不改，直接辞退
- 创业公司不养"独行侠"

---

#### 问题5：合规问题

**现象：**
- 发布违规内容
- 使用绝对化承诺
- 泄露敏感信息

**处理方式：**

**立即处理：**
- 紧急下架违规内容
- 评估影响范围
- 向老板汇报

**事后处理：**
- 第1次：严重警告，扣当月奖金50%
- 第2次：直接辞退
- 造成损失：追究法律责任

**预防措施：**
- 所有对外内容必须Claude检查
- 重要内容老板审核
- 定期合规培训

---

### 辞退标准

#### 必须辞退（红线）

**1. 合规问题严重**
- 故意发布违规内容
- 泄露公司机密
- 损害公司利益

**2. 欺诈行为**
- 伪造数据
- 虚报工作
- 侵占公司财产

**3. 严重违纪**
- 旷工3天以上
- 严重违反公司制度
- 打架斗殴等

---

#### 可以辞退（综合判断）

**1. 能力不足**
- 培训3个月仍不能胜任
- 月度考核连续3个月<60分
- 工作质量持续低下

**2. 态度问题**
- 多次拖延不改
- 不服从管理
- 团队协作极差

**3. 经济原因**
- 公司业务调整
- 岗位不再需要
- （给补偿）
