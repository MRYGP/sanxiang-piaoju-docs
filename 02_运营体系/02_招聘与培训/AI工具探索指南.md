## 🔍 工具发现方法

### 核心原则

**不是等工具找上门，而是主动去发现**

**关注重点**：
- ✅ 免费/开源工具（优先）
- ✅ 国内少人用的工具（蓝海）
- ✅ 刚发布的新工具（抢先机）
- ✅ GitHub上的开源项目（技术向）

---

### 方法1：GitHub Trending（每天必看）

**网址**：https://github.com/trending

**关注分类**：
- Trending Repositories（今日热门）
- AI/ML相关（人工智能标签）
- Python/JavaScript（常用语言）

**如何筛选**：
1. 看Star数：>100 值得关注，>1000 重点测试
2. 看更新频率：最近1周有更新=活跃项目
3. 看README：是否有Demo/安装教程
4. 看Issue数：<50个=可能不成熟，50-200=合理

**每日流程**：
```
09:00-09:15（15分钟）：
1. 打开GitHub Trending
2. 筛选AI/ML分类
3. 记录3-5个值得关注的项目到工具发现表格
4. 标注优先级（⭐⭐⭐ 立即测试 / ⭐⭐ 本周测试 / ⭐ 关注）
```

---

### 方法2：Product Hunt（发现商业化工具）

**网址**：https://www.producthunt.com/topics/artificial-intelligence

**关注分类**：
- Today's Top（今日热门）
- Artificial Intelligence（AI分类）
- Free（免费工具）

**如何筛选**：
1. 看Upvote数：>100 = 受欢迎
2. 看评论：用户反馈如何
3. 看定价：Free/Freemium优先
4. 看适用场景：是否适合我们业务

**每日流程**：
```
09:15-09:30（15分钟）：
1. 打开Product Hunt AI分类
2. 浏览今日Top 10
3. 记录2-3个免费/Freemium工具
4. 点进去看详细介绍和用户评论
```

## 🧪 工具测试流程

### 测试原则

**不是玩工具，而是评估"能不能用于实际业务"**

**核心问题**：
1. 这个工具解决什么问题？
2. 上手难度如何？
3. 实际效果如何？
4. 成本是多少？
5. 值不值得推荐给团队？

---

### 标准测试流程（4-6小时/工具）

#### Step 1：快速了解（30分钟）

**目标**：判断是否值得深度测试

**操作**：
1. 阅读官网介绍
2. 看用户评价/评论
3. 查看定价
4. 判断是否继续测试

**判断标准**：
- ✅ 符合我们业务需求
- ✅ 免费或成本可接受
- ✅ 有Demo可以试用
- ✅ 文档齐全

如果以上都符合 → 进入Step 2
如果不符合 → 记录原因，放弃测试

---

#### Step 2：安装/注册（30分钟-1小时）

**目标**：成功运行起来

**操作**：
1. 注册账号（如需要）
2. 安装软件（如果是本地工具）
3. 配置环境（如果是开源项目）
4. 完成第一个Hello World测试

**记录要点**：
- 安装难度：简单/中等/困难
- 遇到的问题：XXX
- 解决方案：XXX
- 是否有中文文档：有/无

**如果这一步卡住超过1小时** → 可能不适合推广，记录问题

---

#### Step 3：核心功能测试（2-3小时）

**目标**：测试核心功能是否好用

**测试方法**：做一个实际项目

**示例1：测试AI音频工具**
```
项目：把一段300字文案转成语音

测试步骤：
1. 准备测试文案（从业务文档中选）
2. 使用工具生成音频
3. 听效果（发音准确性/语调自然度/情感表达）
4. 测试不同参数（语速/音色/语言）
5. 导出音频文件

记录：
- 生成速度：XX秒
- 音质评分：X/10分
- 自然度评分：X/10分
- 是否支持中文：是/否
- 免费额度：XXX字符/月
```

**示例2：测试开源数字人项目**
```
项目：用开源项目生成一个30秒数字人视频

测试步骤：
1. 按README安装项目
2. 准备素材（文案+音频+人物图片）
3. 运行生成脚本
4. 检查生成效果
5. 对比付费工具（D-ID/HeyGen）

记录：
- 安装难度：X/10分
- 生成时间：XX分钟
- 视频质量：X/10分
- 对比D-ID：优势XXX / 劣势XXX
- 是否值得推荐：是/否
```

---

#### Step 4：成本评估（30分钟）

**目标**：算清楚用这个工具要花多少钱

**评估维度**：

**1. 直接成本**
```
- 订阅费：¥XXX/月
- 按量计费：¥XXX/次 或 ¥XXX/分钟
- 免费额度：XXX/月

月度成本预估（假设每月制作30个内容）：
- 方案A（全用免费额度）：¥0
- 方案B（免费+付费）：¥XXX
- 方案C（全付费）：¥XXX
```

**2. 时间成本**
```
- 学习时间：XX小时
- 单次使用时间：XX分钟
- 是否需要人工调整：是/否

如果需要3小时学习 + 每次30分钟使用
→ 时间成本较高，不适合批量生产
```

**3. 机会成本**
```
对比付费工具：
- 付费工具价格：¥XXX
- 这个工具价格：¥XXX
- 节省：¥XXX

对比人工：
- 人工成本：¥XXX
- 这个工具成本：¥XXX
- 节省：¥XXX
```

## 📊 工具评估标准

### 评分维度（满分100分）

**1. 功能完整度（30分）**
- 核心功能是否完整？（15分）
- 是否有必要的辅助功能？（10分）
- 是否持续更新？（5分）

**2. 易用性（20分）**
- 安装/注册难度（5分）
- 上手速度（10分）
- 文档齐全度（5分）

**3. 效果质量（30分）**
- 输出质量（20分）
- 稳定性（5分）
- 速度（5分）

**4. 成本（20分）**
- 免费额度（10分）
- 付费性价比（10分）

**评分标准**：
- 90-100分：强烈推荐，立即推广
- 75-89分：推荐使用，性价比高
- 60-74分：可以用，但有局限
- 60分以下：不推荐

---

### 推荐决策流程

**Step 1：计算总分**

**Step 2：判断推荐等级**
```
⭐⭐⭐⭐⭐ 强烈推荐（90-100分）
- 立即推广给团队
- 写详细使用教程
- 加入标准工具箱

⭐⭐⭐⭐ 推荐使用（75-89分）
- 推荐给团队尝试
- 特定场景使用
- 观察用户反馈

⭐⭐⭐ 可以关注（60-74分）
- 有潜力但不成熟
- 持续关注更新
- 暂不推广

⭐⭐ 不推荐（<60分）
- 记录问题
- 不推广
- 可能未来再看
```

**Step 3：写推荐理由**
```
推荐理由（3条）：
1. XXX
2. XXX
3. XXX

不推荐理由（如有）：
1. XXX
2. XXX
```

## 🎨 方案设计方法

### 什么是"方案设计"？

**不是单个工具，而是工具组合**

**举例**：
```
❌ 单工具：用D-ID做数字人视频
✅ 方案：Google AI Studio研究 → Claude整理 → ElevenLabs配音 → D-ID生成视频

❌ 单工具：用ChatGPT写文案
✅ 方案：Google AI Studio深度研究 → Claude生成多版本文案 → 人工筛选最佳版本
```

---

### 方案设计5步法

#### Step 1：明确场景和目标

**问题**：要解决什么问题？

**示例**：
```
场景：内容营销自动化
目标：用AI工具自动化生产营销内容（文案+音频+视频）
期望：降低成本80%，提升效率5倍
```

---

#### Step 2：拆解流程

**问题**：完成目标需要哪些步骤？

**示例**：
```
步骤1：深度研究（输入：主题 → 输出：研究报告）
步骤2：内容整理（输入：研究报告 → 输出：结构化文稿）
步骤3：音频生成（输入：文稿 → 输出：语音文件）
步骤4：视频制作（输入：语音+图片 → 输出：视频）
```

---

#### Step 3：选择工具（每步3个备选方案）

**原则**：每个步骤找3个工具，对比选最优

**示例**：
```
步骤1：深度研究
- 方案A：Google AI Studio（免费）⭐⭐⭐⭐⭐
- 方案B：Claude（¥150/月）⭐⭐⭐⭐
- 方案C：GPT-4（¥140/月）⭐⭐⭐⭐
→ 选择：方案A（免费且效果好）

步骤3：音频生成
- 方案A：ElevenLabs（¥100/月）⭐⭐⭐⭐⭐
- 方案B：剪映AI（免费）⭐⭐⭐
- 方案C：某开源项目（免费）⭐⭐
→ 测试后决定

步骤4：视频制作
- 方案A：D-ID（¥200/月）⭐⭐⭐⭐⭐
- 方案B：HeyGen（¥300/月）⭐⭐⭐⭐
- 方案C：GitHub开源项目（免费）⭐⭐⭐
→ 测试后决定
```

---

#### Step 4：验证方案

**目标**：实际跑通1次完整流程

**操作**：
1. 准备测试素材
2. 按流程执行
3. 记录每步时间和效果
4. 找出问题和优化点

**示例**：
```
测试项目：做1个30秒业务介绍视频

实际执行：
- 步骤1：Google AI Studio研究（30分钟）✅
- 步骤2：Claude整理文稿（10分钟）✅
- 步骤3：剪映AI生成音频（5分钟）⚠️ 音质一般
- 步骤4：某开源项目生成视频（2小时）❌ 失败，改用D-ID

结论：
- 前2步方案可行
- 音频方案需要优化（考虑付费工具）
- 视频方案需要调整（开源项目不成熟）
```

---

#### Step 5：成本效益分析

**计算3个方案的成本**：

**方案A（全付费）**：
```
- Google AI Studio：¥0
- Claude：¥150/月
- ElevenLabs：¥100/月
- D-ID：¥200/月
总成本：¥450/月
单个内容成本：¥15（假设每月30个）
```

**方案B（部分免费）**：
```
- Google AI Studio：¥0
- Claude：¥150/月
- 剪映AI：¥0
- 某开源项目：¥0（但需要2小时人工）
总成本：¥150/月 + 人工成本
单个内容成本：¥5 + 人工
```

**方案C（全免费）**：
```
- 全部用免费工具
总成本：¥0
问题：效果不达标
```

**推荐方案**：方案A（付费但效果好，可规模化）
