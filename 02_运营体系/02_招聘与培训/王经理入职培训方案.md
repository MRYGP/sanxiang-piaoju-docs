## 📖 三、业务学习重点

### 3.1 优先级业务（必须掌握）

**P0业务（重点）**：
- **A/B业务**：基础业务，高频，建立信任
- **H业务**：基础设施业务，企业做手术，养流水→贷款（6万→贷款300-400万）

**P2业务（了解）**：
- **D业务**：创收业务，收益率15-25%

### 3.2 H业务核心定位（重点）

**一句话定位**：
"企业体质改造专家（养流水→做资质→申请贷款）"

**不是**：
- ❌ 贷款中介
- ❌ 包装公司

**而是**：
- ✅ 基础设施服务
- ✅ 企业做手术

**关键数字**：
- 养流水周期：3-6个月
- 贷款额度：年开票额5-30%
- 成功案例：4个月养出300万（交行年化3.x%）

**详细学习**：参见《01_业务详解/H业务详解.md》

## 🎯 九、核心认知总结

### 9.1 不是二选一，是双轮驱动

```
传统思维：先做存量，再做增量（串行）
创新思维：存量增量同时推进（并行）
```

### 9.2 不是内容运营，是增长操盘

```
错误定位：王经理=内容生产者
正确定位：王经理=增长操盘手
```

### 9.3 不是单兵作战，是团队协同

```
王经理：统筹指挥
杨、廖：执行落地
松阳：战略支持
```

### 9.4 不是短期收割，是长期经营

```
短期：激活存量，建立信心
中期：招募合伙人，扩大规模
长期：网络自运转，持续增长
```
