## 📱 电梯版（30秒，破冰用）

### 我们做什么

**一句话：**
> 我们是"企业资金便利店"，帮企业老板在收钱、付钱这块省钱省心少踩坑。

**展开（加一个类比）：**
```
就像滴滴不养司机，但连接司机和乘客;
我们不直接服务企业，但连接"有企业资源的会计/中介"和"需要财务服务的企业"。

比如:
- 企业手里有未来6个月才能到的票据，我们帮他今天变现
- 企业要付100万货款，我们帮他设计更划算的付款方式，能省1-8万

我们靠全国的兼职合伙人(会计/代账/中介)带客户，成交后分成。
```

---

### 你做什么

**一句话：**
> 你是"合伙人经纪人"，招募和管理一批有企业资源的兼职合伙人，让他们持续带客户。

**展开：**
```
不是让你自己拉客户(有后端专业团队负责成交)，
而是:
- 招募100-200个兼职合伙人(重点是会计/代账/企业服务中介)
- 给他们话术、素材、培训，让他们"拿来就能用"
- 让他们在朋友圈发内容，给企业老板推荐我们
- 持续激活，淘汰不活跃的

核心工具:AI帮你生成内容，你不需要懂票据金融。

一句话:你不是销售，你是销售团队的保姆和指挥官。
```

## 📄 详细版（5分钟，面试用）

### 第一层：我们做什么（2分钟）

**企业老板的3个痛点：**

```
1. 收钱慢：手里有票据/欠条，要等几个月才能拿到钱
   → 我们帮他提前变现，10分钟-2小时到账

2. 付钱贵：每年对公付款几千万，用现金要付利息(5%)
   → 我们帮他用票据付款，能省0.4-8%成本

3. 账面差：注册资本没实缴、流水太小，影响融资/招投标
   → 我们帮他合规包装(专利实缴、真实贸易做大流水)
```

**我们的模式(S2B2C)：**

```
公司(S) ← 搞定复杂的资金渠道、风控、合同
    ↓
合伙人(B) ← 会计/代账/中介，手里有几百个企业老板微信
    ↓
企业客户(C) ← 有需求的企业

你的位置：连接S和B
- 让B(合伙人)源源不断带来C(客户)
- 让S(公司)持续赋能B(合伙人)
```

---

### 第二层：你做什么（2分钟）

**三步工作法：**

**第1步：招募(找对人)**
- 目标：会计/代账/企业服务中介(他们手里有企业资源)
- 方法：短视频/朋友圈/社群，吸引他们加你企微
- 话术："你手里的客户资源闲着也是闲着，帮我转发个海报，成交了分钱"

**第2步：投喂(给弹药)**
- 用AI工具(ChatGPT/Claude)一键生成：
  - 朋友圈文案(10-20条)
  - 私聊话术(开场白/异议处理)
  - 海报素材(一键转发)
- 发到合伙人群里，让他们"复制+粘贴"

**第3步：激活(盯着动)**
- 分层管理：
  - A类(有资源)：每周1v1沟通，优先支持
  - B类(愿意学)：群内统一培训
  - C类(观察期)：3个月不动淘汰
- 用成功案例和收益截图激励他们
- 合伙人带来客户，公司专业团队负责成交

---

### 第三层：你的日常（1分钟）

**每天：**
- 通过新的合伙人微信，打招呼筛选
- 在合伙人群发今天的内容/话术
- 回答合伙人问题(不会的问AI)

**每周：**
- 统计数据：新增多少合伙人?多少人在发圈?多少条线索?
- 更新话术库(把有效的话术沉淀下来)
- 组织一次小培训/答疑

**每月：**
- 给老板看盘：合伙人质量如何?哪些方法有效?
- 提优化建议：哪类合伙人值得重点维护?

## 🎤 面试官实战演绎版（带节奏指导）

**💡 实战技巧：按照下面这个节奏讲，不要一口气背诵，要看着对方的眼睛说：**

**(第一段：定调子 - 看着眼睛说)**
```
"简单说，我们是做**'企业资金便利店'的**。
就像企业手里的票据要等6个月才能拿钱，我们帮他今天就变现**;
或者企业要付100万货款，我们教他个法子，能省下好几万。
这是刚需，市场巨大。"
```

**(第二段：讲模式 - 身体前倾，强调不一样)**
```
"但我们不是那种苦哈哈招销售、一个个打骚扰电话的公司。
我们的模式像**'滴滴'——
我们靠连接全国的会计、代账、中介**(也就是我们的合伙人)来带客户。
成交和交付全部由公司搞定，合伙人只管推人，然后分钱。"
```

**(第三段：讲岗位 - 放松语气，消除恐惧)**
```
"所以，你在这个岗位，绝对不是让你去跑业务。
你的角色是**'合伙人经纪人'**。
你的核心工作就三件事：
第一，找到100个手里有企业资源的会计或中介;
第二，用我们教你的AI工具，一键生成文案发给他们;
第三，盯着他们发朋友圈，谁发了，谁就有钱赚。"
```

**(第四段：画饼与收尾 - 坚定自信)**
```
"你不需要懂金融，AI会帮你;
你只需要执行力强，愿意用新工具去武装这群合伙人。
3个月后，你手里握着50个活跃的会计渠道，这就相当于你带了一个50人的销售团队，但你不用给他们发底薪。
这个玩法，你觉得有意思吗?"
```
