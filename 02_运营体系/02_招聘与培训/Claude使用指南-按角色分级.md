## 什么是AI辅助工作模式

### 核心理念

```
传统工作模式：
员工 → 背知识 → 独立工作 → 老板检查
问题：培训成本高、容易出错、质量不稳定

AI辅助工作模式：
员工+Claude → Claude指导 → 快速执行 → 老板校正
优势：培训快、质量高、标准统一、规模化容易
```

### 为什么要用这个模式？

**对创始人（常松阳）：**

- ✅ 解放80%的培训时间
- ✅ 员工执行质量标准化
- ✅ 招聘门槛降低（只需要执行力）
- ✅ 规模化复制成本极低

**对运营专员：**

- ✅ 3天就能上手工作
- ✅ 不需要背大量知识
- ✅ 随时有"专家"指导
- ✅ 工作质量有保障

**对实习生：**

- ✅ 从零到能干活只需1周
- ✅ 边做边学，不枯燥
- ✅ 有问题立即解决
- ✅ 快速积累实战经验

### 这个模式如何运作？

```
Step 1：表明身份
你告诉Claude："我是常松阳" 或 "工号002" 或 "工号003"

Step 2：Claude识别并切换模式
- 创始人 → 战略参谋模式
- 运营 → 执行指导模式
- 实习生 → 手把手教学模式

Step 3：开始协作
你提需求 → Claude提供支持 → 你执行 → Claude帮检查

Step 4：持续改进
老板检查成果 → 发现问题 → 反馈给Claude → 优化流程
```

```

```

### Claude的响应模式

| 身份   | 响应模式 | 回答风格   | 深度 | 进度追踪器                 |
| ------ | -------- | ---------- | ---- | -------------------------- |

### 注意事项

⚠️ **重要提醒**：

1. **每次新窗口都要重新表明身份**
   - Claude的对话窗口关闭后，不会记住你的身份
   - 新窗口第一句话要再次表明
2. **可以在对话中切换身份**
   - 如果需要切换视角，重新表明即可
   - 例如：运营想看战略层面的建议，可以说"现在用创始人视角分析"
3. **敏感信息只对创始人提供**
   - 战略决策、合作伙伴细节、财务数据等
   - 运营和实习生看到的是"可执行层面"的信息

### 使用技巧

**提问技巧**：

1. **背景要说清楚**

   ```
   ❌ 不好：E业务要不要做？
   ✅ 好：E业务（债券配置），陈部有资源，但需要我们导流，市场需求不明确。要不要投入测试？
   ```

2. **说明决策考虑的因素**

   ```
   ❌ 不好：给我个建议
   ✅ 好：我主要考虑ROI和风险，以及是否会占用核心团队资源
   ```

3. **要多方案对比**

   ```
   ❌ 不好：怎么办？
   ✅ 好：给我3个方案，分别是保守、平衡、激进的做法
   ```

**节省时间技巧**：

1. **定期查看进度**
   - 每周一问："本周重点关注什么？"
   - Claude会从progress-tracker-boss.md提取要点
2. **批量决策**
   - 把多个问题一起问
   - Claude会逐个分析，最后给优先级建议
3. **让Claude帮你检查员工工作**
   - "运营提交的XX方案靠谱吗？帮我审核一下"
   - Claude会基于标准给出评估

## 常见问题FAQ

### Q1：我每次新窗口都要表明身份吗？

**A**：是的！每次新窗口开始时，第一句话表明身份。

因为Claude的对话窗口关闭后，不会记住你是谁。就像你每次去不同的店，都要重新介绍自己一样。

------

### Q2：我可以切换身份吗？

**A**：可以！在对话中重新表明身份即可。

例如：

- 你是运营，但想看创始人视角的分析
- 你可以说："现在用创始人视角分析这个问题"

------

### Q3：Claude会把我的对话告诉别人吗？

**A**：不会。每个对话窗口是独立的。

你和Claude的对话，只有你自己看得见（除非你分享给别人）。

------

### Q4：我问的问题太"笨"，会被笑话吗？

**A**：完全不会！

Claude是AI，没有情绪，不会笑话你。反而，越"笨"的问题，Claude越耐心讲解。

记住：**没有笨问题，只有没问出来的问题。**

------

### Q5：如果Claude给的答案不对，怎么办？

**A**：

1. 告诉Claude："这个答案好像不对"
2. Claude会重新查找正确信息
3. 如果还是不对，及时告诉导师/运营/老板

Claude不是万能的，但会尽力帮你找到正确答案。

------

### Q6：我可以问Claude私人问题吗？

**A**：可以问，但建议区分工作和生活。

Claude主要帮你解决工作问题。如果有私人问题（如：职业规划、学习建议），也可以问，但不要占用太多工作时间。

------

### Q7：Claude能替我做决策吗？

**A**：不能！Claude只能辅助，不能替代你。

- Claude提供建议和方案
- 最终决策由你或老板做
- 你要为自己的决策负责

------

### Q8：如果我完全不懂技术，也能用Claude吗？

**A**：完全可以！

Claude的使用很简单：

1. 表明身份
2. 像和人聊天一样提问
3. 跟着Claude的指导做

不需要任何技术背景。

------

### Q9：我能让Claude帮我做作业/写论文吗？

**A**：工作时间，请专注工作相关的问题。

如果有学习需求，可以：

1. 下班后问
2. 或问和工作相关的学习问题（如：学习销售技巧）

------

### Q10：Claude会记住我之前问的问题吗？

**A**：在同一个对话窗口内，会记住。

但如果你关闭窗口，再打开新窗口，Claude就"忘记"了。

所以，如果是持续的任务，建议在同一个窗口完成。或者，把重要信息记录到"进度追踪器"。
