## 🎯 一、顶层设计：三轮驱动模型

### 核心逻辑（已修正）

**原逻辑（已废弃）**：先搭内容，再招合伙人  
**新逻辑（当前执行）**：存量实战 → 产出案例 & 选题 → 内容验证 → 合伙人放大

这不是简单的"发广告"，而是构建自动运转的获客机器：

```
第一步：存量实战（0-2个月）
    ↓
    激活存量客户，做标杆项目，积累真实案例
    ↓
第二步：产出案例 & 选题（2-3个月）
    ↓
    从真实对话中提取选题，包装成功案例
    ↓
第三步：内容验证（3-4个月）
    ↓
    基于真实案例制作内容，验证内容获客效果
    ↓
第四步：合伙人放大（4-6个月）
    ↓
    用验证过的内容吸引合伙人，建立合伙人网络
```

**关键原则**：
- ✅ 内容由实战倒推，不允许"闭门编故事"
- ✅ 任何重大内容投放前，必须有3-5个真实案例支持
- ✅ 每月复盘"线下vs线上"数据，调整资源投入比例

### 1. 第一轮：内容引力(天网)

**载体**：公众号/视频号/朋友圈(三湘内容工厂生产)

**作用**：解决"信任"问题。通过秘闻、避坑故事，建立专家人设

**核心逻辑**：不发硬广，只发"认知差"

**与现有体系的关系**：
- 已落地：见`02_运营体系/业务员运营与招募手册.md`的"AI内容工厂"模块
- 当前用途：招募业务员
- 战略升级：同时用于获取企业客户

---

### 2. 第二轮：AI工具矩阵(地网)

**载体**：微信小程序/H5工具箱

**作用**：解决"留存"和"线索捕捉"问题

**核心逻辑**：工具即探针。每一次计算/查询，都是精准需求暴露

**关键差异**：
- 传统模式：内容看一次就忘
- 新模式：好用的工具会一直用，持续触达

---

### 3. 第三轮：合伙人承接(人网)

**载体**：企业微信+兼职合伙人网络

**作用**：解决"转化"问题

**核心逻辑**：工具是武装合伙人的"核武器"，让他们不仅仅有一张嘴

**与现有体系的关系**：
- 已落地：见`00_核心文档/8个业务清单更新版.md`的兼职业务员网络
- 战略升级：业务员配备AI工具，提升成交率

## ⏰ 二、时间分配原则（当前阶段）

### 2.1 运营和创始人时间分配

**当前阶段（0-6个月）**：
- **运营**：至少60-70%时间在一线触达
  - 标杆项目跟进
  - 真实对话记录
  - 案例包装
- **创始人（常松阳）**：至少60-70%时间在一线触达
  - 参与关键客户沟通
  - 把关标杆项目
  - 指导话术优化
  - 战略方向把控

**内容生产时间**：
- 不超过30%时间用于内容生产
- 内容必须基于真实对话和真实案例
- 不允许"闭门编故事"

### 2.2 内容选题来源机制

**强制要求**：
- ✅ 每周从「进度追踪器」里选出3-5个真实对话，作为下周选题池
- ✅ 每个选题必须有对应的真实案例或真实对话支撑
- ❌ 禁止编造故事或虚构案例

**流程**：
```
一线对话 → 标签 → 每周例会选题 → 内容制作
```

## ⚖️ 三、核心边界与护栏(Guardrails)

为防止战略跑偏，设定以下不可逾越的红线：

### 1. 业务边界护栏

**✅ 只做A/B相关**：所有工具必须直接服务于"识别有票企业"或"识别付款企业"

**❌ 不做杂货铺**：严禁开发发票整理、工资条等泛用型工具(除非对A/B有直接转化价值)

**示例判断**：
```
提案："开发一个企业发票管理工具"
评估：❌ 拒绝。与A/B业务无直接关联

替代：✅ "开发票据到期提醒+变现时机建议工具"(直接服务A业务)
```

---

### 2. 合规边界护栏

**✅ 数据源合法**：企查查/天眼查数据仅作内部情报或人工查询辅助

**❌ 严禁转售**：绝对不做"1元查企业"的数据倒卖生意，避免法律风险

**✅ 定位顾问**：提供"基于数据的分析建议"，而非"权威征信报告"

**合规口径**：
- 时效：`通常10分钟-2小时到账(以票种/额度/通道为准)`
- 收益：`示例：半年期银承约省0.2%-0.8%；具体以成交时为准`
- 数据：`*以上数据为示例值，受XX影响*`

---

### 3. 玩法边界护栏（内容合规）

**明确不详细讲的内容**：
- ❌ "骗贷技术细节"：不教客户如何骗贷、如何造假
- ❌ "洗流水教程"：不教客户如何空转、如何洗钱
- ❌ "避税逃税方法"：不教客户如何逃税、如何避税

**所有内容的落脚点必须是**：
- ✅ **合规替代方案**：提供合法合规的解决方案
- ✅ **风险提示**：明确告知风险，不承诺100%成功
- ✅ **真实案例**：基于真实案例，不编造故事

**内容定位**：
- 从"秘闻/灰度" → "真实踩坑+合规替代+中介赚钱方式"
- 强调"我们不做违法的事，只做合规的替代方案"

**示例**：
```
❌ 错误内容："教您如何用空壳公司骗贷"
✅ 正确内容："企业融资资格修补术：通过真实贸易操作，合规做大贸易量，获得银行贷款资格"

❌ 错误内容："教您如何洗流水"
✅ 正确内容："真实贸易带量：用真实货物、真实发票、真实交易、真实仓单，合规做大贸易规模"
```

---

### 4. 研发边界护栏(去工程化)

**✅ MVP先行**：所有工具必须先用"飞书/Excel+人工"跑通逻辑

**❌ 拒绝自研**：所有技术开发一律外包或使用低代码平台，绝不组建研发团队

**决策流程**：
```
新工具提案
    ↓
用Excel/飞书做原型
    ↓
人工跑通逻辑(至少10个真实案例)
    ↓
验证有效后外包开发
    ↓
绝不自建技术团队
```

## 🗺️ 五、落地执行路线图

### Phase 1：手工MVP期(现在-运营入职后1个月)

**核心动作**：
1. 用Excel/飞书多维表格制作"计算器"和"方案生成器"模板
2. 让"内容工厂"产出配套话术：《我用这个表帮老板省了2万》
3. 运营入职后，手动发给种子合伙人试用

**验证目标**：
- 合伙人愿不愿意用？
- 老板看了有没有反应？
- 转化率能达到多少？

**决策点**：
- ✅ 有效 → 进入Phase 2外包开发
- ❌ 无效 → 调整工具逻辑或放弃

---

### Phase 2：低代码/外包期(3-6个月)

**核心动作**：
1. 将验证成功的Excel逻辑外包开发成H5或小程序
2. 植入自动获取手机号/微信授权功能
3. 线索自动回流到企业微信

**技术选型**：
- 方案A：低代码平台(如宜搭、轻流) - 快速但功能受限
- 方案B：外包开发(找淘宝/猪八戒) - 灵活但需验收
- 方案C：本地/私有化AI平台 - 数据安全但成本高

**预算范围**：
- 单个工具：5000-20000元(示例区间)*
- 总投入：2-5万元(示例区间)*

*以上预算为示例区间，实际成本受功能复杂度、开发商报价等因素影响

---

### Phase 3：平台化期(12个月+)

**核心动作**：
1. 数据沉淀，形成区域企业信用库
2. 反向赋能银行/资金方
3. 成为真正的数据平台

**战略意义**：
- 从"工具提供商" → "数据平台"
- 从"赚差价" → "赚数据价值"
- 形成真正的竞争壁垒

**前置条件**：
- 累积10000+企业使用数据
- 建立数据安全与合规体系
- 获得相关资质或牌照

## ⚠️ 八、关键风险与应对

### 风险1：工具无人使用

**表现**：开发完了，合伙人不推广，客户不使用

**应对**：
- ✅ Phase 1必须验证：手工MVP阶段必须有真实使用数据
- ✅ 激励机制：合伙人推广工具有额外奖励
- ✅ 持续优化：根据反馈快速迭代

---

### 风险2：合规踩线

**表现**：工具承诺过度，涉及非法集资/数据倒卖等问题

**应对**：
- ✅ 法务前置：每个工具上线前法务审核
- ✅ 口径统一：严格遵守白名单/禁用词
- ✅ 用户协议：明确"仅供参考，不构成承诺"

---

### 风险3：技术依赖外包

**表现**：外包团队跑路，工具无法维护

**应对**：
- ✅ 源代码托管：所有代码必须交付并托管
- ✅ 技术文档：要求详细的技术文档
- ✅ 多家备选：不依赖单一外包商

## 🎯 十、高阶获客渠道储备库(Phase 2+)

**文档定位**：中长期获客策略储备/高级合伙人赋能手册  
**适用阶段**：Phase 2(扩张期)及以后  
**核心用途**：当基础朋友圈获客遇到瓶颈，或需要指导高级合伙人拓客时启用

**重要说明**：
- ⚠️ 这些渠道**当前不启用**，仅作战略储备
- ✅ 主要用于**赋能高级合伙人**，教他们"除了发朋友圈还能怎么做"
- 📊 每个渠道都标注了**适用度评级**和**启用条件**

---

### 渠道分级体系

我们按照"适合度 × 前景度"将10个高阶渠道分为4个等级：

```
⭐⭐⭐⭐⭐ 极力推荐(Phase 2优先启用)
  - 推荐裂变机制
  - 招投标数据开发

⭐⭐⭐⭐ 高度推荐(Phase 2-3)
  - 线上课堂/训练营
  - 渠道合作(代账公司)

⭐⭐⭐ 值得考虑(Phase 3+)
  - 搜索占位(SEO/长尾词)

  - 软件代理商结盟

⭐⭐ 谨慎考虑(Phase 4+)
  - 圈层渗透(商会/高端异业)
  - 精准广告投放
```

### ⭐⭐⭐⭐⭐ 第一梯队：Phase 2优先启用

#### 渠道1：推荐裂变机制 🔥

**核心逻辑**：让现有合伙人/老板，去推荐新的合伙人/企业主

**为什么适合**：
- 会计/代账/中介互相认识一堆同行
- 老板之间也会互相问："你贴票找谁做？"
- 客单价高、信任门槛高，天然适合熟人推荐

**启用条件**：
- ✅ 合伙人数量达到50人
- ✅ 已有10+成功案例可分享
- ✅ 分成系统运行稳定

**实施方案**：

```
【合伙人推荐合伙人】
- 推荐1个新合伙人，其首单成交 → 老合伙人获得该单利润的10-15%分成
- 或：老合伙人在新人前3单中，额外获得5bp分成(在原有分成基础上)

【老板推荐老板】
- 推荐1个企业成交 → 推荐人获得该单10%利润分成
- 或：赠送1次免费"企业风险体检"服务

【转介绍素材包】
- 给同行："我们在全国招票据合伙人，月入5000-20000元(示例区间)*，你要不要了解？"
- 给老板："我这边有个资金便利店，急用票/付款可以找他们。"

*收入为示例区间，受个人能力、市场环境、投入时间等因素影响
```

**教合伙人的话术**：


#### 渠道2：招投标数据开发 🎯

**核心逻辑**：利用公开数据，在客户"刚需爆发"时切入

**为什么适合**：
- 企业中标 → 立即需要垫资、买材料(B业务)、开票据(A业务)
- 数据公开，不用求人，ROI最高

**启用条件**：
- ✅ 运营专员已入职
- ✅ 有标准化话术和方案模板
- ✅ 后端执行能力稳定

**实施方案**：

```
【数据来源】
- 官方平台：各省公共资源交易中心(如湖南省公共资源交易中心)
- 第三方平台：企查查/天眼查的"中标信息"订阅
- 行业垂直平台：建筑招标网、政府采购网

【筛选标准】
- 中标金额：100万-5000万(太小没需求，太大我们吃不下)
- 所在地区：优先本地，其次周边省份
- 行业类型：建筑、市政、贸易、制造

【接触流程】
Step 1: 每天抓取10-20条中标公示
Step 2: 筛选符合条件的5-10家企业
Step 3: 通过企查查找到老板联系方式
Step 4: 发送定制化祝贺+服务方案

【话术模板】(合规版)
"X总您好，恭喜贵司中标【XX项目】！

我们是三湘票据，专注为工程企业提供资金周转服务：
✅ 票据贴现：10分钟-2小时到账(以票种/额度/通道为准)*
✅ 票据付款：相比现金省0.2%-0.8%(示例区间)*
✅ 供应链金融：项目启动期资金支持

如有需要，可随时联系。
祝项目顺利！"

*到账时效受票种、额度、通道等因素影响
*费率为示例区间，以实际成交时市场情况为准
```

**教合伙人的方法**：

```
【培训内容】
1. 如何注册企查查/天眼查账号
2. 如何设置"中标信息"订阅
3. 如何从公示信息中提取关键信息(项目金额、企业名称、联系方式)
4. 如何发送第一条祝贺消息

【操作演示】(10分钟视频)
- 实操演示：从打开网站到发送第一条消息

【话术库】
- 提供5套不同行业的祝贺+服务话术模板
```

**预期效果**：
- 每月触达：50-200家中标企业(示例区间)*
- 回复率：5-15%(示例区间)*
- 转化率：10-20%(示例区间)*

*以上数据为示例值，受话术质量、市场环境等因素影响

#### 渠道5：渠道合作(代账公司/SaaS) 🔗

**核心逻辑**：和"已有客户的服务商"绑定，借道获客

**为什么适合**：
- 这些服务商手里有一批稳态企业
- 他们不擅长票据/资金，但需要新变现点
- 我们提供"业务分成+专业后端"

**启用条件**：
- ✅ 有标准化流程和案例
- ✅ 有成熟的合作分成模型
- ✅ 有商务谈判能力

**实施方案**：

```
【目标对象】
类型A: 代理记账公司(优先)
  - 本地中小型代账公司(20-200家客户)
  - 他们的客户=我们的精准目标

类型B: 企业服务SaaS
  - 费控系统、进销存、ERP等
  - 能看到企业资金流/票据流

类型C: 园区运营方
  - 产业园、孵化器
  - 聚集大量中小企业

【合作模式】
模式1: 推荐分成
  - 代账公司推荐客户成交 → 分成10-20%
  - 类似合伙人模式，但比例更高

模式2: 联合服务
  - 代账服务+票据服务打包
  - 利润分成或固定服务费

模式3: 工具嵌入
  - 在SaaS/园区平台嵌入我们的工具入口
  - 按使用量或成交量分成
```

**谈判话术**：

```
"X总您好，我们是做企业票据资金服务的。

我了解到贵司服务了很多中小企业客户，
其中应该有不少有票据贴现或付款优化的需求。

我们可以提供：
✅ 专业的票据服务后端
✅ 您的客户成交，我们给您分成
✅ 不占用您的资源，纯增量收入

是否方便聊聊合作可能？"
```

**教合伙人的方法**：

```
【针对有资源的合伙人】
- 如果合伙人本身是代账公司老板 → 直接升级为"超级合伙人"
- 如果合伙人认识代账公司 → 教他们如何谈合作

【话术模板】
"老王，你们代账公司的客户，有没有需要贴票或付款的？
我这边有专业通道，成交了分你10-20%。"
```
