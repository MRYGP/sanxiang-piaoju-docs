## 📌 核心定位

**B业务是三湘票据的护城河业务。**

- A业务（贴现）：红海竞争，客户可以找银行、金融机构、任何中介
- B业务（卖票）：**供给端被中介控制**，企业想买票/凭证，必须找中介

**在资金体检主线中的角色**：
- **工具业务（支付端）**：在资金体检主线中，B业务是支付端的工具业务
- **在H项目中**：为H项目设计上下游贸易链，配合H业务做真实流水
- **在存量对话中**：顺手筛选B机会，在对话中自然推荐
- **在线上内容中**：最适合作为主入口的业务（内容+合伙人侧）

**战略方向**：
1. 强化供应端 → 建立票据/凭证库存数据库
2. 主动服务 → 不等客户问，主动设计省钱方案
3. 工具赋能 → 开发计算器/设计器，让客户自己算、自己选

## 一、B业务在整体模型中的位置

### 1.1 在资金体检主线中的角色

**B业务定位**：
- **工具业务（支付端）**：在资金体检主线中，B业务是支付端的工具业务
- **不是独立业务线**：B业务不是独立的业务线，而是资金体检方案中的工具模块

**在体检→方案→执行链条中的位置**：
- **体检阶段**：发现企业有付款需求，可以优化付款结构
- **方案阶段**：设计付款优化方案，推荐合适的票据/凭证类型
- **执行阶段**：提供票据/凭证，帮助企业完成付款

**与其他业务的关系**：
- **与H业务的关系**：为H项目设计上下游贸易链，配合H业务做真实流水
- **与A业务的关系**：A业务是收票端，B业务是出票端，形成闭环
- **与D业务的关系**：在有真实贸易基础的情况下，B业务可以配合D业务做收益放大

### 1.2 在不同获客渠道中的角色

**存量客户**：
- 在对话中顺手筛选B机会
- 从A业务客户转化（"您经常有票要贴现，说明您供应商给您开票。反过来，您付货款给供应商时，可以用票代替现金"）

**线上内容**：
- 最适合作为主入口的业务
- 内容定位：真实踩坑+合规替代+中介赚钱方式
- 栏目B：给中介——《在监管变严下还能合法赚多少》

**合伙人/中介**：
- 中介如何用B业务打开老板的话题
- 如何与A/H/D串成一个"升级阶梯"

## 三、交付模式（两种模式）

### 3.1 初期：撮合型（借冷部能力先跑单）

**模式特点**：
- 我们作为撮合方，连接企业和冷部（持票/持凭证资方）
- 企业有需求 → 我们找冷部 → 冷部提供票据/凭证 → 企业付款
- 我们赚差价和服务费

**优势**：
- ✅ 快速启动，不需要大量资金
- ✅ 风险低，不需要囤货
- ✅ 可以快速验证市场需求

**劣势**：
- ❌ 依赖冷部，响应速度可能不够快
- ❌ 利润空间有限（需要分给冷部）
- ❌ 难以标准化

**适用阶段**：
- 初期（0-6个月）
- 验证市场需求
- 建立客户基础

### 3.2 中后期：工具化/系统化（把流程产品化）

**模式特点**：
- 建立票据/凭证库存数据库
- 开发省钱计算器、贷款设计器等工具
- 标准化流程，系统化管理
- 主动推荐，不等客户问

**优势**：
- ✅ 响应速度快，客户体验好
- ✅ 利润空间大（减少中间环节）
- ✅ 可以规模化复制
- ✅ 建立护城河（工具+数据）

**劣势**：
- ❌ 需要大量资金（囤货）
- ❌ 需要系统开发（工具）
- ❌ 需要团队建设（运营）

**适用阶段**：
- 中后期（6个月+）
- 市场需求验证完成
- 有稳定客户基础
- 准备规模化

## 四、给中介的玩法说明

### 4.1 中介如何用B业务打开老板的话题

**开场话术**：
```
"X总，最近生意节奏还可以吧？

我这边几个老客户，最近都在用一种方法付款：
付货款的时候用票付，能省0.4%-8%的成本。

比如付100万货款，用票只需要99.6万，省4000元。

您这边平时付货款多不多？
要不要我帮您算一下能省多少钱？"
```

**核心逻辑**：
- 不是直接推销，而是"帮您算一下能省多少钱"
- 用具体数字吸引（100万省4000元）
- 降低门槛（先算账，再决定）

### 4.2 如何与A/H/D串成一个"升级阶梯"

**升级路径**：
```
【第一步：A业务破冰】
"X总，您有票要变现吗？"
→ 建立信任，完成第一次合作

【第二步：B业务转化】
"X总，您经常有票要贴现，说明您供应商给您开票。
反过来，您付货款给供应商时，可以用票代替现金，能省0.4%-8%。"
→ 从"卖票给我们"变成"从我们这买票"，双向业务关系

【第三步：H业务升级】
"X总，您这边有贷款需求吗？
我们有个'贷款体质手术'项目，通过3-6个月真实贸易操作，
帮您养流水，然后可以申请发票贷25-150万。"
→ 从工具业务升级到核心手术

【第四步：D业务增值】
"X总，您这边有真实贸易基础，可以配合D业务做收益放大。"
→ 在有真实贸易基础的情况下做收益放大
```

**关键点**：
- A业务是入口，建立信任
- B业务是留存，建立长期关系
- H业务是升级，做核心手术
- D业务是增值，在有真实贸易基础的情况下做收益放大

### 4.3 中介的收益模式

**模式1：推A/B业务赚差价**
- A业务（票据变现）：客户有票，我们收，中介赚差价
- B业务（付款省钱）：客户要付货款，我们卖票，中介赚差价

**模式2：推H业务做项目分成**
- H业务是"贷款体质手术"，帮企业养流水后申请发票贷
- 项目周期3-6个月，中介推荐客户，我们执行，按项目利润分成

**模式3：用我们的体检工具提升专业度**
- 我们有"资金体检"工具，帮中介提升专业形象
- 客户觉得中介专业，更容易成交

## 六、省钱计算器（主推工具）

### 6.1 产品定位

**让企业主3分钟算清楚：用票/凭证付货款能省多少钱。**

### 6.2 用户场景

```
场景1：企业主自己用
"我要付100万货款，用什么方式最省钱？"
→ 输入金额、要求
→ 工具推荐3个方案
→ 企业主自己选

场景2：合伙人给客户演示
"X总，我帮您算一下，您这100万货款..."
→ 当场演示计算过程
→ 客户直观看到省钱效果
→ 促成成交
```

### 6.3 功能设计

**输入项**：
- 付款金额（如：100万）
- 付款时间要求（如：30天内、60天、90天）
- 供应商类型（如：是否接受票据、是否已开通凭证账户）
- 特殊要求（如：要开发票、要公对公）

**输出项**：
```
【推荐方案1】银行承兑汇票
- 省钱金额：约4,000-6,000元（示例值）
- 操作难度：⭐（简单）
- 供应商接受度：高
- 我方报价：99.4万（示例值）
- 适合理由：最通用，供应商容易接受

【推荐方案2】云信/中企云链凭证
- 省钱金额：约6,000-8,000元（示例值）
- 操作难度：⭐⭐（需开通账户）
- 供应商接受度：中（需供应商也开通）
- 我方报价：99.2万（示例值）
- 适合理由：省钱更多，但需要双方都开通

【推荐方案3】商业承兑汇票
- 省钱金额：约8,000-15,000元（示例值）
- 操作难度：⭐⭐⭐（风险稍高）
- 供应商接受度：中低（需信任基础）
- 我方报价：98.5万（示例值）
- 适合理由：省钱最多，但需评估风险

⚠️ 以上数据为示例值，实际价格以成交时为准
```

## 七、贷款设计器（增值工具）

### 7.1 产品定位

**帮企业主找到最适合的贷款产品，找不到就给适配建议。**

### 7.2 核心逻辑

```
【输入】企业当前条件
- 成立时间
- 年营业额/流水
- 有无抵押物
- 有无发票
- 信用状况
- 贷款金额需求
- 贷款期限需求

【输出1】符合条件的贷款产品
- 产品A：XX银行发票贷，额度XX万，利率XX%
- 产品B：XX银行流水贷，额度XX万，利率XX%
- ...

【输出2】不符合条件时的适配建议
"您当前不符合XX贷款条件，但可以通过以下方式适配："

建议1：贸易带量（H业务）
- 操作：通过我们做大贸易流水
- 周期：4-6个月
- 效果：可获得银行无抵押贷款300-500万
- 如果不计较利息，甚至可达千万级

建议2：专利实缴（G业务）
- 操作：用专利完成注册资本实缴
- 效果：提升企业资质，增加贷款额度

建议3：票据质押
- 操作：用持有的票据做质押
- 效果：快速获得短期资金
```

### 7.3 贷款产品库（待建设）

需要整理市场上常见的贷款产品：

| 贷款类型 | 典型产品 | 基本条件 | 额度范围 | 利率范围 |
|---------|---------|---------|---------|---------|
| 发票贷 | 各银行 | 有真实发票 | 年开票5%-30% | 待研究 |
| 流水贷 | 各银行 | 有稳定流水 | 待研究 | 待研究 |
| 抵押贷 | 各银行 | 有房产/设备 | 抵押物价值70% | 待研究 |
| 信用贷 | 各银行 | 信用良好 | 待研究 | 待研究 |
| 供应链贷 | 核心企业 | 有订单/应收 | 待研究 | 待研究 |

### 7.4 H业务联动（重点）

**贸易带量→银行贷款 路径**：

```
【客户现状】
- 成立时间短，或流水不够
- 银行不给贷款

【我们的方案】
通过H业务（贸易带量）做大流水
    ↓ 4-6个月
银行认可的贸易流水记录
    ↓
申请无抵押贷款
    ↓
获得300-500万（正常）
甚至1000万+（不计较利息）

【关键卖点】
"凭空给企业创造贷款资格"
```
