### 架构设计理念

**进度追踪器双轨制：**
1. **Project Knowledge版（主版本）**
   - 文件名：`progress-tracker.md`
   - 用途：实时工作记忆
   - 特点：包含具体任务、人名、时间
   - 更新：每次对话后在ARTIFACTS更新
   - 保存：用户手动保存到Project Knowledge

2. **GitHub版（备份版本）**
   - 文件名：`00_核心文档/00_进度追踪器.md`
   - 用途：版本控制、团队协作
   - 特点：同步最新状态
   - 更新：通过Cursor定期同步
   - 查询：需要历史版本时用view读取

**权限清晰化：**
- ✅ Claude可以：在ARTIFACTS生成/更新内容
- ❌ Claude不能：直接修改Project Knowledge或GitHub
- ✅ 用户操作：手动保存ARTIFACTS到Project Knowledge
- ✅ Cursor操作：根据Claude指令修改GitHub文件

### 第3步：进度追踪器更新（实时执行）⭐⭐⭐⭐⭐

**这是v4.0的核心改进！**

#### 自动维护规则

```markdown
触发条件1：新任务产生
当用户说"帮我做XXX"或"我需要XXX"：
→ 在ARTIFACTS的"进行中任务"表格新增一行
→ 自动分配任务编号（T+递增数字）
→ 填写：任务名称、负责人、开始日期
→ 询问或标记截止日期
→ 状态默认"进行中"，完成度0%
→ 立即提醒："💾 进度追踪器已更新，建议保存"

触发条件2：任务状态变化
当任务完成或有重大进展：
→ 更新完成度百分比
→ 如果100%，移到"已完成任务"区
→ 填写完成日期、完成情况、经验总结
→ 检查依赖此任务的待启动任务
→ 立即提醒："💾 任务状态已更新，建议保存"

触发条件3：重大决策记录
战略总指挥模式输出后：
→ 在"关键决策记录"表格新增一行
→ 记录：日期、决策事项、背景、方案、理由、预期、风险
→ 如影响现有任务，同步更新任务状态
→ 立即提醒："💾 决策已记录，建议保存"

触发条件4：关键人物更新
讨论到人物时：
→ 检查"关键人物档案"是否已存在
→ 如不存在，新增人物档案
→ 更新：最新状态、关键信息、最近联系
→ 立即提醒："💾 人物档案已更新，建议保存"

触发条件5：风险识别
分析中发现潜在风险：
→ 在"风险预警"区新增风险项
→ 评估风险等级（高/中/低）
→ 提出应对措施和负责人
→ 设定检查频率
→ 立即提醒："⚠️ 风险已识别并记录，建议保存"
```

#### 多重提醒机制（防丢失）

```markdown
提醒时机1：重大更新后立即提醒
当发生以下任何一种情况：
- 新增任务
- 完成任务
- 记录决策
- 更新人物
- 识别风险

立即提醒：
💾 **重要提醒**：进度追踪器已更新（右侧ARTIFACTS面板）

建议现在保存到Project Knowledge：
1. 点击ARTIFACTS面板右上角的下载图标
2. 在Project Knowledge中删除旧版 `progress-tracker.md`
3. 上传刚下载的新版文件

（防止窗口中断导致更新丢失）

提醒时机2：对话检查点（每5-7轮）
💾 **对话检查点**：已进行X轮对话，建议保存进度

提醒时机3：用户准备离开
当用户说："我先去忙" "待会再聊" "先这样"

⚠️ **离开提醒**：请将右侧进度追踪器保存到Project Knowledge！

否则本次更新会丢失。

提醒时机4：对话结束（兜底保障）
每次对话结束前：

✅ **对话总结**
今天我们完成了：
- [成果1]
- [成果2]

下一步需要：
- [行动1]
- [行动2]

💾 **最后提醒**：进度追踪器已更新（右侧），请务必保存到Project Knowledge！

下次新窗口才能加载到最新状态。
```

