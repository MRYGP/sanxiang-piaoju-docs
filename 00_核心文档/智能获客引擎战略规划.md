**定位**：6-24个月战略蓝图  
**核心升级**：三网合一获客体系(内容+工具+合伙人)  
**战略周期**：2025年12月 - 2027年12月  
**当前状态**：战略储备期(手工MVP验证中)

---

## 🎯 一、顶层设计：三轮驱动模型

### 核心逻辑

这不是简单的"发广告"，而是构建自动运转的获客机器：

```
第一轮：内容引力(天网) → 让人想看
    ↓
第二轮：AI工具矩阵(地网) → 让人想用
    ↓
第三轮：合伙人承接(人网) → 让人成交
```

### 1. 第一轮：内容引力(天网)

**载体**：公众号/视频号/朋友圈(三湘内容工厂生产)

**作用**：解决"信任"问题。通过秘闻、避坑故事，建立专家人设

**核心逻辑**：不发硬广，只发"认知差"

**与现有体系的关系**：
- 已落地：见`02_运营体系/业务员运营与招募手册.md`的"AI内容工厂"模块
- 当前用途：招募业务员
- 战略升级：同时用于获取企业客户

---

### 2. 第二轮：AI工具矩阵(地网)

**载体**：微信小程序/H5工具箱

**作用**：解决"留存"和"线索捕捉"问题

**核心逻辑**：工具即探针。每一次计算/查询，都是精准需求暴露

**关键差异**：
- 传统模式：内容看一次就忘
- 新模式：好用的工具会一直用，持续触达

---

### 3. 第三轮：合伙人承接(人网)

**载体**：企业微信+兼职合伙人网络

**作用**：解决"转化"问题

**核心逻辑**：工具是武装合伙人的"核武器"，让他们不仅仅有一张嘴

**与现有体系的关系**：
- 已落地：见`00_核心文档/8个业务清单更新版.md`的兼职业务员网络
- 战略升级：业务员配备AI工具，提升成交率

## ⚖️ 二、核心边界与护栏(Guardrails)

为防止战略跑偏，设定以下不可逾越的红线：

### 1. 业务边界护栏

**✅ 只做A/B相关**：所有工具必须直接服务于"识别有票企业"或"识别付款企业"

**❌ 不做杂货铺**：严禁开发发票整理、工资条等泛用型工具(除非对A/B有直接转化价值)

**示例判断**：
```
提案："开发一个企业发票管理工具"
评估：❌ 拒绝。与A/B业务无直接关联

替代：✅ "开发票据到期提醒+变现时机建议工具"(直接服务A业务)
```

---

### 2. 合规边界护栏

**✅ 数据源合法**：企查查/天眼查数据仅作内部情报或人工查询辅助

**❌ 严禁转售**：绝对不做"1元查企业"的数据倒卖生意，避免法律风险

**✅ 定位顾问**：提供"基于数据的分析建议"，而非"权威征信报告"

**合规口径**：
- 时效：`通常10分钟-2小时到账(以票种/额度/通道为准)`
- 收益：`示例：半年期银承约省0.2%-0.8%；具体以成交时为准`
- 数据：`*以上数据为示例值，受XX影响*`

---

### 3. 研发边界护栏(去工程化)

**✅ MVP先行**：所有工具必须先用"飞书/Excel+人工"跑通逻辑

**❌ 拒绝自研**：所有技术开发一律外包或使用低代码平台，绝不组建研发团队

**决策流程**：
```
新工具提案
    ↓
用Excel/飞书做原型
    ↓
人工跑通逻辑(至少10个真实案例)
    ↓
验证有效后外包开发
    ↓
绝不自建技术团队
```

## 🛠️ 三、AI工具矩阵规划

### 第一梯队：核心刚需(立即落地)

#### 工具1：【贴现计算器Pro】(A业务)

**功能**：
- 输入：金额/到期日
- 输出：到手金额+"如果不贴现的理财收益对比"

**钩子**：计算结果页底部 → "获取精准报价"按钮 → 留联系方式

**技术实现**：
- Phase 1(当前)：Excel模板，业务员手动计算
- Phase 2(3-6个月)：H5页面，自动计算
- Phase 3(12个月+)：小程序，对接实时报价API

**预期效果**：
- 月使用量：500-2000次(示例区间)*
- 线索转化率：5-15%(示例区间)*

*以上数据为示例值，受推广力度、市场环境等多因素影响

---

#### 工具2：【付款省钱方案生成器】(B业务)

**功能**：
- 输入：付款金额
- 输出：PDF对比报告(现金 vs 贷款 vs 票据)

**钩子**：报告末尾 → "一键咨询方案"按钮

**技术实现**：
- Phase 1(当前)：Word模板+人工填写
- Phase 2(3-6个月)：自动生成PDF
- Phase 3(12个月+)：智能推荐+历史数据分析

**预期效果**：
- 月使用量：300-1000次(示例区间)*
- 咨询转化率：10-20%(示例区间)*

*以上数据为示例值，受推广力度、方案吸引力等因素影响

---

### 第二梯队：增值粘性(Q2 2026)

#### 工具3：【企业风险体检仪】(人工+AI版)

**功能**：
- 输入：企业名
- 后台：运营人工查询企查查/天眼查
- 输出：AI生成"票据收付建议"简报

**定位**：合伙人专属特权，用于维系客户关系

**技术实现**：
- Phase 1(当前)：纯人工
- Phase 2(6个月)：半自动(API查询+AI生成)
- Phase 3(12个月+)：全自动+数据库沉淀

**商业模式**：
- 免费：合伙人维护客户时使用
- 未来可能：VIP客户年费服务

## 🗺️ 四、落地执行路线图

### Phase 1：手工MVP期(现在-运营入职后1个月)

**核心动作**：
1. 用Excel/飞书多维表格制作"计算器"和"方案生成器"模板
2. 让"内容工厂"产出配套话术：《我用这个表帮老板省了2万》
3. 运营入职后，手动发给种子合伙人试用

**验证目标**：
- 合伙人愿不愿意用？
- 老板看了有没有反应？
- 转化率能达到多少？

**决策点**：
- ✅ 有效 → 进入Phase 2外包开发
- ❌ 无效 → 调整工具逻辑或放弃

---

### Phase 2：低代码/外包期(3-6个月)

**核心动作**：
1. 将验证成功的Excel逻辑外包开发成H5或小程序
2. 植入自动获取手机号/微信授权功能
3. 线索自动回流到企业微信

**技术选型**：
- 方案A：低代码平台(如宜搭、轻流) - 快速但功能受限
- 方案B：外包开发(找淘宝/猪八戒) - 灵活但需验收
- 方案C：本地/私有化AI平台 - 数据安全但成本高

**预算范围**：
- 单个工具：5000-20000元(示例区间)*
- 总投入：2-5万元(示例区间)*

*以上预算为示例区间，实际成本受功能复杂度、开发商报价等因素影响

---

### Phase 3：平台化期(12个月+)

**核心动作**：
1. 数据沉淀，形成区域企业信用库
2. 反向赋能银行/资金方
3. 成为真正的数据平台

**战略意义**：
- 从"工具提供商" → "数据平台"
- 从"赚差价" → "赚数据价值"
- 形成真正的竞争壁垒

**前置条件**：
- 累积10000+企业使用数据
- 建立数据安全与合规体系
- 获得相关资质或牌照

## ⚠️ 七、关键风险与应对

### 风险1：工具无人使用

**表现**：开发完了，合伙人不推广，客户不使用

**应对**：
- ✅ Phase 1必须验证：手工MVP阶段必须有真实使用数据
- ✅ 激励机制：合伙人推广工具有额外奖励
- ✅ 持续优化：根据反馈快速迭代

---

### 风险2：合规踩线

**表现**：工具承诺过度，涉及非法集资/数据倒卖等问题

**应对**：
- ✅ 法务前置：每个工具上线前法务审核
- ✅ 口径统一：严格遵守白名单/禁用词
- ✅ 用户协议：明确"仅供参考，不构成承诺"

---

### 风险3：技术依赖外包

**表现**：外包团队跑路，工具无法维护

**应对**：
- ✅ 源代码托管：所有代码必须交付并托管
- ✅ 技术文档：要求详细的技术文档
- ✅ 多家备选：不依赖单一外包商

### ⭐⭐⭐⭐⭐ 第一梯队：Phase 2优先启用

#### 渠道1：推荐裂变机制 🔥

**核心逻辑**：让现有合伙人/老板，去推荐新的合伙人/企业主

**为什么适合**：
- 会计/代账/中介互相认识一堆同行
- 老板之间也会互相问："你贴票找谁做？"
- 客单价高、信任门槛高，天然适合熟人推荐

**启用条件**：
- ✅ 合伙人数量达到50人
- ✅ 已有10+成功案例可分享
- ✅ 分成系统运行稳定

**实施方案**：

```
【合伙人推荐合伙人】
- 推荐1个新合伙人，其首单成交 → 老合伙人拿固定奖励500元
- 或：老合伙人在新人前3单中，额外获得5bp分成

【老板推荐老板】
- 推荐1个企业成交 → 推荐人获得该单10%利润分成
- 或：赠送1次免费"企业风险体检"服务

【转介绍素材包】
- 给同行："我们在全国招票据合伙人，月入5000-20000元(示例区间)*，你要不要了解？"
- 给老板："我这边有个资金便利店，急用票/付款可以找他们。"

*收入为示例区间，受个人能力、市场环境、投入时间等因素影响
```

**教合伙人的话术**：

```
"老王，我最近做了个副业，帮企业做票据资金服务。
你手上有没有客户需要贴票或者付款的？
我们这边通道很稳，我推荐给你也有分成。"
```

**风险提示**：
- ⚠️ 防止合伙人为了拿奖励推荐无效人员
- ✅ 设置"推荐人必须完成首单"的验证机制

---

#### 渠道2：招投标数据开发 🎯

**核心逻辑**：利用公开数据，在客户"刚需爆发"时切入

**为什么适合**：
- 企业中标 → 立即需要垫资、买材料(B业务)、开票据(A业务)
- 数据公开，不用求人，ROI最高

**启用条件**：
- ✅ 运营专员已入职
- ✅ 有标准化话术和方案模板
- ✅ 后端执行能力稳定

**实施方案**：

```
【数据来源】
- 官方平台：各省公共资源交易中心(如湖南省公共资源交易中心)
- 第三方平台：企查查/天眼查的"中标信息"订阅
- 行业垂直平台：建筑招标网、政府采购网

【筛选标准】
- 中标金额：100万-5000万(太小没需求，太大我们吃不下)
- 所在地区：优先本地，其次周边省份
- 行业类型：建筑、市政、贸易、制造

【接触流程】
Step 1: 每天抓取10-20条中标公示
Step 2: 筛选符合条件的5-10家企业
Step 3: 通过企查查找到老板联系方式
Step 4: 发送定制化祝贺+服务方案

【话术模板】(合规版)
"X总您好，恭喜贵司中标【XX项目】！

我们是三湘票据，专注为工程企业提供资金周转服务：
✅ 票据贴现：10分钟-2小时到账(以票种/额度/通道为准)*
✅ 票据付款：相比现金省0.2%-0.8%(示例区间)*
✅ 供应链金融：项目启动期资金支持

如有需要，可随时联系。
祝项目顺利！"

*到账时效受票种、额度、通道等因素影响
*费率为示例区间，以实际成交时市场情况为准
```

**教合伙人的方法**：

```
【培训内容】
1. 如何注册企查查/天眼查账号
2. 如何设置"中标信息"订阅
3. 如何从公示信息中提取关键信息(项目金额、企业名称、联系方式)
4. 如何发送第一条祝贺消息

【操作演示】(10分钟视频)
- 实操演示：从打开网站到发送第一条消息

【话术库】
- 提供5套不同行业的祝贺+服务话术模板
```

**预期效果**：
- 每月触达：50-200家中标企业(示例区间)*
- 回复率：5-15%(示例区间)*
- 转化率：10-20%(示例区间)*

*以上数据为示例值，受话术质量、市场环境等因素影响

---

#### 渠道3：行业社群渗透 🤝

**核心逻辑**：进入/共建"会计、代账、财税中介"聚集地，长期输出干货+招募

**为什么适合**：
- 目标人群(会计/代账)天然聚集在各种财税群里
- 对"票据、资金玩法、避坑故事"特别敏感
- 愿意转发这类实用信息

**启用条件**：
- ✅ 有5-10个成功案例可分享
- ✅ 有系统化的业务知识内容
- ✅ 有专人负责社群运营

**实施方案**：

```
【目标社群】
```
