### 创新2：自动维护规则（🆕 新增）

**位置**：在"对话过程中（实时维护）"之后新增

**内容**：
```markdown
### 进度追踪器自动维护规则

#### 触发条件1：新任务产生
当用户说"帮我做XXX"或"我需要XXX"：
→ 在ARTIFACTS的"进行中任务"表格新增一行
→ 自动分配任务编号（T+递增数字）
→ 填写：任务名称、负责人、开始日期
→ 询问或标记截止日期
→ 状态默认"进行中"，完成度0%
→ 立即提醒："💾 进度追踪器已更新，建议保存"

#### 触发条件2：任务状态变化
当任务完成或有重大进展：
→ 更新完成度百分比
→ 如果100%，移到"已完成任务"区
→ 填写完成日期、完成情况、经验总结
→ 检查依赖此任务的待启动任务
→ 立即提醒："💾 任务状态已更新，建议保存"

#### 触发条件3：重大决策记录
战略参谋模式输出后：
→ 在"关键决策记录"表格新增一行
→ 记录：日期、决策事项、背景、方案、理由、预期、风险
→ 如影响现有任务，同步更新任务状态
→ 立即提醒："💾 决策已记录，建议保存"

#### 触发条件4：关键人物更新
讨论到人物时：
→ 检查"关键人物档案"是否已存在
→ 如不存在，新增人物档案
→ 更新：最新状态、关键信息、最近联系
→ 立即提醒："💾 人物档案已更新，建议保存"

#### 触发条件5：风险识别
分析中发现潜在风险：
→ 在"风险预警"区新增风险项
→ 评估风险等级（高/中/低）
→ 提出应对措施和负责人
→ 设定检查频率
→ 立即提醒："⚠️ 风险已识别并记录，建议保存"
```

### 修改原则

**从"手把手"改为"原则导向"**：

**之前的风格（过度指导）**：
```markdown
1. 打开Cursor，进入项目目录
2. 打开文件：`/mnt/project/XX/XX.md`
3. 找到第XX行 / ## XX章节
4. 执行具体操作XXX
5. 保存文件（Cmd+S）
6. Git操作：
   - Stage changes
   - Commit: `[具体commit信息]`
   - Sync到GitHub
```

**现在的风格（原则导向）**：
```markdown
## 📋 Cursor执行任务

### 任务：[任务名称]

**目标**：[清晰描述要达成的目标]

**原则**：
1. 保持现有文档结构和格式风格
2. 不修改用户手动添加的内容（如有标注）
3. 修改后进行完整性检查
4. 使用有意义的commit信息

**期望结果**：
- 文件修改点1：[描述]
- 文件修改点2：[描述]

**修改内容**：
[提供具体的修改内容，但不规定具体步骤]

**验证方法**：
- Claude将用view工具重新读取文件
- 检查修改是否完整、格式是否正确
```
