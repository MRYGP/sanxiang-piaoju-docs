## 🎯 三个核心点

### 1. 一鱼多吃：中小企业客户价值最大化

**现状问题**：

- ✅ 有8个业务（A-H），但客户通常只做了1-2个
- ✅ 有存量客户资源，但只开发了20%的价值
- ✅ 获客成本只付一次，但客户价值没有最大化

**核心机会**：

- 中小企业客户有很多业务需求（票据、付款、贷款、理财、实缴等）
- 我们只做了一二个业务，还有6-7个业务没挖掘
- **一鱼多吃 = 一个客户，多次变现，提升LTV（客户终身价值）**

### 2. 兼职合伙人的轻资产模式

**现状优势**：

- ✅ 通过兼职合伙人获客，降低人力成本
- ✅ 客户终身绑定制，合伙人持续获得分成
- ✅ 不需要全职业务员，轻资产运营

**核心价值**：

- 合伙人带来客户 → 公司成交 → 合伙人分成
- 客户后续做其他业务，合伙人继续分成
- **轻资产 = 不需要大量全职员工，通过合伙人网络规模化**

#### 2.1 合伙人单客收益结构图（数字化）

**以制造/金属类A类客户为例（完整走完一条路径）**：

```
【合伙人视角：一个客户能挣多少钱？】

首单：B业务（付款省钱）
  ├── 公司净赚：1000元
  └── 合伙人分成（30%）：300元

H业务（贷款体质手术，3-6个月）
  ├── 公司净赚：5万元
  └── 合伙人分成（30%）：1.5万元

D业务（套利，年化15-25%）
  ├── 公司净赚：2万元
  └── 合伙人分成（30%）：6000元

A/B业务（高频工具，持续使用）
  ├── 公司净赚：3万元/年
  └── 合伙人分成（30%）：9000元/年

长期授信（后端佣金）
  ├── 公司净赚：1万元
  └── 合伙人分成（30%）：3000元

─────────────────────────────
合伙人单客总收益：约3.3万元
公司单客总收益：约11万元
客户LTV：约15万元
```

**合伙人收益结构说明**：

- **A业务**：小钱、即时现金流（单笔300-1000元）
- **H项目**：大项目分成（单项目1-2万元）
- **A/B高频业务**：长期维护钱（年化5000-10000元）
- **后端佣金**：额外收益（视情况）

**关键点**：

- 合伙人不需要懂所有业务细节
- 只需要推荐客户，客户做多个业务，合伙人持续分成
- 一个客户走完完整路径，合伙人能挣3-5万元

### 3. 免费工具给客户获客

**现状**：

- ✅ 有"资金体检"作为入口
- ✅ 有AI工具（体检器、方案参谋）
- ⚠️ 但可能没有系统化地利用免费工具获客

**核心机会**：

- 免费工具吸引客户 → 客户使用工具 → 发现需求 → 推荐业务
- **免费工具 = 获客入口 + 需求挖掘 + 信任建立**

## 💡 商业模式设计：三个核心点的闭环

### 闭环1：免费工具获客 → 一鱼多吃 → 合伙人分成

```
【第一步：免费工具获客】
免费工具（资金体检器、省钱计算器、贷款设计器）
  ↓
客户使用工具，发现需求
  ↓
【第二步：一鱼多吃】
客户做第一个业务（A/B/H等）
  ↓
系统自动推荐其他业务（交叉销售）
  ↓
客户做第二个、第三个业务...
  ↓
【第三步：合伙人分成】
合伙人推荐客户 → 客户做多个业务 → 合伙人持续分成
  ↓
合伙人看到收益，继续推荐更多客户
  ↓
形成正向循环
```

#### 2.2 业务推荐时机与话术

**时机1：首次成交后（3天内）**

```
"X总，您这次做的A业务还顺利吧？

您看哪个对您比较有用？"
```

**时机2：业务执行中（1个月内）**

```
"X总，您这次做的H业务进展还顺利吧？

我们这边有个配套服务：
- D业务：在真实贸易基础上做套利，年化15-25%
- 正好配合您的H项目，可以增厚利润

您看要不要了解一下？"
```

**时机3：业务完成后（3个月内）**

```
"X总，您上次做的H业务已经完成了吧？

现在您有真实贸易基础了，可以：
1. 申请发票贷（我们协助对接）
2. 做D业务套利（年化15-25%）
3. 做E业务债券理财（稳健配置）

您看哪个对您比较有用？"
```

#### 2.3 系统化交叉销售流程

**Step 1：客户标签化**

- 记录客户已做业务：A✅、B✅、H✅...
- 记录客户未做业务：C❌、D❌、E❌...
- 记录客户需求：有贷款需求、有付款需求、有理财需求...

**Step 2：自动推荐**

- 系统根据客户标签，自动推荐未做业务
- 合伙人/业务员收到推荐提醒，主动联系客户

**Step 3：持续跟进**

- 每月跟进一次，推荐新业务
- 客户做新业务，合伙人继续分成

## 🛠️ 免费工具获客系统设计（收缩版：少而狠）

> **执行原则**：不要一上来就实现4个完整工具，当前阶段只做1-2个非常好用的工具。

### 工具1：资金体检器（MVP版本，优先上线）

**功能**：

- 企业主自测：输入票、税、流水、征信等信息
- AI自动生成：资金体质诊断 + 产品路线建议
- **内嵌功能**：贷款设计器逻辑（不符合条件时推荐H业务）+ 需求挖掘器逻辑（推荐业务组合）

**获客逻辑**：

```
客户使用工具 → 发现"贷款体质不佳"或"不符合贷款条件"
  ↓
系统推荐：H业务（贷款体质手术）
  ↓
【硬绑CTA】客户必须选择：
  1. 预约一对一体检/顾问
  2. 一键报备给合伙人/三湘
  ↓
客户留下联系方式
  ↓
合伙人跟进 → 成交 → 分成
```

**关键要求**：

- 每个工具的页面，必须有且只允许1-2个CTA
- 不能只是"查看结果"，必须引导到"下一步动作"
- 工具是获客入口，不是给同行看的玩具

### 工具2：省钱计算器（B业务专用，第二优先级）

**功能**：

- 输入：付款金额、付款时间要求
- 输出：推荐3个方案（银承、云信、商承），显示省钱金额

**获客逻辑**：

```
客户使用工具 → 看到"能省4000-8000元"
  ↓
【硬绑CTA】客户必须选择：
  1. 预约一对一体检/顾问
  2. 一键报备给合伙人/三湘
  ↓
客户留下联系方式
  ↓
合伙人跟进 → 成交B业务 → 分成
  ↓
系统推荐：A业务、H业务等其他业务
```

**暂不开发**：

- ❌ 贷款设计器（单独工具）：逻辑已内嵌到资金体检器
- ❌ 客户需求挖掘器（单独工具）：逻辑已内嵌到资金体检器

**开发优先级**：

1. **资金体检器**（MVP版本，包含所有逻辑）
2. **省钱计算器**（第二优先级，验证需求后再开发）

## 📊 一鱼多吃的数据化运营

### 关键指标

**单客价值指标**：

- **首次业务价值**：客户第一次做的业务，产生的收入
- **交叉销售率**：客户做第二个业务的比例（目标：≥30%）
- **业务组合数**：客户平均做几个业务（目标：≥2.5个）
- **LTV（客户终身价值）**：客户在所有业务上产生的总收入（目标：≥10万）

**运营指标**：

- **业务推荐成功率**：推荐业务后，客户成交的比例（目标：≥20%）
- **推荐时机准确率**：在合适时机推荐业务，成交的比例（目标：≥30%）
- **客户留存率**：客户在3个月内做第二个业务的比例（目标：≥40%）

**客户价值看板**：

> **工具是获客入口，不是盈利点**

- 免费工具吸引客户使用
- 客户使用工具，发现需求
- 推荐业务，实现变现
