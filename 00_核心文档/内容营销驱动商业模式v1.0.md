## 🎯 一、核心定位（重新定义）

### 1.1 我们是谁

```
三湘票据 = 票据中介的合伙平台

         ≠ 直接面向企业的票据公司
```

**关键转变**：
- ❌ 旧定位：我们直接服务企业客户
- ✅ 新定位：我们赋能中介/业务员，他们服务企业客户

---

### 1.2 目标客户（战略调整）

```
【主要客户】（80%精力）

- 中介（单一业务中介，想多赚钱）

- 兼职业务员（财务/会计/销售，想副业）



【次要客户】（20%精力，副产品）

- 企业客户（由中介/业务员带来）
```

**为什么这样调整？**
- 中介/业务员有现成的企业客户资源
- 我们借力他们的资源，不需要从0获客
- 规模化更快（100个业务员 = 100个渠道）

## 🔄 二、完整商业模式

### 2.1 业务流程（四步）

```
Step 1：内容营销（吸引中介/业务员）

   ↓

【内容】干货技巧 + 行业秘闻 + 招募暗示

【平台】公众号 + 视频号 + 抖音/快手

【转化】私信 → 加企业微信 → 送工具包

   ↓

Step 2：筛选培训（快速赋能）

   ↓

【筛选】有资源？愿意发圈？能坚持？

【培训】2小时培训（看视频+测试）

【工具包】话术库 + 素材库 + 报备SOP

   ↓

Step 3：业务员展业（他们找企业客户）

   ↓

【动作】发朋友圈 → 找企业客户 → 挖掘需求 → 报备线索

【支持】总部提供话术/素材/后端支持

   ↓

Step 4：后端处理+分成

   ↓

【后端】冷部/合作伙伴处理业务

【分成】业务员拿50-70%，平台拿30-50%

【沉淀】企业客户数据进入平台
```

## 💰 三、盈利模式

### 3.1 收入来源

```
【主要收入】票据买卖差价（A/B业务）

- 单笔利润：0.1%-1%

- 月成交量：500-2000万

- 月利润：5-20万



【次要收入】服务费（C/D/E/F/G/H业务）

- 服务费：0.5-3万/单

- 月成交量：10-30单

- 月利润：5-30万



【合计】月利润：10-50万（取决于规模）
```

---

### 3.2 成本结构

```
【主要成本】业务员分成

- 占比：50-70%

- 特点：纯变动成本，有业务才有成本



【次要成本】

- AI/软件：1000-3000元/月

- 外包（设计/剪辑）：3000-5000元/月

- 办公：5000-10000元/月



【人力成本】

- 老板：战略+关键客户

- 运营专员：业务员管理+内容生产

- 其他：外包为主



【总成本】月成本：5-10万（不含分成）
```

---

### 3.3 利润模型（示例）

```
假设：100个业务员，每人每月带来2个订单



【收入】

- 200单/月 × 平均5万/单 = 1000万成交额

- 利润率1% = 10万利润



【成本】

- 业务员分成：10万 × 60% = 6万

- 固定成本：5万

- 总成本：11万



【净利润】10万 - 6万 = 4万（首月可能亏损）



【规模化后】（500个业务员）

- 1000单/月 × 5万/单 = 5000万成交额

- 利润50万

- 业务员分成：30万

- 固定成本：10万

- 净利润：10万
```

**关键点**：
- 规模越大，单位成本越低
- 业务员分成是变动成本，可控
- 固定成本占比小，易盈利

## 🎯 五、防飞单机制

### 5.1 为什么会飞单？

```
业务员想法：

"客户是我的，为什么要给平台分成？

我直接找冷部/其他后端，不更赚吗？"



平台痛点：

- 业务员带走客户

- 平台白干了（培训/素材/支持）

- 无法建立客户池
```

---

### 5.2 防飞单三重机制

#### 机制1：技术手段

```
✅ 企业微信客户池

- 客户添加的是企业微信

- 客户数据在平台

- 业务员离职，客户留在平台



✅ 订单系统

- 所有订单必须走平台

- 追踪成交/分成

- 数据透明



✅ 合同/发票

- 客户看到的是平台

- 合同主体是平台

- 增强平台品牌
```

---

#### 机制2：利益绑定

```
✅ 多业务绑定

- A业务成交 → B/G/H业务持续分成

- 一个客户，持续赚钱

- 飞单=损失未来收益



✅ 老客户持续分成

- 客户复购，业务员持续分成

- 不是一次性交易

- 飞单=损失持续收入



✅ 升级奖励

- 带来优质客户，额外奖励

- 成交额越大，分成比例越高

- 飞单=损失高收益
```

**注意**：所有奖励机制均基于实际成交的提成分润，不设固定奖励，避免亏损风险。

---

#### 机制3：规则约束

```
✅ 报备制度

- 客户必须先报备

- 报备后30天独家期

- 未报备=无分成



✅ 违约成本

- 飞单被发现

- 取消所有分成

- 拉黑不再合作



✅ 关系优势

- 平台有多个后端

- 平台有8个业务

- 业务员单干，客户体验差
```

---

### 5.3 核心逻辑

```
让"不飞单"比"飞单"更有利



【不飞单】

- 持续分成（老客户+多业务）

- 平台支持（素材+培训+后端）

- 多个后端（8个业务）

- 品牌背书（客户信任）



【飞单】

- 一次性收益

- 无平台支持

- 单一业务

- 客户信任低

- 被发现=拉黑



理性业务员会选择"不飞单"
```

## 📈 六、客户池建设（长期战略）

### 6.1 短期策略（0-12个月）

```
【目标】借力中介，快速起量



【重点】

- All in 招募中介/业务员

- 建立100-1000人网络

- 企业客户数据只是副产品



【不做】

- 不主动获取企业客户

- 不和中介抢客户

- 不急于建客户池
```

---

### 6.2 中期策略（12-24个月）

```
【目标】从中介客户中沉淀自己的客户池



【机制】客户分级制度

┌────────────────────────────────────┐
│ 一级客户：中介带来的新客户          │
│  - 客户关系：中介负责               │
│  - 平台角色：后端处理               │
│  - 分成：中介拿50-70%               │
├────────────────────────────────────┤
│ 二级客户：成交3次以上客户           │
│  - 触发：成交3次 or 累计金额>50万   │
│  - 客户关系：平台接管深度维护       │
│  - 分成：中介拿30-40%               │
├────────────────────────────────────┤
│ 三级客户：平台直接获客              │
│  - 来源：品牌效应/老客户转介绍      │
│  - 客户关系：完全在平台             │
│  - 分成：平台100%                   │
└────────────────────────────────────┘



【关键点】

- 中介持续有收益，但比例降低

- 客户关系逐步转移到平台

- 不是抢客户，是自然升级
```

---

### 6.3 长期愿景（24个月+）

```
【目标】平台品牌驱动，客户主动找来



【效果】

- 客户说："我要找三湘票据"（不是找某个中介）

- 70%中介带客户，30%自己获客

- 有自己的客户池（1000-5000个）



【标志】

- 品牌知名度

- 口碑传播

- 内容影响力
```

## 🎯 九、与传统模式对比

### 传统模式

```
【获客方式】

- 老板/销售直接找企业客户

- 线下拜访、电话销售

- 成本高、效率低



【团队规模】

- 需要专业销售团队（5-10人）

- 需要专业后端团队（5-10人）

- 人力成本高



【客户关系】

- 客户关系在公司

- 控制力强

- 但获客慢
```

---

### 我们的模式

```
【获客方式】

- 内容营销吸引中介/业务员

- 借力他们的企业客户资源

- 成本低、规模化快



【团队规模】

- 核心团队3-5人（老板+运营+实习生）

- 兼职业务员100-1000人

- 人力成本低（纯变动成本）



【客户关系】

- 短期：客户关系在中介

- 长期：通过客户分级沉淀到平台

- 先借力，后自建
```

---

### 优劣势对比

```
【优势】

✅ 规模化快（100个业务员 = 100个渠道）

✅ 成本低（纯变动成本）

✅ 借力现有资源（不需要从0获客）

✅ AI降低内容生产成本（效率10倍）



【劣势】

⚠️ 客户关系不在平台（短期）

⚠️ 飞单风险（需要防飞单机制）

⚠️ 业务员质量不可控（需要筛选淘汰）

⚠️ 内容营销需要持续投入（不能停）



【战略选择】

用短期劣势（客户关系不在平台）

换取长期优势（规模化快速起量）

然后通过客户分级，逐步建立自己的客户池
```
