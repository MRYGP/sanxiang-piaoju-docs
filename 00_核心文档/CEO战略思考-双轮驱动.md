## 📊 一、现状诊断

### 1.1 核心资产盘点
```
存量资产：
├── 5-6个企业微信（每个50-100客户）
├── 总计250-600个企业客户
├── 都是因A业务建立的信任关系
```

## 🎯 二、双轮驱动战略

### 2.1 第一轮：存量激活（Week 1-2）
```
时间：前2周集中突击
目标：激活200个存量客户
策略：H业务做主钩，A/B/D组合推
预期：20-30单成交，10个成功案例
```

### 2.2 第二轮：增量扩张（Week 2开始）
```
时间：第2周开始并行
目标：建立100人合伙人网络
策略：用存量案例做背书招募
预期：3个月达到月产50-100单
```

### 2.3 为什么是双轮驱动？
```
只做存量 = 吃完就没了（天花板低）
只做增量 = 见效太慢（团队没信心）
双轮驱动 = 短期有粮，长期有地
```

## 💡 五、核心策略

### 5.1 H业务做主钩

**为什么**：
- 价值最大（养流水→贷款）
- 客户痛点最痛（缺资金）
- 成功案例最有说服力

**如何做**：
- 优先推给A类客户
- 用成功案例做背书
- 强调"企业体质改造"定位

### 5.2 用存量案例招募合伙人

**策略**：
- 成功案例包装成内容
- 用案例吸引潜在合伙人
- 强调"已验证模式"

**话术**：
"我们2周激活了200个存量客户，成交了30单。
这个模式已经验证，现在招募合伙人一起做。"

### 5.3 组合推业务

**策略**：
- H业务做主钩
- A/B/D业务组合推
- 提升单客户价值

**话术**：
"除了养流水，我们还有票据贴现、付款省钱、套利等服务。
都是帮企业解决资金问题的。"
