## 🎯 系统架构

### 三层记忆体系

```
┌─────────────────────────────────────┐
│  Custom Instructions（系统大脑）     │
│  • 完整的系统指令（18KB）           │
│  • 自动加载，0延迟                  │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  Knowledge Base（工作记忆）         │
│  • progress-tracker.md              │
│  • 当前任务、决策、人物             │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  GitHub（长期存储）                 │
│  • 系统文档                         │
│  • 业务详解                         │
│  • 版本控制                         │
└─────────────────────────────────────┘
```

## 💡 核心特性

### 1. 三重角色自动切换
- **执行秘书**：处理日常任务、生成文档
- **战略参谋**：分析问题、提供建议、预判风险
- **架构师**：维护系统、生成Cursor指令

### 2. 跨窗口记忆
- 通过进度追踪器实现跨窗口共享记忆
- 新窗口自动加载上次进度
- 不再因窗口切换而"失忆"

### 3. 多次提醒保存
- 重大更新后立即提醒
- 每5-7轮对话提醒一次
- 对话结束时最后提醒
- 防止数据丢失

## 🎓 设计理念

> **从"静态文档"到"智能系统"**

这不是简单的文档库，而是：
- 会记忆的AI系统（跨窗口记忆）
- 会思考的AI伙伴（战略参谋）
- 会进化的AI助手（持续优化）

**核心价值**：
- ✅ 不再失忆（进度追踪器）
- ✅ 主动提醒（多次保存机制）
- ✅ 角色灵活（秘书/参谋/架构师）
- ✅ 易于维护（GitHub版本控制）
- ✅ 持续进化（系统自举机制）

**业务理念**：
- ✅ 精益原则（先做MVP，再优化）
- ✅ 数据驱动（一切假设都要验证）
- ✅ AI优先（能AI的AI，能外包的外包）
- ✅ 一人公司（3人中枢 + AI + 外包 = 一人公司模式）
