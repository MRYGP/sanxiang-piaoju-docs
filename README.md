## 🚀 快速开始

### 第1步：部署AI助手系统（10分钟）

#### 1.1 配置Claude Projects

**Custom Instructions设置**：
1. 打开Claude Projects设置
2. 复制 [`00_核心文档/系统指令4.3.md`](./00_核心文档/系统指令4.3.md) 的全部内容
3. 粘贴到Custom Instructions中
4. 保存设置

**Knowledge Base设置**：
1. 上传 [`00_核心文档/00_进度追踪器.md`](./00_核心文档/00_进度追踪器.md) 到Knowledge Base
2. 这是实时更新的工作记忆，每次对话后需要保存更新

#### 1.2 测试系统

在Claude Projects中测试：
- 说："当前任务是什么？"
- 系统应该能读取进度追踪器并展示当前任务

#### 1.3 启动流程说明

**第一次使用（初始化）**：
- 系统会自动搜索进度追踪器
- 如果找不到，会在ARTIFACTS创建空白模板
- 根据你的回答初始化内容
- 记得保存到Project Knowledge

**每天第一次对话（日常启动）**：
- 系统会自动加载昨天的任务、决策、风险
- 主动问候并收集今日信息
- 给出今日建议待办

**每次新窗口（继续工作）**：
- 系统强制读取最新进度追踪器
- 根据你的第一句话决定展示方式
- 等待你的指令

> 📖 **详细启动流程**：见 [`00_核心文档/系统指令4.3.md`](./00_核心文档/系统指令4.3.md) 的"每日智能启动"和"快速启动流程"章节

## 💡 核心特性

### 1. 三重角色自动切换

- **执行秘书**：处理日常任务、生成文档
- **战略参谋**：分析问题、提供建议、预判风险
- **架构师**：维护系统、生成Cursor指令

### 2. 跨窗口记忆

- 通过进度追踪器实现跨窗口共享记忆
- 新窗口自动加载上次进度
- 不再因窗口切换而"失忆"

### 3. 多次提醒保存

- 重大更新后立即提醒
- 每5-7轮对话提醒一次
- 对话结束时最后提醒
- 防止数据丢失
