## 📖 使用说明

### 对于AI（Claude Projects）
1. 每次对话先读取 `00_核心文档/00_进度追踪器.md`
2. 基于SSOT原则，以 `8个业务清单更新版.md` 为准
3. 遵循白名单/禁用词规范
4. 技术参考：查阅 `05_参考资料/` 中的票据凭证详细文档

### 对于业务员
1. **新人必读**：先读 `02_运营体系/远期支票速成页（业务员版）.md`（3分钟快速上手）
2. 学习 `02_运营体系/展业话术大全.md`（标准话术）
3. 使用 `03_工具包/` 中的素材
4. 按照 `04_SOP标准流程/TODO_待创建/SOP03_远期支票收出操作清单.md` 填写业务信息
5. 遵循合规要求
