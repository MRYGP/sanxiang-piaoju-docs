## 💡 核心特性

### 1. 三重角色自动切换

- **执行秘书**：处理日常任务、生成文档
- **战略参谋**：分析问题、提供建议、预判风险
- **架构师**：维护系统、生成Cursor指令

### 2. 跨窗口记忆

- 通过进度追踪器实现跨窗口共享记忆
- 新窗口自动加载上次进度
- 不再因窗口切换而"失忆"

### 3. 多次提醒保存

- 重大更新后立即提醒
- 每5-7轮对话提醒一次
- 对话结束时最后提醒
- 防止数据丢失

## 📊 使用场景

### 老板日常工作流

**早上 9:00**：

- 打开Projects → AI自动加载进度
- 询问："当前任务是什么？"
- AI汇报任务状态，提醒紧急事项

**工作中**：

- 需要决策："XX和XX，选哪个？给我建议"
- 需要文档："帮我写XX文档"
- 需要分析："分析一下XX的风险"

**晚上 18:00**：

- 说："帮我做今日总结"
- AI更新进度追踪器
- AI提醒明天待办事项

### 业务场景示例

**招聘场景**：

- "帮我准备网站运营专员的面试清单"
- "分析候选人A和B，哪个更合适？"
