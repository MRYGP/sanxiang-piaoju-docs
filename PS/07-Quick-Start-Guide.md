## 🎯 快速上手三步走

### 第1步：设置PROJECTS（5分钟）

#### 1.1 打开Claude.ai
1. 访问 https://claude.ai
2. 登录账号
3. 点击左上角 "Projects"

#### 1.2 创建新Project
1. 点击 "+ New Project"
2. 项目名称：`AI秘书系统`
3. 点击 "Create project"

#### 1.3 添加Custom Instructions
1. 点击 "Project settings"（右上角齿轮图标）
2. 找到 "Custom instructions" 区域
3. 打开文件 `01-PROJECTS-Core-Instructions.md`
4. 复制全部内容，粘贴到 Custom instructions
5. 点击 "Save"

#### 1.4 上传知识库文件
1. 在Project界面，点击 "Add content" → "Upload files"
2. 上传以下文件：
   - `02-Progress-Tracker-Template.md`（进度追踪器）
   - 其他业务相关文档
3. 点击 "Done"

#### 1.5 初始化进度追踪器
1. 在Project中开启新对话
2. 说："初始化进度追踪器，当前任务是：[描述你的任务]"
3. AI会自动创建并更新进度追踪器

---

### 第2步：测试系统（3分钟）

#### 测试1：记忆功能
**你说**："当前有什么任务？"  
**AI应该回答**：显示完整进度追踪器（右侧ARTIFACTS面板）

✅ 如果显示正确 → 系统正常  
❌ 如果不知道 → 检查进度追踪器是否上传

#### 测试2：秘书功能
**你说**："帮我做一个XXX清单"  
**AI应该**：立即生成清单

✅ 如果生成清单 → 系统正常  
❌ 如果问东问西 → 检查Custom Instructions是否粘贴完整

#### 测试3：参谋功能
**你说**："XX和XX，我应该选哪个？给我建议"  
**AI应该**：分析优劣，给出推荐理由

✅ 如果给出分析 → 系统正常  
❌ 如果没有分析 → 重新检查Custom Instructions

## 📋 日常使用流程

### 老板的每日工作流

#### 早上（9:00）：启动工作日
1. 打开Projects → `AI秘书系统`
2. 开启新对话
3. AI在后台自动加载进度追踪器（强制执行，100%加载完整记忆）
4. 根据你的第一句话，AI会智能展示：
   - **如果你问**："当前任务是什么？" → 显示完整进度追踪器（右侧ARTIFACTS面板）
   - **如果你说**："我们讨论一下XXX" → 简短摘要（3-5句）+ 直接进入话题
   - **如果你说**："帮我做XXX" → 一句确认 + 直接开始任务
5. AI给出建议和优先级

#### 工作中（随时）：处理任务
- 需要招聘：说"帮我准备XX岗位的面试清单"
- 需要决策：说"给我分析一下XX和XX，哪个更好？"
- 需要文档：说"帮我写一个XX文档"
- 需要提醒：说"记录一下，明天要XX"

#### 晚上（18:00）：总结一天
1. 说："帮我做今日总结"
2. AI总结今天完成的任务
3. AI更新进度追踪器
4. AI提醒明天要做的事

#### 新窗口（继续工作）
1. 开启新对话
2. AI自动读取进度追踪器
3. AI说："我已加载记忆，当前有X个任务进行中"
4. 你继续工作，无缝衔接

## 🔧 常见问题FAQ

### Q1：AI怎么知道之前的事情？
**A**：通过进度追踪器。每次对话结束，AI都会更新进度追踪器。新窗口启动时，AI会读取进度追踪器，所以能记得之前的事。

### Q2：如果AI忘记了之前的事怎么办？
**A**：检查两个地方：
1. 进度追踪器是否上传到知识库
2. Custom Instructions是否正确设置

如果都正常，对AI说："读取进度追踪器"，它会重新加载。

### Q3：员工能访问PROJECTS吗？
**A**：不建议。PROJECTS是老板的专属空间，里面有敏感信息（候选人评估、业务决策等）。

员工只需要用AI Studio + 三套提示词就够了。

### Q4：进度追踪器在哪里？怎么查看？
**A**：
- 在PROJECTS的Knowledge Base里
- 或在对话中的ARTIFACTS面板（右侧）
- 你可以随时下载查看或手动编辑

### Q5：AI Studio和PROJECTS有什么区别？
**A**：
| 项目 | AI Studio | PROJECTS |
|------|----------|----------|
| 工具 | Google AI Studio | Claude Projects |
| 用户 | 员工使用 | 老板使用 |
| 功能 | 执行层（完成任务） | 管理层（决策+培训） |
| 提示词 | 3套专用提示词 | 核心指令+知识库 |
| 记忆 | 单次对话 | 跨对话记忆 |

### Q6：三套AI提示词，员工应该怎么选？
**A**：
- 第1周：只用"业务培训助手"学基础
- 第2周：开始用"个人秘书"提高效率
- 第2周起：遇到问题用"思考教练"分析
- 长期：主要用"个人秘书"，其他两个辅助

### Q7：如果员工说AI没用怎么办？
**A**：检查3个问题：
1. 提示词粘贴完整了吗？
2. 员工真的在用吗？（不是试一次就放弃）
3. 员工会提问吗？（问题太笼统AI答不好）

建议：让员工先用"个人秘书"，每天规划工作和生成话术，这个最直接有用。

### Q8：系统需要维护吗？
**A**：需要定期维护（建议每周五）：
1. 检查进度追踪器，清理已完成任务
2. 补充新的案例和经验到知识库
3. 根据实际情况优化提示词
4. 收集员工反馈，改进系统

### Q9：为什么AI要多次提醒保存？
**A**：因为ARTIFACTS面板的内容不会自动同步到知识库。多次提醒机制能确保：
- 即使对话中断，最多只丢失最近几轮
- 不会因为忘记保存而丢失所有更新
- 给你"保存检查点"的意识

## ⚡ 关键提醒

### ✅ 五个必做
1. **必做1**：Custom Instructions一定要完整粘贴
2. **必做2**：进度追踪器一定要上传到知识库
3. **必做3**：每次对话结束，AI会多次提醒保存，记得保存！
4. **必做4**：培训员工时，一定要让他们实操，不是听懂就行
5. **必做5**：定期（每周）维护系统，清理过时信息

### ❌ 五个不要
1. **不要**把PROJECTS的账号密码给员工
2. **不要**在PROJECTS里讨论敏感个人信息
3. **不要**期待AI完美无误（重要决策要复查）
4. **不要**让员工依赖AI做决策（AI是辅助工具）
5. **不要**忘记保存进度追踪器（否则AI会"失忆"）
