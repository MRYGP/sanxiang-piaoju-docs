## 📝 模板1：文档修改工作流程

### 使用场景
修改现有文档内容（如业务优先级、费用数据、定位描述等）

### 标准流程

```markdown
## 任务：修改[具体内容]

### Step 1：理解任务
- [ ] 明确修改目标
- [ ] 理解业务逻辑
- [ ] 识别影响范围

### Step 2：搜索先行
- [ ] 搜索相关文档（grep/codebase_search）
- [ ] 查找已有信息
- [ ] 建立信息地图

### Step 3：影响分析
- [ ] 列出所有可能受影响的文档
- [ ] 使用对应的检查清单
- [ ] 建立修改优先级

### Step 4：系统性执行
- [ ] 按优先级逐个修改
- [ ] 确保一致性
- [ ] 记录修改内容

### Step 5：验证与反思
- [ ] 完整性验证（检查清单）
- [ ] 一致性检查（grep验证）
- [ ] 反思与改进（记录错误）
```

## 📝 模板2：新文档创建工作流程

### 使用场景
创建新文档（如新业务说明、新SOP、新话术等）

### 标准流程

```markdown
## 任务：创建[文档名称]

### Step 1：确定文档定位
- [ ] 文档用途是什么？
- [ ] 应该放在哪个目录？
- [ ] 命名规范是什么？

### Step 2：查找参考文档
- [ ] 搜索类似文档作为参考
- [ ] 了解文档结构和格式
- [ ] 确定内容框架

### Step 3：创建文档
- [ ] 使用标准格式
- [ ] 包含必要信息（版本、日期、用途）
- [ ] 遵循命名规范

### Step 4：更新索引
- [ ] 更新相关索引文档
- [ ] 更新进度追踪器
- [ ] 更新文档关联关系

### Step 5：验证
- [ ] 文档路径是否正确？
- [ ] 内容是否完整？
- [ ] 格式是否规范？
```

## 📝 模板3：批量修改工作流程

### 使用场景
需要修改多个文档的相同内容（如统一术语、统一格式）

### 标准流程

```markdown
## 任务：批量修改[具体内容]

### Step 1：全局搜索
- [ ] 使用grep搜索所有出现的地方
- [ ] 列出所有需要修改的文件
- [ ] 分析修改范围

### Step 2：制定修改策略
- [ ] 确定修改规则（统一标准）
- [ ] 识别特殊情况（需要单独处理）
- [ ] 建立修改顺序

### Step 3：批量执行
- [ ] 使用replace_all（如适用）
- [ ] 逐个文件修改（如需要上下文）
- [ ] 记录修改内容

### Step 4：验证
- [ ] 再次grep搜索，确认已全部修改
- [ ] 检查是否有遗漏
- [ ] 验证修改是否正确
```

## 📝 模板4：信息查找工作流程

### 使用场景
需要查找某个信息（如公司地址、业务费用、工作流程）

### 标准流程

```markdown
## 任务：查找[具体信息]

### Step 1：多维度搜索
- [ ] 使用grep搜索关键词
- [ ] 使用codebase_search语义搜索
- [ ] 检查相关文档目录

### Step 2：验证信息
- [ ] 找到的信息是否最新？
- [ ] 是否有多个版本？
- [ ] 哪个是权威来源（SSOT）？

### Step 3：记录信息
- [ ] 记录信息位置
- [ ] 记录信息来源
- [ ] 如有冲突，记录并询问

### Step 4：使用信息
- [ ] 直接使用找到的信息
- [ ] 不要留空让用户填写
- [ ] 如有不确定，先搜索再问
```

## 📝 模板5：任务完成反思模板

### 使用场景
每次任务完成后，强制执行反思

### 反思内容

```markdown
## 任务完成反思

### 任务信息
- **任务名称**：[具体任务]
- **完成时间**：[日期时间]
- **修改的文件**：[列出所有文件]

### 完成情况
- [ ] 所有目标是否达成？
- [ ] 是否有遗漏？
- [ ] 是否有错误？

### 错误分析
**错误1**：[具体错误]
- **原因**：[为什么会犯这个错误]
- **影响**：[造成了什么影响]
- **改进**：[下次如何避免]

**错误2**：[如有]
- **原因**：[分析]
- **影响**：[分析]
- **改进**：[措施]

### 经验总结
**做得好的地方**：
- [具体做法]

**需要改进的地方**：
- [具体改进措施]

### 更新清单
- [ ] 更新"常见错误清单"（如有新错误）
- [ ] 更新"最佳实践清单"（如有新实践）
- [ ] 更新"文档关联关系图"（如有新关联）
```

## 📝 模板6：文档同步验证模板

### 使用场景
修改多个相关文档后，验证是否同步

### 验证清单

```markdown
## 文档同步验证

### 修改内容
- **修改项**：[具体内容]
- **修改范围**：[哪些文档]

### 验证方法
- [ ] 使用grep搜索关键词，确认所有地方都已修改
- [ ] 检查是否有其他表述方式（如"中介"vs"合作方"）
- [ ] 检查是否有遗漏的文档

### 验证结果
**已修改的文档**：
- [文件1] ✅
- [文件2] ✅
- [文件3] ✅

**需要修改但未修改的文档**：
- [文件4] ❌ （原因：xxx）

**验证通过**：✅/❌
```
