# A业务合伙人培训要点

## 培训目标
30分钟学会，当天就能开始找客户

---

## 核心认知（5分钟）

### 你的角色
- 你是**获客者**，不是票据专家
- 你只需要：找客户 → 收截图 → 拉群
- 专业的事交给冷部

### 你不需要懂
- 票据专业知识
- 报价计算
- 背书操作
- 风险判断

### 你需要懂
- 什么样的人可能有票（中小企业、贸易、工程）
- 怎么开口问（话术）
- 怎么拉群（流程）

---

## 操作流程（10分钟）

### 标准流程
```
发现客户 → 要截图 → 拉群 → 等成交 → 拿提成
```

### 拉群模板
- 群名：XX公司-票据业务
- 成员：客户、你、三湘管理员、冷部

### 群内规则
- 不抢话，让冷部主导
- 客户问你问题，不确定就说"群里老师更专业，@冷部帮忙解答"

---

## 获客技巧（10分钟）

### 哪里找客户
| 渠道     | 说明                 |
| -------- | -------------------- |
| 现有人脉 | 做生意的朋友、老客户 |
| 企业财务 | 会计、出纳、财务经理 |
| 同行异业 | 贷款中介、财税公司   |
| 线上渠道 | 朋友圈、企业社群     |

### 开口话术
> "最近有帮朋友处理承兑汇票，比银行快很多。你们公司有收到票吗？"

### 判断意向
- 高意向："有的，正好有一张"
- 中意向："偶尔有，现在没有"
- 低意向："我们不收票"

---

## 收益说明（3分钟）

| 票据类型 | 你的提成/10万 |
| -------- | ------------- |
| 银承     | 50元          |
| 商承     | 100元         |
| 凭证     | 100-200元     |

### 举例
- 客户贴100万银承 → 三湘赚500元 → 你的提成从中支付
- 一个月做10单×50万 → 月入可观
- 找到稳定客户 → 持续复购收益

### 结算
- 月结，每月固定日发放
- 客户绑定你，复购提成都是你的

---

## 常见问题（2分钟）

### "客户问价格我怎么说？"
> "价格要看具体的票，您发截图我马上帮您问。"

### "客户说太贵了怎么办？"
> "比银行贵一点，但快很多，急用钱的时候划算。"

### "客户不信任怎么办？"
> "可以来我们办公室，或者我们派人过去。"
