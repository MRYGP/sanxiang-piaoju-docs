# A业务风险红线

## 🔴 绝对禁止（触犯可能违法）

| 红线             | 说明                         |
| ---------------- | ---------------------------- |
| ❌ 伪造票据       | 任何形式的假票、变造票       |
| ❌ 客户主资金走私账 | 客户打款、收款必须公对公（票面金额的进出） |
| ❌ 承诺固定收益   | 不能说"保证省X%"、"固定收益" |
| ❌ 无真实贸易背景 | 票据必须基于真实交易         |
| ❌ 代客户操作网银 | 可以教，但不能代操作         |

---

## 💡 关于"公对公"的说明

**核心原则**：客户的票面金额必须公对公，扣款可以灵活处理。

**实际操作**：
- 客户把100万票背书给冷部 ✅
- 冷部打100万到客户对公户 ✅（公对公，平进平出）
- 扣款500元，客户用私户/微信转给冷部 ✅（这是合规的）
- 或者：冷部直接打99.95万，扣掉500元 ✅（更简单）

**为什么这样做**：
- 客户账面上"票进钱出"金额一致，好做账
- 扣款单独走，灵活方便

**合伙人不用管这些细节，冷部会处理。**

## 🟡 高度注意（可能引发纠纷）

| 风险点         | 正确做法                              |
| -------------- | ------------------------------------- |
| 报价不是最终价 | 说明"以冷部最终报价为准"              |
| 到账时间不确定 | 说"通常10分钟-2小时"，不说"保证X分钟" |
| 背书瑕疵       | 让冷部判断，不自己承诺"没问题"        |
| 客户信息保密   | 不在群外泄露客户信息                  |

---

## 🟢 合规操作（正确姿势）

| 场景 | 合规做法                    |
| ---- | --------------------------- |
| 客户收款 | 公对公转账，保留凭证        |
| 扣款处理 | 两种方式：①直接从票面金额扣除（推荐）②客户用私户/微信单独转扣款给冷部 |
| 说明 | 客户的"票面金额"走公对公，"扣款"可以单独私转，账面上平进平出 |
| 合同 | 有需要时可签服务协议        |
| 发票 | 按实际服务开具              |
| 记录 | 保留聊天记录、转账记录      |

## ⚠️ 话术禁用词

| 禁用       | 替代                     |
| ---------- | ------------------------ |
| "保证到账" | "通常10分钟-2小时"       |
| "零风险"   | "基于银行承兑，风险可控" |
| "100%安全" | "公对公操作，凭证可追溯" |
| "固定省X%" | "以实际报价为准"         |
