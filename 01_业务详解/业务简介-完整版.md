## A业务：票据/凭证贴现（变现）

### 一句话描述
企业手上有票据/凭证（银票、商票、云信、航信等），需要提前变现，我们帮企业快速换成现金，赚差价。

### 客户痛点分析

**核心痛点**：企业有票据/凭证但等不到期，急需现金周转

**典型痛点场景**：
1. **现金流紧张**：
   - 收到客户100万半年期银票,但本月要发工资/付货款
   - 账面有钱(票据),但无法立即使用
   - 银行贷款来不及/批不下来

2. **机会成本**：
   - 有好的投资机会,但资金被票据锁住
   - 供应商给现金折扣优惠,想提前变现省钱

3. **财务优化**：
   - 想优化财务报表,把"应收票据"变成"货币资金"
   - 季度/年度末财务优化需求

### 客户画像

**高频客户**：
- 制造企业（下游用票付款多）
- 贸易公司（大量票据流转）
- 建筑企业（工程款回款常用票据）
- 批发商（上游给票,下游要现金）

**企业特征**：
- 年营业额：500万以上
- 经营年限：1年以上
- 票据持有量：月均5-100张不等
- 现金流状况：常有周转压力

### 核心卖点（对客户的价值）

1. **快速到账**：最快当天/T+1到账（看票据类型）
2. **价格透明**：报价清晰,按市场行情定价
3. **手续简单**：提供票据信息即可报价,对公转账安全
4. **灵活度高**：可以单张收,也可以批量收

### 开场沟通话术

**第一次接触（陌生客户）**：
```
"X总您好,我是三湘票据的XXX。

请问贵公司平时有收到票据/凭证吗？
（如银行承兑汇票、商业承兑汇票、云信、航信等）

如果有急需用钱的情况，
我们可以帮您快速贴现变现，
通常当天或T+1就能到账。

方便的话，我可以简单介绍一下我们的服务？"
```

**第二次接触（有初步了解）**：
```
"X总，上次聊到您公司有票据贴现需求。

请问您手上现在有要贴现的票据吗？
可以发票面信息给我，我马上给您报个价？

我们这边：
✅ 支持19类票据/凭证（银票、商票、各类电子凭证）
✅ 报价透明、当天回复
✅ 最快当天到账

您看什么时候方便，我给您详细介绍？"
```

### 核心问题（判断客户需求）

**必问问题（判断是否符合）**：
1. "您公司平时有收到票据/凭证吗？" → 判断是否有货源
2. "票据类型是什么？金额大概多少？" → 判断具体需求
3. "您一般什么时候需要变现？" → 判断紧急程度
4. "票面信息方便发我看看吗？" → 获取详细信息

**追问问题（深挖需求）**：
5. "您手上这种票据大概一个月有多少张？" → 判断是否是长期客户
6. "之前有用过贴现服务吗？在哪家？" → 了解竞品情况
7. "您一般什么价格可以接受？" → 了解价格敏感度

### 常见异议处理

**异议1**："你们价格会不会比银行贵？"
```
回应：
"X总,我们的价格是根据票据类型、期限、承兑人信用来定的,
通常与银行贴现价格接近,甚至某些情况下更优惠。

关键是我们的优势在于：
1. 速度快：通常当天/T+1到账（以票种/额度/通道为准），银行通常要3-7天
2. 灵活：单张也收,银行通常要批量
3. 服务好：一对一服务,随时沟通

您可以先让我报个价,对比一下？"
```

**异议2**："票据安全吗？"
```
回应：
"X总,票据的安全性主要看：
1. 票据本身真实性（我们会核验）
2. 交易方式（全程公对公转账,有合同保障）

我们做这个业务10年了,流程非常规范：
✅ 先验票真实性
✅ 签订正规合同
✅ 公对公转账
✅ 票款同步交割

完全可以放心。"
```

**异议3**："我们票据量不大,你们收吗？"
```
回应：
"当然收！我们单张票也做。

只要票据真实、承兑人信用OK,
无论金额大小我们都可以帮您处理。

您可以先发票面信息给我,
我给您报个价,您看合适再做,
没有任何额外费用。"
```

### 移交标准（什么时候移交总部/冷部）

**立即移交**：
- 客户发来票面信息,需要报价
- 客户明确表示要贴现
- 票据类型不确定,需要专业判断

**暂不移交,继续跟进**：
- 客户只是咨询,还在比较
- 客户暂时没有票据
- 客户表示下次有需求再联系

**记录并定期回访**：
- 客户表示有需求但不急
- 客户在观望市场行情
- 客户说"过段时间有票"

### 风险提示（业务员必知）

**红线（绝对不能做）**：
- ❌ 不承诺"固定价格/保证收益"
- ❌ 不参与伪造票据、虚假票据
- ❌ 不做私下交易（必须公对公）
- ❌ 不承诺"100%安全/零风险"

**灰色地带（需要请示）**：
- 票据金额特别大（>500万）
- 票据类型不常见
- 客户有特殊要求（如加急、指定时间到账）
- 承兑人信用存疑

## B业务：承兑/凭证销售（企业付款成本优化）

### 一句话描述
企业要付货款/工程款,不想全用现金,我们提供票据/凭证,企业用票付款,比现金省钱,我们赚差价。

### 客户痛点分析

**核心痛点**：企业要付大额款项,现金流压力大,想降低付款成本

**典型痛点场景**：
1. **现金流压力**：
   - 每月要付100万货款给供应商
   - 账上现金紧张,但不想贷款（利息高）
   - 想用部分票据+部分现金组合支付

2. **成本优化**：
   - 供应商接受票据付款
   - 用票付款比现金便宜0.4%-8%（年化）
   - 一年能省几万到几十万

3. **资金周转**：
   - 回款慢但支付压力大
   - 想把有限现金用在刀刃上
   - 票据能延后真实现金支出时间

### 客户画像

**高频客户**：
- 制造企业（要付原材料款/设备款）
- 贸易公司（要付采购款）
- 建筑企业（要付材料款/分包款）
- 批发商（要付上游货款）

**企业特征**：
- 月付款额：50万以上
- 供应商：愿意接受票据付款（或可以协助开通凭证账户）
- 财务压力：有现金周转压力或想优化成本
- 企业和供应商：已开通或愿意开通凭证账户（每种凭证有独有的支付平台）

### 核心卖点（对客户的价值）

1. **降低付款成本**：用票付款通常能节省0.4%-8%成本（年化）
2. **缓解现金压力**：不用一次性支付全额现金
3. **供应商满意**：供应商收到足额票据,账面不受损
4. **合规安全**：全程公对公操作,有合同保障

### 开场沟通话术

**第一次接触（直接切入）**：
```
"X总您好,我简单问一句：

您公司平时付货款给供应商,
是一定要全现金,还是可以接受一部分用票据/凭证来付？

如果可以接受,我们可以帮您优化付款结构,
通常能节省0.4%-8%的付款成本（年化,具体以市场为准）,
比银行贷款便宜多了。

方便的话,我给您详细介绍一下？"
```

**第二次接触（有初步了解）**：
```
"X总,上次聊到您有大额付款需求。

我这边简单说一下我们的服务：

您要付100万货款,传统方式是转100万现金。

我们的方式是：
1. 您先付99.6万现金给我们（举例,实际看市场）
2. 我们给您100万票据/凭证
3. 您用这100万票付给供应商
4. 供应商收到100万（满意）
5. 您实际只花99.6万（省0.4万,年化节省0.8%）

⚠️ 重要提醒：
- 企业必须先付现金给我们,我们才给票据/凭证
- 节省成本为示例区间,不构成刚性承诺

这个方案您看怎么样？"
```

### 核心问题（判断客户需求）

**必问问题（判断是否符合）**：
1. "您公司平时有大额付款需求吗？每月大概多少？" → 判断业务量
2. "供应商接受票据/凭证付款吗？" → 判断可行性
3. "您和供应商是否开通了凭证账户？" → 判断技术条件（每种凭证有独有的支付平台，需要双方都开通）
4. "您能先付现金给我们，我们再给您票据/凭证吗？" → 核心要求确认

**追问问题（深挖需求）**：
5. "您现在付款方式是什么？全现金还是有用票？" → 了解现状
6. "您每月大概有多少笔付款？" → 判断业务规模
7. "您希望节省多少成本？" → 了解价格敏感度

### 常见异议处理

**异议1**："供应商不收票怎么办？"
```
回应：
"X总,这个确实是关键。

我们的经验是：
1. 大部分企业其实都接受票据（这是常见支付方式）
2. 如果供应商没开通凭证账户,我们可以协助开通（免费）
3. 您可以先跟供应商沟通一下意愿

如果供应商完全不接受,
我们还有其他方案（如部分现金+部分票据）

要不要我先给您一个跟供应商沟通的话术模板？"
```

**异议2**："票据安全吗？供应商会担心吗？"
```
回应：
"X总,票据的安全性主要看承兑人信用：

1. 银行承兑汇票：银行担保,最安全
2. 商业承兑汇票：企业担保,看企业信用
3. 电子凭证：合同化、留痕机制,可控

我们提供的都是正规票据/凭证：
✅ 供应商收到后可以到期兑现
✅ 也可以提前找我们贴现变现
✅ 全程公对公操作,有合同保障

供应商账面上收到的是100万,
并不吃亏。"
```

**异议3**："我们现金不够,能不能先给票再付钱？"
```
回应：
"X总,非常抱歉,这个我们做不了。

我们的业务流程是：
❌ 不能先给票后付钱（风险太大）
✅ 必须先收到您的现金,我们再给您票据

这是行业规则,也是保护双方的方式。

如果您现金确实紧张,
可以考虑：
1. 先做小额测试（如先付10万,我们给10万票）
2. 或者我们看看能不能分批次处理

您看这样可以吗？"
```

### 移交标准（什么时候移交总部/冷部）

**立即移交**：
- 客户明确表示要买票/凭证
- 客户询问具体报价
- 客户要付款但有特殊要求

**暂不移交,继续跟进**：
- 客户还在考虑
- 客户要先跟供应商确认
- 客户说"下次有需求再联系"

**记录并定期回访**：
- 客户有意向但不急
- 客户在比较不同服务商
- 客户说"过段时间再说"

### 风险提示（业务员必知）

**红线（绝对不能做）**：
- ❌ 不承诺"固定节省成本/保证省钱"
- ❌ 不承诺"先给票后付钱"（核心红线！）
- ❌ 不做私下交易（必须公对公）
- ❌ 不承诺"100%安全/零风险"

**灰色地带（需要请示）**：
- 付款金额特别大（>500万）
- 客户要求特殊票据类型
- 供应商完全不接受票据
- 客户资金情况存疑

## C业务：冲存款（银行存款任务撮合）

### 一句话描述
银行网点有存款任务,企业主有闲置资金或想维护银行关系,我们撮合双方,赚居间服务费。

### 客户痛点分析

**核心痛点**：银行网点有存款考核压力,需要企业帮忙冲时点

**典型痛点场景**：
1. **银行求企业帮忙**：
   - 月末/季末/年末存款考核压力大
   - 银行客户经理求企业主帮忙存一笔
   - 企业主想维护银行关系（为了后续贷款/授信）

2. **企业维护银行关系**：
   - 企业有贷款需求,银行要求"存款换贷款"
   - 企业想在银行办其他业务,需要维护关系
   - 企业老板跟银行关系好,愿意帮忙

3. **闲置资金利用**：
   - 企业有短期闲置资金（1天-1个月）
   - 想赚点利息收益
   - 又不想锁定太久

### 客户画像

**高频客户**：
- 有银行关系维护需求的企业主
- 手上有闲置资金的企业老板
- 想办贷款/授信但银行要求"先存款"的企业
- 老板跟银行客户经理关系好的企业

**企业特征**：
- 资金量：50万-5000万不等
- 存款时间：1天-1个月
- 目的：维护银行关系或赚取利息
- 资金性质：合法、干净、可追溯

### 核心卖点（对客户的价值）

1. **维护银行关系**：帮银行完成任务,后续办事方便
2. **赚取利息**：短期存款也有利息收益
3. **资金安全**：钱在银行账户,不过我们的手
4. **撮合服务**：我们对接资金方和银行,省心省力

### 开场沟通话术

**第一次接触（判断需求）**：
```
"X总您好,我这边是做企业资金服务的。

请问您公司有跟银行合作吗？
银行有没有让您帮忙完成存款任务？

我们专门做这个撮合服务,
可以帮您对接资金方,
既能帮银行完成任务,
您还能赚点服务费/利息。

方便的话,我简单介绍一下？"
```

**第二次接触（有初步了解）**：
```
"X总,上次聊到您有银行关系维护需求。

我这边简单说一下我们的服务：

如果银行需要您帮忙存款（如月末冲时点）,
我们可以帮您对接资金方：

1. 我们找资金方（有闲置资金的企业）
2. 资金方把钱存入您指定的银行账户
3. 存款时间：1天-1个月不等（看需求）
4. 您付给资金方服务费（市场价万5-千1/天）
5. 银行任务完成,您的关系维护好了

全程资金不过我们的手,
我们只是撮合服务。

您看这个方案怎么样？"
```

### 核心问题（判断客户需求）

**必问问题（判断是否符合）**：
1. "银行有没有让您帮忙存款？" → 判断需求真实性
2. "需要存多少金额？存多久？" → 判断具体需求
3. "您愿意为这个服务付费吗？" → 判断付费意愿
4. "您有维护银行关系的需求吗？" → 判断核心动机

**追问问题（深挖需求）**：
5. "您跟哪个银行合作？具体哪个网点？" → 获取详细信息
6. "银行客户经理叫什么名字？" → 确认真实性
7. "您之前有做过这个吗？" → 了解经验

### 常见异议处理

**异议1**："这个合规吗？"
```
回应：

核心是：
1. 真实的资金（来源合法）

3. 正常的居间服务（我们撮合，收服务费）

- 不同银行要求不同

```

```
举例：

具体价格看：

2. 存款时间
3. 市场行情

```

**异议3**："资金安全吗？"
```
回应：
"X总,资金安全完全没问题。
```

```
✅ 必须有真实合同和资金流

如果您不能接受这些要求,
那我们可能帮不上忙。

但如果您能接受真实贸易,
我们可以帮您设计合规的方案,
既能做大贸易规模,又完全合法合规。

您看您能接受真实贸易的要求吗？"
```

### 移交标准（什么时候移交总部/贸易合作方）

**立即移交**：
- 客户明确表示需要做大贸易量
- 客户有明确用途和时间要求
- 客户询问具体方案和报价

**暂不移交,继续跟进**：
- 客户还在考虑
- 客户要先研究一下
- 客户说"有需求再联系"

**记录并定期回访**：
- 客户有潜在需求但不急
- 客户在比较不同方案
- 客户表示"以后可能需要"

### 风险提示（业务员必知）

**红线（绝对不能做）**：
- ❌ 不参与虚构贸易、虚假贸易
- ❌ 不参与虚开发票、虚假流水
- ❌ 不承诺"保证完成贸易规模"
- ❌ 不做"无真实货物"的纯流水包装

**灰色地带（需要请示）**：
- 客户要求特别大的贸易规模
- 客户贸易用途不明确
- 客户有特殊操作要求
- 客户对合规要求理解不清

## 📊 附录：业务员提成机制详解

### 提成比例

**一级业务员（您直接推荐的客户）**：
- 您的提成：30%
- 平台：70%

**二级业务员（您发展的业务员推荐的客户）**：
- 二级业务员提成：30%
- 您的额外提成：总利润的10%（强激励，刺激推荐）
- 后续目标客户成交：推荐人每笔成交，您都可以获得总利润的10%（长期有效）
- 平台：剩余利润

### 提成计算示例

**示例1：一级业务员**
```
客户成交金额：100万
平台利润：1万元

您的提成：1万 × 30% = 3000元
平台收入：1万 × 70% = 7000元
```

**示例2：二级业务员（首次成交）**
```
客户成交金额：100万
平台利润：1万元

二级业务员提成：1万 × 30% = 3000元
您的额外提成：1万 × 10% = 1000元（总利润的10%）
平台收入：1万 - 3000元 - 1000元 = 6000元
```

**示例3：二级业务员（后续目标客户成交）**
```
二级业务员又成交了新客户
客户成交金额：100万
平台利润：1万元

二级业务员提成：1万 × 30% = 3000元
您的额外提成：1万 × 10% = 1000元（长期有效，每笔都有）
平台收入：1万 - 3000元 - 1000元 = 6000元
```

### 提成发放

✅ 提成直接打到各自银行卡
✅ 不经过一级业务员（避免代收纠纷）
✅ 每月15日统一发放上月提成

### 防作弊机制

**客户归属认证**：
- 客户首次移交时，总部回访确认"谁介绍的"
- 客户自己说是谁介绍的（一级无法冒领）
- 系统记录并锁定归属关系

**实名认证**：
- 每个业务员必须实名认证
- 二级业务员必须有独立账号
- 不能用一级账号代注册

**违规处理**：
- 如发现虚构二级业务员：
  - 没收该笔提成
  - 追回历史3个月提成
  - 永久封号

### 常见问题

**Q1：我发展的二级业务员，我能拿多少？**
A1：二级业务员每笔成交，您额外获得总利润的10%，长期有效。后续目标客户的成交都可以有这样的分润。

**Q2：如果二级业务员不认我怎么办？**
A2：我们有客户归属认证机制，客户会说是谁介绍的，有据可查。

**Q3：我能代收二级业务员的提成吗？**
A3：不能。提成直接打各自银行卡，避免纠纷。
