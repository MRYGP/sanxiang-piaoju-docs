# 业务简介 - 极简版（一线业务员速查本）

> **版本**：v1.0  
> **更新日期**：2025-11-19  
> **适用对象**：一线业务员（特别是新手兼职业务员）  
> **用途**：现场照着念，不需要深度理解业务原理

---

## 📖 使用说明

### 这是什么？

这是一份"剧本"，你只需要：
1. **找对场景**：判断客户可能需要哪个业务
2. **照着念**：把对应的话术念给客户听
3. **问对问题**：根据客户回答，判断是否移交总部
4. **记录移交**：符合条件的客户，立即移交

### 不需要理解什么？

- ❌ 不需要懂业务原理
- ❌ 不需要懂痛点分析
- ❌ 不需要懂客户画像
- ❌ 不需要深度回答客户疑问

### 只需要做什么？

- ✅ 照着念开场白
- ✅ 问对核心问题
- ✅ 判断是否符合移交标准
- ✅ 符合就移交，不符合就记录

## A业务：票据/凭证贴现（变现）

### 📱 开场白（照着念）
```
"X总您好！

请问您公司有收到票据/凭证吗？
（如银行承兑汇票、商业承兑汇票、云信、航信等）

如果有急需用钱的情况，
我们可以帮您快速贴现变现，
通常当天或T+1就能到账。

您现在有要贴现的票据吗？"
```

### ❓ 核心问题（照着问）
1. "您现在有票据吗？"
2. "票据类型是什么？金额多少？"
3. "什么时候需要变现？"

### ✅ 移交标准（符合就移交）
- 客户说"有票据要贴现" → **立即移交总部**
- 客户发来票面信息 → **立即移交总部**
- 客户问"价格多少" → **立即移交总部**

### ⏸️ 暂不移交（记录下来）
- 客户说"暂时没有票据" → 记录，定期回访
- 客户说"过段时间有" → 记录，定期回访
- 客户说"我考虑一下" → 记录，定期回访

## 💡 使用技巧

### 技巧1：不要一次性问完所有业务
- ❌ 不要说："我们有A、B、C、D、E、F、G、H业务，您需要哪个？"
- ✅ 根据客户行业和初步沟通，选择2-3个最可能相关的业务询问

### 技巧2：用口语化表达
- ❌ 不要说："我们提供票据贴现服务"
- ✅ 说："您有票据要变现吗？我们可以帮您"

### 技巧3：记录是关键
- ✅ 每次沟通后，立即记录客户信息
- ✅ 符合条件的客户，立即移交
- ✅ 不符合的客户，记录下来定期回访

### 技巧4：不懂就不要解释
- ❌ 不要不懂装懂，乱解释
- ✅ 遇到不懂的问题，说："这个我需要问一下总部，我马上给您回复"
- ✅ 然后立即咨询业务主管或总部

## 📞 遇到问题怎么办？

### 情况1：客户问的问题你不懂
**标准回答**：
```
"X总，这个问题我需要请示一下总部，
确保给您准确的信息。
我马上问清楚，5分钟内回复您。"
```

### 情况2：客户要求特殊操作
**标准回答**：
```
"X总，您这个需求我需要跟总部确认一下，
看看能不能做。
我马上问清楚，给您回复。"
```

### 情况3：客户质疑合规性
**标准回答**：
```
"X总，我们所有业务都是合规合法的，
全程公对公操作，有合同保障。
具体合规细节，我让总部专业人员给您解释。"
```

### 情况4：客户砍价
**标准回答**：
```
"X总，具体价格我们总部会根据您的情况报价，
我现在还不能确定。
您可以先把需求告诉我，
我让总部给您一个详细报价。"
```
