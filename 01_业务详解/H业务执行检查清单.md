- [ ] 已准备"测额小程序"或相关工具

### 1.2 后端资源确认

- [ ] **后端合作方已确认**：________________
- [ ] **联系方式已获取**：________________
- [ ] **费用标准已确认**：流水的千分之____
- [ ] **银行渠道已确认**：________________
- [ ] **合同模板已准备**：________________
- [ ] **对接流程已明确**：________________

### 1.3 工具准备

- [ ] 朋友圈文案库（至少20条）
- [ ] 客户诊断表模板

## 🎯 二、客户开发检查清单

### 2.1 初次接触

- [ ] 已识别客户需求（银行授信/招投标/企业评级）
- [ ] 已使用核心话术框架介绍业务
- [ ] 已建立初步信任
- [ ] 已获取客户联系方式

### 2.2 望闻阶段（资格诊断）

- [ ] 已要求客户提供企业征信报告
- [ ] 已要求客户提供近一年开票汇总表
- [ ] 已要求客户提供纳税评级截图（A/B/M级）
- [ ] 已进行初步诊断
- [ ] 已判断客户是否符合条件

**客户筛选标准**：
- [ ] 年营收≥1000万
- [ ] 纳税评级A/B/M级（非D级）
- [ ] 无当前逾期
- [ ] 有真实业务往来
- [ ] 愿意交税（核心筛选器）

**不符合条件处理**：
- [ ] 已礼貌劝退（D级纳税、有当前逾期等）
- [ ] 已记录客户信息，待条件改善后跟进

### 2.3 问阶段（挖掘痛点）

- [ ] 已分析客户数据（开票记录、纳税记录）
- [ ] 已指出客户问题（流水不足、纳税不稳定等）
- [ ] 已站在银行角度解释被拒原因
- [ ] 已制造适当焦虑（但不过度）

### 2.4 切阶段（抛出方案）

- [ ] 已给出"数据修复手术"方案
- [ ] 已说明具体操作流程（空户操作、真实完税）
- [ ] 已说明预期结果（灰名单→白名单）
- [ ] 已说明时间周期（T+3到T+30）
- [ ] 已说明预期贷款额度

### 2.5 报价阶段（价值锚定）

- [ ] 已先算收益（贷款额度、节省利息）
- [ ] 已说明成本（服务费+税点）
- [ ] 已计算ROI（几万换几十万/上百万）
- [ ] 已尊重客户决策权

## 🔄 三、操作执行检查清单

### 3.1 合同签署

- [ ] 已签署客户服务合同
- [ ] 已签署网银盾托管授权书
- [ ] 已明确费用标准和服务内容
- [ ] 已明确不承诺100%下款（只承诺数据真实录入）
- [ ] 已明确三不碰红线（不碰基本户、不接不舍得交税的客户、不承诺100%下款）

### 3.2 账户交接（空户操作）

- [ ] **已确认使用一般户**（非基本户）
- [ ] **已要求客户清空账户余额**（留0元）
- [ ] **已确认账户余额为0**
- [ ] 已接收客户网银盾（U-Key）
- [ ] 已签署网银盾托管授权书
- [ ] 已确认网银一天转账额度≥月总贸易金额

### 3.3 后端对接

- [ ] 已将客户资料转交后端
- [ ] 已与后端确认操作方案
- [ ] 已与后端确认时间安排
- [ ] 已与后端确认费用结算方式

### 3.4 操作执行（后端主导）

**前端跟进检查**：
- [ ] 已确认后端开始操作
- [ ] 已确认操作完成（1-2小时）
- [ ] 已获取完税证明
- [ ] 已获取银行电子回单
- [ ] 已获取财务报表

**客户配合检查**：
- [ ] 已确认客户去税务局开发票
- [ ] 已确认发票已开具
- [ ] 已确认账户利润处理（客户需私下返还给后端）

### 3.5 数据静置期（3-30天）

- [ ] 已告知客户等待时间（3-30天）
- [ ] 已定期查询税务系统数据更新情况
- [ ] 已定期查询银行系统数据更新情况
- [ ] 已及时通知客户数据更新进度

## 💰 四、贷款申请检查清单

### 4.1 申请准备

- [ ] 已确认数据已更新（税务系统+银行系统）

- [ ] 已发起线上测额

### 4.3 放款确认

- [ ] 已确认审批通过
- [ ] 已确认放款到账
- [ ] 已确认贷款额度、利率、期限
- [ ] 已与客户确认满意度

### 4.4 费用结算

- [ ] 已与后端结算服务费
- [ ] 已与客户结算服务费
- [ ] 已记录成功案例
- [ ] 已包装案例素材（用于朋友圈/获客）

## ⚠️ 六、风险控制检查清单

### 6.1 合规检查

- [ ] 已确认四个"真实"（货物+发票+交易+仓单）
- [ ] 已拒绝任何虚构贸易要求
- [ ] 已拒绝任何虚开发票要求
- [ ] 已确认客户愿意交税

### 6.2 三不碰红线检查

- [ ] **已确认不碰基本户**（只使用一般户）
- [ ] **已确认不接不舍得交税的客户**
- [ ] **已确认不承诺100%下款**（只承诺数据真实录入）

### 6.3 客户风险检查

- [ ] 已确认客户纳税评级（A/B/M级，非D级）
- [ ] 已确认客户无当前逾期
- [ ] 已确认客户有真实业务
- [ ] 已确认客户经营稳定（3年以上）
