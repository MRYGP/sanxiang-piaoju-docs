```

这种我们可以帮忙搞定：
100万存1天只要500元，

您有这个需求吗？
```

```
"老板，我简单问一句：
您最近有没有需要求银行办事？
银行有没有要求您帮忙完成存款任务？

100万存1天只要500元，
```
