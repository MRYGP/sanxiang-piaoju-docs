## ⚠️ 合规提示框

**本业务严格遵循以下合规原则**：

### ✅ 推荐使用（白名单）
- **到账时效**：`通常 10 分钟—2 小时（以票种/额度/通道为准）`
- **收益/年化**：`示例：半年期银承省约0.2%—0.8%；具体以成交时为准`
- **安全与合规**：`基于银行承兑/合同化与留痕机制，合规边界内可控`

**重要提醒**：
- 所有时效、收益、安全表述均为示例区间，不构成刚性承诺

- 全流程公对公操作，严禁任何个人账户收付

## 📋 合规结算范式（模板）

### **资金流**
客户对公 → 我方对公 →（必要时）合作方对公/收票方对公；**严禁**任何个人账户收付。

### **合同与票据流**

1. 我方与客户签《服务/采购或居间合同》（明确票种、金额、费率、交付与违约）；
2. 票据背书/凭证交付全程留痕（网银回单/影像/回执）；
3. 涉及贴现/代办环节，签《贴现/代办服务协议》并载明费率与时效为**区间+条件**。

### **发票与凭证**
服务费开具对应发票；票据/凭证流转凭证与合同要素一致。

### **风险揭示**
费率会随票种/期限/市场波动；到账时效依赖银行与通道；客户需确保票据与贸易背景真实、资金来源合规。

### **禁用词**
私卡、内部秘密、承诺型字眼（100%安全、零风险、保收益、秒到等）。

## 业务本质（✅ 已理解）

### 核心逻辑：
```
企业要付100万货款给供应商
  ↓
传统方式：直接付100万现金
  ↓
我们的方式：从我们这买承兑/凭证
  - 企业付现金给我们（金额取决于承兑/凭证类型和期限）
  - 我们给企业承兑/凭证
  - 企业用承兑/凭证付供应商
  - 供应商持有到期收100万（或找我们贴现）
  ↓
结果：企业省钱（省多少取决于类型和期限）
```

⚠️ **关键区别：期限不同！**
```
承兑（银承、商承）：
  - 开出来就是半年期
  - 在流通过程中可能少于半年

凭证（云信、建信等）：
  - 可以开1年期
  - 甚至可以开2年期
  - 期限更灵活
```

### 【资金流和票据流】

**我们的角色：**
```
Step 1：从A业务客户那收票
  - 我们付99.5万现金
  - 收到100万银承（6个月到期）

Step 2：把票卖给B业务客户
  - 企业付99.6万现金给我们
  - 我们给企业100万银承

Step 3：我们赚差价
  - 利润：99.6万 - 99.5万 = 0.1万（1000元）
```

**企业（B业务客户）：**
```
传统方式：
  - 付100万现金给供应商

我们的方式：
  - 付99.6万给我们
  - 收到100万银承
  - 用100万银承付供应商
  - 省了：100万 - 99.6万 = 0.4万（4000元）
```

**供应商：**
```
收到100万银承后：
  选项A：持有到期，收100万（零风险）
  选项B：找我们贴现，收99.5万左右（立即变现）
```

### 【实际算账案例】

**案例1：100万承兑-银承（半年期，目前真实行情）**

⚠️ **承兑统一说明：银承、商承统称"承兑"，开出来就是半年期**

| 角色 | 付出 | 收到 | 结果 |
|------|------|------|------|
| 我们（中介） | 99.5万（从A业务买入） | 99.6万（卖给B业务） | 赚0.1万 |
| 企业（B业务客户） | 99.6万现金 | 100万银承（半年期） | 省0.4万 |
| 供应商 | - | 100万银承 | 持有半年后收100万 |

**企业省钱计算：**
- 原本要付：100万现金
- 现在只付：99.6万现金（买银承）
- 节省：0.4万
- 节省比例：0.4%（半年期）
- **年化节省：0.8%**

| 角色 | 付出 | 收到 | 结果 |

| 企业（B业务客户） | 96万现金 | 100万商承（半年期） | 省4万 |

**企业省钱计算：**
- 原本要付：100万现金
- 现在只付：96万现金（买商承）

- 节省比例：4%（半年期）
- **年化节省：8%**

**商承说明：**
- 年化5-25%都有（看承兑人资质）
- 案例用的是年化10%的商承（半年期贴息5%）

**案例3：100万凭证-建信融通（1年期，年化5%）**

⚠️ **凭证期限说明：凭证可以开1年期，甚至2年期**

| 角色 | 付出 | 收到 | 结果 |

| 我们（中介） | 95万（从A业务买入） | 96万（卖给B业务） | 赚1万 |
| 企业（B业务客户） | 96万现金 | 100万建信融通（1年期） | 省4万 |

- 原本要付：100万现金

- 节省比例：4%（1年期）

**凭证说明：**

- 如果是2年期，企业只需付92万，省8万

**案例4：对比不同期限的成本差异**

以年化5%的建信融通为例：

| 期限 | 企业付款 | 省钱金额 | 省钱比例 | 年化节省 |

- 年化利率一样（都是5%）

- 供应商持有时间也越长

## 承兑和凭证样本库

⚠️ **关键区别：期限不同！**
- **承兑（银承、商承）**：半年期（开出来就是半年，流通中可能少于半年）
- **凭证（云信、建信等）**：可开1年期，甚至2年期

---

### 1. 承兑-银行承兑汇票（银承）⭐⭐⭐⭐⭐
- **期限**：半年期（开出来就是半年，流通中可能少于半年）
- **贴息成本**：约0.4-1%年化（目前真实行情：100万半年期贴息约0.4万）
- **优势**：供应商最容易接受，贴息最低，变现最容易
- **我们有哪些银行的银承**：待补充
- **企业偏好哪些银行**：待补充

### 2. 承兑-商业承兑汇票（商承）⭐⭐⭐
- **期限**：半年期（开出来就是半年，流通中可能少于半年）
- **贴息成本**：5-25%年化（看承兑人资质和市场认可度）
- **差异原因**：承兑人资质不同，市场认可度不同
- **范围很广**：年化5-25%的都有，到时看客户喜好
- **我们的票源**：我们也可以贴一些自己持有的商承给客户选择
- **风险等级**：相对较高，需要评估承兑人信用

⚠️ **重要法律差异：承兑可追索！**
```
如果承兑最后没兑付：
  → 最后的持票人可以根据票据法起诉所有的背书户
  → 有法律保障，相对安全
```

**注意：银承、商承统称"承兑"**

### 3. 凭证（供应链金融凭证）⭐⭐⭐⭐

⚠️ **期限优势：可开1年期，甚至2年期（比承兑更灵活）**

- **期限范围**：半年期、1年期、2年期都可以
- **贴息成本**：4-7%年化（我们卖出去的价格）
- **优势**：银行/央企背书，安全性高，开通后使用方便，**期限灵活是最大优势**

⚠️ **重要法律差异：凭证不可追索！**
```
如果凭证最后没兑付：
  → 目前没有法律依据来起诉背书户
  → 只能打合同官司（比较麻烦）
  → 风险相对承兑更高
```

## 推荐优先级

### 🥇 第一优先：承兑-银承
- 供应商最容易接受（银行信用背书）
- 贴息成本最低（0.4-1%年化）
- 变现最容易（随时可以贴现）
- **期限**：半年期
- **100万银承（半年期），企业只需付99.6万，省0.4万**

### 🥈 第二优先：银行系凭证（建信融通/云信）
- 银行背书，安全性接近银承
- 贴息成本适中（4-5%年化）
- 供应商接受度较高
- **期限优势**：可开1年期甚至2年期
- **100万凭证（1年期，5%年化），企业只需付96万，省4万**
- **100万凭证（半年期），企业只需付98万，省2万**

### 🥉 第三优先：央企凭证
- 央企背书，风险较低
- 贴息成本适中（4-7%年化）
- 适合和央企有业务往来的企业
- **期限优势**：可开1年期甚至2年期

### ⚠️ 谨慎推荐：承兑-商承
- 贴息成本差异大（5-25%年化）
- 需要评估承兑人资质
- 供应商接受度取决于承兑人知名度
- **期限**：半年期
- **优势：省钱最多！100万商承（10%年化，半年期），企业只需付96万，省4万**

## 如何说服供应商接受凭证？

### 核心话术（松阳提供）：

**主要说法：**
> "X总，不好意思，我们现在没有现金。
> 下游付给我们的就是银票/凭证，我们也是刚收到。
> 
> 您收了这个凭证后，有两个选择：
> 1. 持有到期（基于银行承兑/合同化与留痕机制，合规边界内可控，到期兑付）
> 2. 如果急需现金，我可以介绍贴现的人给您（通常 10 分钟—2 小时到账，以票种/额度/通道为准）
> 
> 您看这样可以吗？"

**为什么我们不自己贴现？（借口）**
- "贴现的只能扣了打款，我们做不了账"
- "对方没有发票和贴现凭证给我们，我们入不了账"
- "我们没办法付贴息"

**实在不行：我们负担一部分贴息**
> "这样吧，贴息我们负担一部分，您看可以吗？"

**合规操作说明**：
```
客户给我们100万凭证或承兑
  → 我们打100万现金到企业公户（公对公）
  → 贴息通过合同约定的方式结算（公对公）
  → 全程合同化、发票与凭证留痕可追溯
```

## 🎯 B业务的两种模式

### 【模式1：付款成本优化】（上面已详细说明）
- 企业用凭证付货款，降低付款成本
- 省钱0.4%-8%不等

### 【模式2：企业理财】（新增！）

**核心逻辑：**
```
企业有闲置资金
  ↓
买商承/凭证持有到期
  ↓
赚取贴息收益
```

**举例：企业有100万闲置资金（6个月）**

| 方案 | 投入 | 持有到期收回 | 收益 | 年化收益率 |
|------|------|-------------|------|-----------|
| 银行定期存款 | 100万 | 101万 | 1万 | 约2% |
| 买商承（10%年化） | 100万买110万商承 | 110万 | 10万 | 10% |
| 买凭证（5%年化） | 100万买105万凭证 | 105万 | 5万 | 5% |

**我们提供：**
- 风险分析意见（评估商承/凭证的安全性）
- 推荐合适的商承/凭证品种
- 持有到期全程跟踪

⚠️ **风险提示：**
- 商承：风险相对高，但收益高，可追索
- 凭证：风险适中，收益适中，不可追索
- 需要企业自行评估风险承受能力

### 🚀 企业高级玩法：质押套利（循环理财）

#### 核心逻辑：
```
买凭证 → 质押开银票 → 贴现拿现金 → 再买凭证 → 循环
```

#### 【完整案例】100万现金，5%年化凭证

**第1轮：**
```
Step 1：用100万买105万凭证（5%年化，半年期）
Step 2：用105万凭证去银行质押
Step 3：银行开出95万银票（约90%质押率）
Step 4：95万银票贴现（1%年化，半年期）
Step 5：得到现金约94.5万
```

**第2轮：再买凭证**
```
用94.5万现金，再买99.2万凭证（5%年化）
  → 再去质押，开出89万银票
  → 再贴现，得到88.5万现金
```

**第3轮：继续循环...**

#### 【收益计算】

**不循环（传统方式）：**
- 投入100万，买105万凭证
- 半年后到期收回105万
- 收益：5万

**循环1次：**
- 第1轮：100万 → 105万凭证 → 收益5万
- 第2轮：94.5万 → 99.2万凭证 → 收益约4.7万
- 第1轮贴现成本：95万 × 1% × 0.5年 = 0.475万
- 总收益：5万 + 4.7万 - 0.475万 = 9.225万
- 收益率提升：从5%提升到约9.2%！
