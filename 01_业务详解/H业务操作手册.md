## 📋 一、业务定位（核心认知）

### 1.1 核心定位

**一句话定位**：
"企业体质改造专家（养流水→做资质→申请贷款）"

**不是**：
- ❌ 贷款中介
- ❌ 包装公司
- ❌ 资金掮客

**而是**：
- ✅ 企业体质改造专家
- ✅ 基础设施服务商
- ✅ 财务健康顾问

### 1.2 关键数字

- **养流水周期**：3-6个月
- **贷款额度**：年开票额的5-30%
- **成功案例**：4个月养出300万（交行，年化3.x%）
- **目标客户**：年营收1000万以上企业

### 1.3 价值主张

```
传统贷款中介：找产品、包装材料（一锤子买卖）
我们：改造体质、真实提升（长期陪伴成长）

结果：
✅ 账面好看了（贸易规模做大）
✅ 拿到真金白银了（发票贷资金）
✅ 解决资金周转问题
✅ 一举三得，价值最大化
```

## 🔄 二、业务流程（SOP框架）

### Step 1：企业诊断（1-2天）

**诊断内容**：
- [ ] 现有银行流水分析
- [ ] 开票能力评估
- [ ] 上下游关系梳理
- [ ] 贷款需求确认
- [ ] 风险点识别

**产出**：诊断报告

**必问问题**：
1. "您公司需要做大贸易量/做流水的目的是什么？" → 判断用途真实性
2. "是银行授信需要？还是招投标需要？还是其他场景？" → 判断具体需求
3. "您现在的贸易规模大概是多少？目标要做到多少？" → 判断具体需求
4. "您希望多长时间内完成？" → 判断时间要求
5. "您公司有真实贸易业务吗？" → 判断基础条件
6. "您了解真实贸易操作的要求吗？" → 判断认知水平
7. "您能接受真实货物、真实发票、真实交易、真实仓单的要求吗？" → 确认合规要求（四个真实）
8. "您公司网银的一天转账额度是多少？是否大于月总贸易金额？" → 判断网银额度是否满足要求

### Step 2：方案设计（2-3天）

**方案要素**：
- [ ] 流水养成计划（月度目标）
- [ ] 贸易路径设计
- [ ] 时间周期预估
- [ ] 预期贷款额度
- [ ] 费用结构说明

**产出**：实施方案

**方案设计原则**：
1. **基于真实业务**：必须基于客户现有的真实贸易业务
2. **合规操作**：所有操作必须符合监管要求（合同+发票+资金流+仓单）
3. **风险可控**：操作流程清晰，风险可控
4. **方案定制**：根据企业行业和需求，设计合适的贸易方案

### Step 3：执行养流水（3-6个月）

**执行要点**：
- [ ] 真实贸易安排
- [ ] 流水每月监控
- [ ] 问题及时调整
- [ ] 银行关系维护
- [ ] 材料持续准备

**产出**：月度报告

**操作模式（资金不过夜）**：
- **企业不需要准备资金**：资金由后端全额垫付
- **操作方式**：企业将**网银盾（U-key）**交给后端，后端全权代操作资金进出
- **时效**：资金不过夜，通常1小时甚至几分钟内走完一个月流水
- **企业唯一要做的**：自己去当地税务局开发票
- **⚠️ 网银额度要求**：网银的一天转账额度必须**大于月总贸易金额**（因为很多时候，一次就把一个月的贸易做完了）

### Step 4：贷款申请（1个月）

**申请流程**：
- [ ] 材料最终准备
- [ ] 银行产品匹配
- [ ] 申请提交
- [ ] 审批跟进
- [ ] 放款确认

**产出**：贷款合同

**发票贷基本信息**：
- **核心特点**：纯信用，无需抵押
- **额度**：年开票额的5%-30%，最高300-500万
- **利率**：年化3.2%-15%
- **期限**：一般12个月，随借随还
- **放款速度**：最快24小时，一般3-5天

**申请条件**：
- 成立满1年
- 连续12个月有开票记录
- 年开票≥100万
- 企业信用良好，无重大诉讼

## ⚠️ 五、合规要求（核心红线）

### 5.1 必须满足的条件

**四个"真实"缺一不可**：

1. **真实货物**：
   - 必须有真实的货物流转
   - 不能是"空转""走单"
   - 货物必须真实存在、真实流转

2. **真实发票**：
   - 必须有真实的发票开具
   - 不能虚开发票
   - 发票必须对应真实交易
   - **企业需要自己去当地税务局开发票**

3. **真实交易**：
   - 必须有真实的合同和资金流
   - 不能是虚构的贸易背景
   - 交易必须符合正常商业逻辑

4. **真实仓单**：
   - 必须有真实的仓单（货物仓储凭证）
   - 证明货物真实存在和流转
   - 这是税务局穿透稽查的关键凭证

### 5.2 绝对不能做的

**红线（绝对不能做）**：
- ❌ 不参与虚构贸易、虚假贸易
- ❌ 不参与虚开发票、虚假流水
- ❌ 不参与"空转""走单""循环贸易"
- ❌ 不承诺"保证完成贸易规模"
- ❌ 不做"无真实货物"的纯流水包装

**危险信号识别**：
如果客户说以下任何一句话，需要立即警觉并引导到合规方向：
- "帮我走一笔流水"（需要引导：我们只做真实贸易）
- "做个贸易背景，好去银行说事"（需要引导：必须真实贸易）
- "帮我冲一下业绩/营业额"（需要引导：必须真实业务）
- "货不用真实走，就过个流程"（需要拒绝：我们不做）
- "做大一点账面规模"（需要引导：必须真实贸易）

## 🛡️ 七、风险控制

### 7.1 主要风险点

1. **合规风险**：必须是真实贸易
2. **时间风险**：周期长，客户可能失去耐心
3. **成功率风险**：不是100%能贷到
4. **资金风险**：过程中需要一定资金周转

### 7.2 风控措施

- [ ] 合同明确不保证结果
- [ ] 分阶段收费降低风险
- [ ] 选择优质客户提高成功率
- [ ] 过程透明，及时沟通

## 📊 九、典型案例

### 案例：某制造企业

**背景**：
- 企业年开票额：100万
- 需求：想申请银行贷款，但银行要求年开票≥300万
- 同时需要资金周转：50万

**解决方案**：
1. **第一步：做大开票额**
   - 通过H业务，将年开票从100万做到500万
   - 真实贸易操作，完全合规
   - 时间：3个月

2. **第二步：申请发票贷**
   - 凭借500万开票额，申请发票贷
   - 额度：500万 × 15% = 75万（实际获批60万）
   - 利率：年化6%
   - 放款时间：5天

**结果**：
- ✅ 账面好看了（500万开票，满足银行要求）
- ✅ 拿到真金白银了（60万发票贷，解决资金周转）
- ✅ 银行授信更容易了（开票额达标）
