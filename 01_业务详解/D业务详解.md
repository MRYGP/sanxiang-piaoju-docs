# D业务详解：贸易套利指导

**业务代码**: D业务  
**业务名称**: 贸易套利指导  
**一句话描述**: 四种套利场景：①企业用真实发票+我们的票/凭证去贴现赚差价；②企业用承兑代替现金付款，获得存单收益（年化1.2%左右，半年期0.6%）；③企业用同一张发票在多个银行重复开承兑（5-6倍杠杆），获得存单收益（总收益1-1.2万）；④企业收到建信融通等凭证，在银行抵押后开出银票，获得贴现利差收益（年化约2%）  
**状态**: ✅ 运营中  
**后端处理**: 合作伙伴  
**业务量**: ⭐⭐⭐ 增值服务

## 🎯 一、业务本质

### 核心逻辑 ✅

D业务包含两种套利场景：

#### 场景1：票据/凭证贴现套利

```
企业为什么需要套利？
- 企业有真实贸易背景（真实发票）
- 想通过票据/凭证贴现赚取差价
- 但直接去银行/平台贴现可能：
  ① 价格不够优惠
  ② 流程复杂
  ③ 需要等待
  ④ 资质要求高

我们的价值：
- 提供承兑或凭证给企业（价格比企业直接去贴现优惠）
- 企业拿到票/凭证后，自己去银行/平台贴现
- 企业赚取差价（贴现价格 - 我们卖给他的价格）
- 我们赚取卖票/凭证的差价（类似B业务）
```

#### 场景2：存单收益套利（用承兑代替现金付款）

```
典型场景：
- A企业卖货给B企业，A企业开出发票给B企业
- B企业要付货款给A企业（例如100万元）

B企业的两种选择：
1. 直接付现金100万给A企业
   - 成本：100万现金
   - 收益：0

2. 用承兑代替现金付款（套利方式）
   - 存100万到银行，开出承兑给A企业
   - 在账面上也代表付了100万货款
   - 同时获得存单收益：
     • 年化1.2%左右
     • 半年期银票可以得到0.6%的存单收益
   - 成本：100万现金（但存在银行有收益）
   - 收益：存单收益（例如半年期0.6%）

我们的价值：
- 帮助企业开出承兑（代替现金付款）
- 企业获得存单收益（年化1.2%左右，半年期0.6%）
- 我们赚取开承兑的服务费或差价（类似B业务）

注意：
- 也可以开凭证（如云信），但需要得到云信官方认可，流程较复杂
- 承兑相对简单，流程成熟
```

#### 场景3：杠杆存单收益套利（多银行重复开承兑）

```
前提条件：
- A企业可以配合，或者是B企业实际控制的
- B企业有真实发票（例如100万元）

核心操作：
- B企业用同一张100万发票，在多个银行重复开承兑
  • 在工行开100万承兑给A企业
  • 在建行开100万承兑给A企业
  • 在其他银行也可以开（中行、农行等）
  • 100万发票可以开出500-600万承兑（5-6倍杠杆）

银行为什么喜欢：
- 开承兑需要存保证金（100万），银行得到存款
- 银行喜欢这种业务，因为可以获得稳定的存款

收益计算（以单笔100万承兑为例）：
- A企业把承兑转让出去
- 银票半年损失贴息：约0.4万左右
- 银行存单半年收益：约0.6万
- 存一笔保证金，半年净收益 = 0.6万 - 0.4万 = 0.2万

总收益（5-6倍杠杆）：
- 如果开5-6倍杠杆（500-600万承兑）
- 总净收益 = 0.2万 × 5-6 = 1-1.2万
- 相对于100万发票，收益率 = 1-1.2%

我们的价值：
- 协助企业在多个银行开承兑
- 协助A企业转让承兑
- 我们赚取服务费或差价

风险提示：
- 需要A企业配合（或实际控制）
- 需要多个银行渠道
- 需要评估银行风险
- 需要评估合规风险
```

#### 场景4：抵押开银票套利（凭证抵押换银票）

```
前提条件：
- 企业收到建信融通等电子债权凭证（例如100万元）
- 银行支持凭证抵押开银票（需要与银行协商）

核心操作：
- 企业收到建信融通（电子债权凭证，100万元）
- 在建行进行抵押
- 建行开出银票（90-95万元）
- 银票贴现获得资金

收益计算（以100万建信融通为例）：
- 建信融通如果直接贴现：年化3%
- 抵押后开出银票（90-95万），银票贴现：年化1%
- 利差收益：年化3% - 年化1% = 年化2%
- 实际收益：90-95万能够获得年化2%的利差收益

简单理解：
- 收到100万建信融通
- 如果直接贴现：年化3%，收益较高但成本也高
- 抵押开银票：在建行抵押建信融通，开出90-95万银票
- 银票贴现：年化1%，成本较低
- 利差收益：年化2%（90-95万能够获得年化2%的利差收益）
- 核心优势：通过抵押开银票，用较低成本的银票替代高成本的建信融通贴现，获得利差收益

我们的价值：
- 协助企业与银行协商抵押开银票
- 协助企业办理抵押和开银票手续
- 我们赚取服务费或差价

风险提示：
- 需要与银行协商（可能比较复杂）
- 需要银行支持凭证抵押开银票
- 需要评估银行风险
- 需要评估合规风险
- 抵押后凭证不能直接使用
```

### 盈利模式

```
- 不收取咨询费、服务费
- 我们赚的是卖票/凭证的差价，或开承兑的服务费
- 场景1：我们卖给企业的价格，比企业最终去银行/平台贴现的价格要高一些，但企业仍然有差价可赚
- 场景2：企业用承兑代替现金付款，获得存单收益（年化1.2%左右，半年期0.6%），我们赚开承兑的服务费或差价
- 场景3：企业用同一张发票在多个银行重复开承兑（5-6倍杠杆），获得存单收益（单笔净收益0.2万，总收益1-1.2万），我们赚开承兑的服务费或差价
- 场景4：企业收到建信融通等凭证，在银行抵押后开出银票，获得贴现利差收益（年化约2%），我们赚服务费或差价

## 🔄 二、完整业务流程 ✅

### 场景1：票据/凭证贴现套利流程

#### 场景起点：企业找我们买票/凭证 ✅

```
典型场景：
- 企业有真实贸易背景（真实发票、合同）
- 想通过票据/凭证贴现赚取差价
- 需要合适的票/凭证去贴现

企业会告诉我们：
- 真实发票金额（几十万-几千万不等）
- 发票类型（增值税专用发票、普通发票等）
- 贸易背景（采购、销售等）
- 需要的票/凭证金额、期限
- 期望的套利空间
```

#### 详细操作流程 ✅

**Step 1: 企业提出需求**

- 企业通过业务员或直接联系我们
- 说明有真实发票，想套利，需要票/凭证
- 我们初步了解：
  - 发票金额、类型
  - 贸易背景真实性
  - 需要的票/凭证金额、期限
  - 企业资质（是否有贴现资格）

**Step 2: 匹配票/凭证（合作方处理）**

- 合作方根据企业需求：
  - 评估发票真实性
  - 评估企业资质
  - 匹配合适的票/凭证：
    - 选择合适票据/凭证类型
    - 确定金额、期限
    - 报价（我们卖给企业的价格）
- 告知企业：
  - 票/凭证信息
  - 我们的报价
  - 企业预期收益（贴现价格 - 我们的报价）

**Step 3: 企业决策**

- 企业评估：
  - 我们的报价是否合适
  - 是否有套利空间（贴现价格 - 我们的报价 > 0）
  - 风险是否可控
- 如果决定购买：
  - 签署购买协议（类似B业务）
  - 支付票/凭证款项（公对公）

**Step 4: 交付票/凭证**

- 我们交付票/凭证给企业
- 企业收到票/凭证后，自己去银行/平台贴现
- 企业赚取差价（贴现价格 - 我们卖给他的价格）

**Step 5: 后续服务（可选）**

- 如果企业有新的套利需求，可以继续提供票/凭证
- 建立长期合作关系

#### 详细操作流程 ✅

**Step 1: 企业提出需求**

- 企业通过业务员或直接联系我们
- 说明收到建信融通等凭证，想在银行抵押开银票
- 我们初步了解：
  - 凭证类型、金额
  - 银行信息
  - 企业资质（是否能在银行办理抵押）

**Step 2: 方案设计（合作方处理）**

  - 设计方案：
    - 在建行抵押建信融通（100万）

  - 操作方案

**Step 3: 企业决策**

- 企业评估：
  - 利差收益是否合适（年化约2%）

  - 准备凭证（建信融通等）

**Step 4: 执行操作**

- 企业在建行抵押建信融通（100万）
- 建行开出银票（90-95万）
- 银票贴现获得资金
- 企业获得利差收益（年化约2%）

**Step 5: 后续服务（可选）**

- 如果企业有新的凭证，可以继续提供类似服务

## 💰 三、盈利模式 ✅

### 收入来源

```
场景1：票据/凭证贴现套利
1. 卖票/凭证的差价
   - 我们卖给企业的价格，比企业最终去银行/平台贴现的价格要高一些
   - 但企业仍然有差价可赚（因为我们的价格虽然高，但比他们直接去贴现还是便宜，或者有其他优势）
   - 我们赚的是卖票/凭证的差价（类似B业务）

场景2：存单收益套利
2. 开承兑的服务费或差价
   - 帮助企业开出承兑（代替现金付款）
   - 企业获得存单收益（年化1.2%左右，半年期0.6%）
   - 我们赚开承兑的服务费或差价（类似B业务）

场景3：杠杆存单收益套利
3. 开承兑的服务费或差价（多银行）
   - 协助企业在多个银行开承兑（5-6倍杠杆）
   - 企业获得存单收益（单笔净收益0.2万，总收益1-1.2万）
   - 我们赚开承兑的服务费或差价（类似B业务）

场景4：抵押开银票套利
4. 抵押开银票的服务费或差价
   - 协助企业与银行协商抵押开银票
   - 企业获得贴现利差收益（年化约2%）
   - 我们赚服务费或差价（类似B业务）

- 不收取咨询费、服务费
- 我们只赚卖票/凭证的差价，或开承兑的服务费
```

## 📋 八、与其他业务的关系 ✅

### 与A业务的关系

```
- A业务：企业有票/凭证，我们帮贴现变现
- D业务场景1：企业有真实发票，我们提供票/凭证，企业自己去贴现套利
- D业务场景4：企业收到建信融通等凭证，在银行抵押后开出银票，获得贴现利差收益

相似点：
- 场景4与A业务都涉及凭证（建信融通等）
- 场景4可以转化A业务客户（凭证贴现客户）

区别：
- A业务：我们帮企业贴现凭证变现
- D业务场景1：我们提供票/凭证给企业，企业自己去贴现套利
- D业务场景4：企业收到凭证，在银行抵押开银票，获得利差收益

交叉销售机会：
- A业务客户可能有套利需求（场景1或场景4）
- D业务场景4客户可能也需要A业务（凭证贴现）
- D业务场景1客户可以升级到场景4（抵押开银票套利）
```

### 与B业务的关系

```
B业务：企业要付款，用票/凭证代替现金（省钱）
D业务场景1：企业有真实发票，我们提供票/凭证，企业自己去贴现套利（赚差价）
D业务场景2：企业要付货款，用承兑代替现金付款，同时获得存单收益（年化1.2%左右，半年期0.6%）

相似点：
- 都是我们卖票/凭证给企业，赚卖票/凭证的差价
- 场景2与B业务非常相似，都是企业用票/凭证代替现金付款

区别：
- B业务：企业用票/凭证付款（省钱，节省付款成本）
- D业务场景1：企业用票/凭证去贴现套利（赚差价）
- D业务场景2：企业用承兑代替现金付款，同时获得存单收益（年化1.2%左右，半年期0.6%）

交叉销售机会：
- B业务客户可能有套利需求（场景1、场景2、场景3或场景4）
- D业务场景2客户可能也需要B业务（用票/凭证付款）
- D业务场景3客户可能也需要B业务（用票/凭证付款）
- D业务场景2客户可以升级到场景3（杠杆套利）
- D业务场景4客户可能也需要A业务（凭证贴现）

## ✅ 九、业务优势 ✅

### 核心优势

```
1. 附加价值高
   - 提升客户粘性
   - 展现专业能力
   - 差异化竞争

2. 盈利模式清晰
   - 场景1：赚卖票/凭证的差价（类似B业务）
   - 场景2：赚开承兑的服务费或差价（类似B业务）
   - 不收取咨询费、服务费
   - 风险可控

3. 客户需求明确
   - 场景1：有真实发票的企业，想套利赚钱，需要合适的票/凭证
   - 场景2：要付货款的企业，想用承兑代替现金付款，获得存单收益

4. 复购机会
   - 场景1：企业可能有多次套利需求，可以定期提供票/凭证
   - 场景2：企业可能有多次付款需求，可以定期提供开承兑服务
   - 长期合作机会

5. 场景2的特殊优势
   - 存单收益稳定（年化1.2%左右，半年期0.6%）
   - 操作相对简单（承兑流程成熟）
   - 与B业务高度相似，可以交叉销售

6. 场景3的特殊优势
   - 杠杆收益更高（5-6倍杠杆，总收益1-1.2万）
   - 银行喜欢这种业务（获得稳定存款）
   - 可以升级场景2客户到场景3
   - 规模更大，服务费收入更高

7. 场景4的特殊优势
   - 利差收益较高（年化约2%）
   - 可以转化A业务客户（凭证贴现客户）
   - 需要与银行协商，但收益可观
   - 可以升级场景1客户到场景4
```

### 战略意义

```
✅ 提升客户粘性
✅ 展现专业能力
✅ 附加收入来源
✅ 差异化竞争
```
