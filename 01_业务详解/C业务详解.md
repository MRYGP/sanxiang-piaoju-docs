

# C业务详解：冲存款（银行存款任务撮合）

**业务代码**: C业务
 **业务名称**: 冲存款
 **一句话描述**: 帮银行网点冲存款任务（撮合资金方和银行）
 **状态**: ✅ 运营中
 **后端处理**: 合作伙伴
 **业务量**: ⭐⭐⭐⭐⭐ **实际业务量很大**

## 🎯 一、业务本质

### 核心逻辑 ✅

```
银行为什么需要冲存款？
- 银行个人、部门、支行都有对公存款或个人存款的考核指标
- 必须达标，否则影响绩效考核
- 银行自己出不了这笔钱：
  ① 没办法开支（没有预算）
  ② 市价对银行人员来说太贵
  ③ 偶尔有银行买单，但很少

企业主为什么买单？
- 求银行的人办事（贷款、授信、其他业务支持）
- 帮银行完成任务是人情往来
- 不完成，面子上拉不下去
- 这是企业主的实际需求（维护银行关系）

资金方为什么愿意配合？
- 钱只是从A银行转到B银行
- 钱始终在自己的企业户或个人卡上
- 没有任何风险（资金可控）
- 操作简单：
  • 方式1：临柜开户（去柜台）- 本地企业/个人
  • 方式2：网开（手机APP）- 全国都可以，足不出户
  • 方式3：通知存款（手机APP）- 更灵活

我们的角色：
- 居间撮合（匹配资金方和企业主）
- 操作协调（指导资金方开卡、存款）
- 资金不过我们的手
- 赚取服务费（企业主支付）
```

### 三方关系图 ✅

```
┌─────────────────────────────────────────────┐
│              C业务生态图                     │
└─────────────────────────────────────────────┘

【银行方】                【企业主】              【资金方】
银行个人/部门/支行    ←─  需要维护关系  ─→    企业/个人
   ↓                       ↓                    ↓
存款考核压力           求银行办事            钱从A转到B
完不成影响绩效         愿意买单帮忙          没有风险
   ↓                       ↓                    ↓
   └────→  需要完成任务  ←─┘                  ↓
                ↓                               ↓
                └─────→  【我们】  ←───────────┘
                      （居间撮合）
                          ↓
                    匹配资金 + 协调操作
                          ↓
                  企业主付服务费（万5-千1/天）
                  我们赚万1/天
```

## 🔄 二、完整业务流程 ✅

### 场景起点：企业主找我们 ✅

```
重点：不是银行找我们，是企业主找我们！

典型场景：
- 企业主需要求银行办事（贷款、授信等）
- 银行人员说："帮我完成存款任务，我帮你办事"
- 企业主找我们帮忙完成
- 维护银行关系的需求

企业主会告诉我们：
- 需要的金额（几十万-几千万不等）
- 网点名称（具体哪个支行）
- 或工号（银行人员的工号，任务算在他头上）
- 存款时间（1天、7天、1个月等）
```

### 详细操作流程 ✅

**Step 1: 企业主找我们谈需求**

```
企业主告诉我们：
1. 存款金额：XX万（根据银行任务）
2. 存款时间：
   • 1天（冲时点，晚上12点过夜即可）
   • 7天（日均）
   • 更长时间（也是日均）
3. 指定网点：
   • 方式A：具体支行名称
   • 方式B：银行人员工号（更常见）
4. 谈好价格：
   • 市场价：万5-千1每天
   • 我们报价（含我们利润）
```

**Step 2: 我们匹配资金方** ✅

```
资金方来源：
✅ 我们有合作的资金方网络
✅ 全国性的资金方网络
✅ 通过专业中介对接

资金方分类：
- 企业资金方：有闲置资金的企业
- 个人资金方：有闲置资金的个人
- 分布：全国各地都有

风险控制机制（重要！）：
1. 专业中介把关：
   • 有专业的中介接单
   • 中介会把握资金方质量
   • 不靠谱的资金方不会做
   
2. 资金调配机制：
   • 如果资金方出问题，临时调其他资金
   • 确保企业主的需求一定完成

3. 付款托管：
   • 定金、尾款都在中介方手里
   • 或者后期可以放在我们这里
   • 只有确定干活了才给资金方结算
   • 资金方不干活拿不到钱

4. 三方制衡：
   企业主 ←→ 我们 ←→ 中介 ←→ 资金方
   （付钱）   （居间）  （把关）  （干活）

操作方式分类：

【方式1：临柜开户】
- 适合：本地企业和个人
- 流程：去柜台开户/开卡 → 存款
- 限制：必须本地，小金额不合算
- 场景：大金额或特殊要求时用

【方式2：网开（最常用）】
- 适合：全国任何地方的资金方
- 流程：
  ① 手机银行APP操作
  ② 开一个临时的网点的卡
  ③ 把钱转入
  ④ 第二天转回到主卡
- 优势：足不出户，灵活方便

【方式3：通知存款（网开的一种）】
- 适合：有该银行主卡的资金方（如长沙银行）
- 流程：
  ① 钱存在主卡上
  ② 转入"通知存款"
  ③ 1天（冲时点）或7天+（日均）
  ④ 到期转回主卡
- 优势：更简单，不需要开新卡
```

**Step 3: 付款和开卡**

```
付款方式（重要！）：
1. 定金制（熟悉客户）：
   • 谈好价格后，企业主先付定金
   • 我们安排资金方开卡
   • 开好卡后，企业主付尾款
   • 我们让资金方存款

2. 全款制（不熟悉客户）：
   • 我们确定好资金后
   • 企业主必须付全款
   • 然后我们才操作

开卡流程：
- 网开：资金方在手机APP操作
- 临柜：资金方去银行柜台
- 我们指导资金方完成
```

**Step 4: 存款和截图**

```
存款操作：
1. 资金方把钱转入指定账户
2. 转入金额=约定金额
3. 转入网点=指定网点/工号

完成确认：
1. 资金方存款完成后截图
2. 截图发给我们
3. 我们转发给企业主
4. 企业主让银行那边核对
5. 银行确认任务完成

资金回流：
1. 第二天（或约定时间后）
2. 资金方把钱转回自己主卡
3. 完成！
```

**Step 5: 结算**

```
我们的收益：
- 企业主支付的费用 - 资金方成本 = 我们利润
- 一般我们赚万1/天

举例：
100万存1天：
- 企业主付：500-1000元（万5-千1）
- 资金方成本：0元（钱只是转账，没成本）
- 我们赚：100元（万1）
- 或者如果市场价高，我们赚更多

100万存7天：
- 企业主付：3500-7000元
- 我们赚：700元（万1×7天）
```
