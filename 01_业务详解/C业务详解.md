## 一、业务本质与定位

### 1.1 业务本质

> **一句话：**  
> 银行网点有存款任务考核压力，需要完成存款指标，  
> 企业主需要维护银行关系（求银行办事），愿意买单帮忙，  
> 资金方有闲置资金，愿意配合（钱只是从A银行转到B银行，没有风险），  
> 我们作为居间撮合方，匹配资金方和企业主，协调操作，赚取服务费。

### 1.1.1 业务特征与收益模型

**业务特征**：
- **季节性**：月末/季末是旺季，平常需求较少
- **金额波动大**：单笔金额100万-10亿不等
- **利润率极低**：走量为主，主要靠冲量

**收益模型示例**：
- 1亿的业务：
  - 资金方收益：约10万（存款利息）
  - 我们（居间方）收益：约1万（居间服务费）
  - 企业主支付：约11万（服务费）
- **核心逻辑**：主要靠冲量，单笔利润低但总量可观

关键特征：

- **银行方需求**：  
  银行个人、部门、支行都有对公存款或个人存款的考核指标，必须达标，否则影响绩效考核。  
  银行自己出不了这笔钱（没有预算、市价太贵、偶尔有银行买单但很少）。
- **企业主需求**：  
  求银行的人办事（贷款、授信、其他业务支持），帮银行完成任务是人情往来，这是企业主的实际需求（维护银行关系）。
- **资金方优势**：  
  钱只是从A银行转到B银行，钱始终在自己的企业户或个人卡上，没有任何风险（资金可控），操作简单。
- **我们的价值**：  
  居间撮合（匹配资金方和企业主），操作协调（指导资金方开卡、存款），资金不过我们的手，赚取服务费（企业主支付）。

### 1.2 与其他业务的关系

- 与 **A 业务** 的关系：  
  - A 业务客户（持票企业）贴现后有现金，可以介绍他们做 C 业务的资金方，客户获得存款利息。
- 与 **B 业务** 的关系：  
  - B 业务客户（要付款企业）与银行有业务往来，可能也需要维护银行关系，可以介绍 C 业务。
- 与 **E 业务（债券投资服务）** 的区别：  
  - C：短期存款任务（1天-几个月），资金方赚取存款利息；  
  - E：中长期债券投资（3-12个月），企业赚取债券收益。

可以简单理解：

> C 业务是"银行需要存款任务，企业主需要维护关系，资金方有闲置资金，我们撮合三方共赢"的居间服务。

## 二、客户画像与典型场景

### 2.1 目标客户画像

**适合 C 业务的三方客户，一般具备以下特征：**

1. **企业主（付款方）**
   - 需要求银行办事（贷款、授信、其他业务支持）
   - 银行人员说："帮我完成存款任务，我帮你办事"
   - 愿意买单帮忙，维护银行关系
   - 有明确的存款需求（金额、网点、时间）

2. **银行方（需求端）**
   - 银行个人、部门、支行有存款考核指标
   - 必须达标，否则影响绩效考核
   - 自己出不了这笔钱（没有预算、市价太贵）
   - 偶尔有银行买单，但很少

3. **资金方（供给端）**
   - 有闲置资金的企业或个人
   - 资金规模：几十万-几千万不等
   - 愿意配合（钱只是从A银行转到B银行，没有风险）
   - 操作简单（网开、临柜、通知存款）

### 2.2 典型业务场景

**场景一：企业主维护银行关系**

- 企业主需要求银行办事（贷款、授信等）
- 银行人员说："帮我完成存款任务，我帮你办事"
- 企业主找我们帮忙完成
- 维护银行关系的需求

**场景二：银行网点冲时点**

- 银行网点需要冲时点（晚上12点过夜即可）
- 企业主愿意买单帮忙
- 我们撮合资金方完成1天存款任务

**场景三：银行网点冲日均**

- 银行网点需要冲日均（7天、1个月等）
- 企业主愿意买单帮忙
- 我们撮合资金方完成7天或更长时间存款任务

### 2.3 不适合的情况

- 资金来源不干净（黑钱、洗钱等）
- 银行明确不允许外部资金冲存款
- 企业主不愿意买单（没有维护银行关系的需求）

## 三、三方角色与分工

### 3.1 三方结构

> **企业主（付款方）**  
> - 需要求银行办事（贷款、授信、其他业务支持）；  
> - 愿意买单帮忙，维护银行关系；  
> - 告诉我们存款需求（金额、网点、时间）；  
> - 支付服务费（万5-千1/天，市场价）。

> **资金方（供给端）**  
> - 有闲置资金的企业或个人；  
> - 愿意配合（钱只是从A银行转到B银行，没有风险）；  
> - 完成开卡、存款操作；  
> - 获得存款利息（或服务费）。

> **三湘（总部，前端获客与中台协调）**  
> - 发现并识别"需要维护银行关系"的企业主；  
> - 初步判断客户需求和存款情况；  
> - 向合作伙伴清晰描述需求，与合作伙伴共同评估可行性；  
> - 协调双方沟通、报价、签约及后续执行；  
> - 收取服务费（作为居间和协调方）。

> **合作伙伴（后端处理）**  
> - 专业评估存款需求、匹配资金方；  
> - 指导资金方开卡、存款操作；  
> - 协调资金方和企业主沟通；  
> - 控制操作风险和合规风险。

### 3.2 服务边界（重要）

> **我们只做：真实存款撮合 + 合规操作指导 + 居间服务。**  

边界需要写死：

- 不参与伪造存款、虚假存款等违法行为；  
- 不对客户提供"如何绕过银行监管"的技巧；  
- 不以任何形式承诺"固定收益、绝对安全"；  
- 不在明知资金来源不干净的情况下，仍然推动业务成交；  
- 资金不过我们的手，全程由资金方和企业主直接对接；  
- 不参与银行内部考核作弊等违规行为。

## 四、标准业务流程（官方版）

> 此流程仅涵盖"真实存款撮合 + 合规操作指导"的标准模式，  
> 作为 C 业务的**唯一官方流程**。  
> 更复杂的结构化安排，只能在线下个案讨论，  
> 不写入知识库，不对业务员和 AI 开放。

### Step 1：前端识别 & 收集需求

由业务员或总部进行初次沟通，判断是否有 C 业务需求：

关键提问示例：

- 「您最近有没有需要求银行办事（贷款、授信等）？银行有没有要求您帮忙完成存款任务？」  
- 「您大概需要多少金额？哪个网点？存多久？」  
- 「您是否愿意买单帮忙，维护银行关系？」

将需求收集成表单（建议用飞书多维表或表单）：

- 企业主基本信息  
- 存款金额（几十万-几千万不等）  
- 存款时间（1天、7天、1个月等）  
- 指定网点（具体支行名称或银行人员工号）  
- 银行关系背景（为什么需要维护关系）

### Step 2：内部初筛（合规 & 风险）

我们内部先筛一轮，淘掉明显不能做的情况：

- 资金来源不干净（黑钱、洗钱等）；  
- 银行明确不允许外部资金冲存款；  
- 企业主不愿意买单（没有维护银行关系的需求）；  
- 用途本身就高度可疑的情况。

这一步不要求业务员做复杂风控，但要求：

- 能识别明显红旗；  
- 对于模糊情况，升级给总部或指定风控负责人判断。

### Step 3：转交合作伙伴进行方案评估

将通过初筛的需求信息转交合作伙伴（后端）：

**⚠️ 重要：必须在微信群中对接**

**建群规则**：
- 群名：[客户公司简称]-C业务-冲存款对接群
- 群成员：客户、合伙人（你）、三湘管理员、合作伙伴（存款撮合）

**拉群话术**：
> "我把您拉到业务群，群里有专业老师直接给您评估方案，有问题群里沟通更快。"

合作伙伴评估（在群内进行）：

- 是否能够匹配到合适的资金方；  
- 建议价格区间（企业主需付多少服务费，市场价万5-千1/天）；  
- 可用操作方式（网开、临柜、通知存款）；  
- 合规与操作要求简述。

我们在中间：

- 把企业主的真实情况、需求、限制说清楚；  

### ⚠️ 微信群协作机制（必须遵守）

**所有业务对接必须在微信群中进行，禁止私聊。**

**群成员标配**：
- 客户
- 合伙人（你）
- 三湘管理员
- 后端方（合作伙伴-存款撮合）

**三大目的**：
1. **让你学习**：观察后端方如何对接客户，快速掌握业务技能
2. **累积数据**：我们从群沟通中发现问题、优化流程
3. **服务后端**：让我们的系统更好地支持后端方工作

**你在群里要做的**：
- ✅ 保持观察，学习后端方的话术和处理方式
- ✅ 客户找你时，在群里@后端方协助
- ✅ 有疑问可以在群里提问

**禁止**：
- ❌ 和客户私聊业务细节
- ❌ 和后端方私聊跳过群沟通  
- 把合作伙伴的方案和思路翻译给企业主听。

### Step 4：方案沟通 & 客户决策

在有初步方案后，与企业主进行沟通：

说明要点：

- 企业主需要付多少服务费？（市场价万5-千1/天，具体以市场为准）  
- 操作方式是什么？（网开、临柜、通知存款）  
- 资金方如何操作？（开卡、存款、截图确认）  
- 结算方式是什么？（定金制或全款制）

重要的是让企业主理解：

> **这是"存款撮合服务"，企业主需要支付服务费，我们撮合资金方完成存款任务。**  
> 资金不过我们的手，全程由资金方和企业主直接对接。

### Step 5：付款和开卡

- 由我们与企业主签署正式合同：  
  - 存款撮合服务合同；  
  - 风险提示文件。

- 企业主付款（定金制或全款制）：  
  - 定金制（熟悉客户）：谈好价格后，企业主先付定金，我们安排资金方开卡，开好卡后，企业主付尾款，我们让资金方存款。  
  - 全款制（不熟悉客户）：我们确定好资金后，企业主必须付全款，然后我们才操作。

- 合作伙伴指导资金方开卡：  
  - 网开：资金方在手机APP操作，开一个临时的网点的卡；  
  - 临柜：资金方去银行柜台开户/开卡；  
  - 通知存款：资金方在手机APP操作，转入"通知存款"。

### Step 6：存款和结算

- 资金方存款：  
  - 资金方把钱转入指定账户（转入金额=约定金额，转入网点=指定网点/工号）；  
  - 资金方存款完成后截图，截图发给我们，我们转发给企业主；  
  - 企业主让银行那边核对，银行确认任务完成。

- 资金回流：  
  - 第二天（或约定时间后），资金方把钱转回自己主卡，完成。

- 结算：  
  - 企业主支付的费用 - 资金方成本 = 我们利润（一般我们赚万1/天）；  
  - 举例：100万存1天，企业主付500-1000元（万5-千1），我们赚100元（万1）。

- 事后复盘：  
  - 企业主是否完成了银行关系维护；  
  - 这次撮合安排对企业主是否"物有所值"；  
  - 后续是否还有类似需求（可纳入长期合作）；  
  - 同时问一句：后续是否有 A/B/E/F 等业务的需求，可以一起规划。

## 五、收费结构与盈利模式（官方口径）

> **对外统一说明：**  
> - 我们以"存款撮合服务"的方式参与，  
> - 服务费根据存款金额、期限、市场行情等因素确定，  
> - 具体价格以双方签署的协议为准，不构成刚性承诺。

### 5.1 客户侧的成本构成

对企业主来说，C 业务成本一般包括：

1. **服务费**  
   - 企业主支付的服务费（市场价万5-千1/天）；  
   - 具体以存款金额、期限、市场行情为准；  
   - 示例：100万存1天，企业主付500-1000元（万5-千1）。

对外口径可以是：

> "该服务会产生一定的服务费用，  
> 具体以双方签署的协议和市场行情为准。  
> 企业主通过撮合服务完成银行关系维护，获得银行支持。"

### 5.2 我们的盈利模式（内部理解）

- 盈利方式属于"**居间服务费**"类：  
  - 前端由我们获客、筛选、初步诊断；  
  - 后端由合作伙伴专业评估、匹配资金方、协调操作；  
  - 我们赚取企业主支付的服务费与合作伙伴分成之间的差价。

- 实际盈利数据示例（仅供参考，不写入对外材料）：  
  - 单笔示例（100万存1天）：  
    - 企业主付：500-1000元（万5-千1）  
    - 资金方成本：0元（钱只是转账，没成本）  
    - 我们赚：100元（万1）  
    - 或者如果市场价高，我们赚更多  
  - 100万存7天：  
    - 企业主付：3500-7000元  
    - 我们赚：700元（万1×7天）

- 实际分成比例不写进知识库，  
  通过与合作伙伴的合作协议约定，  
  同时避免业务员在前线乱开条件。

## 六、业务员视角：话术与移交流程

### 6.1 业务员需要做的 3 件事

1. **识别是否适合 C 业务**  
   - 企业主有没有需要求银行办事（贷款、授信等）？  
   - 银行有没有要求企业主帮忙完成存款任务？  
   - 企业主是否愿意买单帮忙，维护银行关系？

2. **用统一话术介绍 C 业务**

   示例话术：

   > 「老板，我简单问一句：  
   > 您最近有没有需要求银行办事（贷款、授信等）？  
   > 银行有没有要求您帮忙完成存款任务？  
   >   
   > 如果有，我们可以帮您撮合资金方完成存款任务，  
   > 维护银行关系，获得银行支持。  
   > 服务费市场价万5-千1/天（具体以市场为准）。」

3. **把信息收集完整并移交总部/常松阳部**

   - 企业主基本信息；  
   - 存款金额、存款时间、指定网点；  
   - 银行关系背景；  
   - 填好表单，发给常松阳部/总部/指定渠道。

### 6.2 业务员禁止做的事（红线）

- 禁止说："保证完成存款任务"、"100%安全/零风险/绝对合规"；  
- 禁止承诺"固定收益、绝对安全"、"肯定能完成"；  
- 禁止使用"私卡/内部秘密/线下结算"等不合规表述；  
- 禁止代替客户操作账户（点买卖、输入密码）；  
- 禁止参与银行内部考核作弊等违规行为。

## 七、风险提示与红线控制

### 7.1 对客户的最低风险提示

在与客户沟通 C 业务时，至少要让客户明确三点：

1. 这是**存款撮合服务**，企业主需要支付服务费；  
2. 服务费为**示例区间**（市场价万5-千1/天，具体以市场为准），不构成刚性承诺；  
3. 资金不过我们的手，全程由资金方和企业主直接对接。

可以形成标准提示语：

> 「我们能帮您撮合资金方完成存款任务，维护银行关系，  
>  但具体服务费以成交时市场行情为准，不构成刚性承诺。  
>   
>  资金不过我们的手，全程由资金方和企业主直接对接。  
>  我们只做居间撮合和操作协调。」

### 7.2 内部红线

- 避免与明显有欺诈动机的客户合作；  
- 避免被卷入伪造存款、虚假存款等违法行为；  
- 金额特别大 / 结构特别复杂的项目，必须总部或指定风控牵头，必要时让律师审合同；  
- 不在任何文档、话术中写"锁死收益""万无一失"等字样；  
- 不参与银行内部考核作弊等违规行为；  
- **核心红线：资金来源必须干净，资金不过我们的手。**

## 附录：C业务详细说明（内部参考）

### 核心逻辑：

```
银行为什么需要冲存款？
- 银行个人、部门、支行都有对公存款或个人存款的考核指标
- 必须达标，否则影响绩效考核
- 银行自己出不了这笔钱：
  ① 没办法开支（没有预算）
  ② 市价对银行人员来说太贵
  ③ 偶尔有银行买单，但很少

企业主为什么买单？
- 求银行的人办事（贷款、授信、其他业务支持）
- 帮银行完成任务是人情往来
- 不完成，面子上拉不下去
- 这是企业主的实际需求（维护银行关系）

资金方为什么愿意配合？
- 钱只是从A银行转到B银行
- 钱始终在自己的企业户或个人卡上
- 没有任何风险（资金可控）
- 操作简单：
  • 方式1：临柜开户（去柜台）- 本地企业/个人
  • 方式2：网开（手机APP）- 全国都可以，足不出户
  • 方式3：通知存款（手机APP）- 更灵活

我们的角色：
- 居间撮合（匹配资金方和企业主）
- 操作协调（指导资金方开卡、存款）
- 资金不过我们的手
- 赚取服务费（企业主支付）
```

### 三方关系图 ✅

```
┌─────────────────────────────────────────────┐
│              C业务生态图                     │
└─────────────────────────────────────────────┘

【银行方】                【企业主】              【资金方】
银行个人/部门/支行    ←─  需要维护关系  ─→    企业/个人
   ↓                       ↓                    ↓
存款考核压力           求银行办事            钱从A转到B
完不成影响绩效         愿意买单帮忙          没有风险
   ↓                       ↓                    ↓
   └────→  需要完成任务  ←─┘                  ↓
                ↓                               ↓
                └─────→  【我们】  ←───────────┘
                      （居间撮合）
                          ↓
                    匹配资金 + 协调操作
                          ↓
                  企业主付服务费（万5-千1/天）
                  我们赚万1/天
```

## 🔄 二、完整业务流程 ✅

### 场景起点：企业主找我们 ✅

```
重点：不是银行找我们，是企业主找我们！

典型场景：
- 企业主需要求银行办事（贷款、授信等）
- 银行人员说："帮我完成存款任务，我帮你办事"
- 企业主找我们帮忙完成
- 维护银行关系的需求

企业主会告诉我们：
- 需要的金额（几十万-几千万不等）
- 网点名称（具体哪个支行）
- 或工号（银行人员的工号，任务算在他头上）
- 存款时间（1天、7天、1个月等）
```

### 详细操作流程 ✅

**Step 1: 企业主找我们谈需求**

```
企业主告诉我们：
1. 存款金额：XX万（根据银行任务）
2. 存款时间：
   • 1天（冲时点，晚上12点过夜即可）
   • 7天（日均）
   • 更长时间（也是日均）
3. 指定网点：
   • 方式A：具体支行名称
   • 方式B：银行人员工号（更常见）
4. 谈好价格：
   • 市场价：万5-千1每天
   • 我们报价（含我们利润）
```

**Step 2: 我们匹配资金方** ✅

```
资金方来源：
✅ 我们有合作的资金方网络
✅ 全国性的资金方网络
✅ 通过专业合作方对接

资金方分类：
- 企业资金方：有闲置资金的企业
- 个人资金方：有闲置资金的个人
- 分布：全国各地都有

风险控制机制（重要！）：
1. 专业合作方把关：
   • 有专业的合作方接单
   • 合作方会把握资金方质量
   • 不靠谱的资金方不会做
   
2. 资金调配机制：
   • 如果资金方出问题，临时调其他资金
   • 确保企业主的需求一定完成

3. 付款托管：
   • 定金、尾款都在合作方手里
   • 或者后期可以放在我们这里
   • 只有确定干活了才给资金方结算
   • 资金方不干活拿不到钱

4. 三方制衡：
   企业主 ←→ 我们 ←→ 合作方 ←→ 资金方
   （付钱）   （居间）  （把关）  （干活）

操作方式分类：

【方式1：临柜开户】
- 适合：本地企业和个人
- 流程：去柜台开户/开卡 → 存款
- 限制：必须本地，小金额不合算
- 场景：大金额或特殊要求时用

【方式2：网开（最常用）】
- 适合：全国任何地方的资金方
- 流程：
  ① 手机银行APP操作
  ② 开一个临时的网点的卡
  ③ 把钱转入
  ④ 第二天转回到主卡
- 优势：足不出户，灵活方便

【方式3：通知存款（网开的一种）】
- 适合：有该银行主卡的资金方（如长沙银行）
- 流程：
  ① 钱存在主卡上
  ② 转入"通知存款"
  ③ 1天（冲时点）或7天+（日均）
  ④ 到期转回主卡
- 优势：更简单，不需要开新卡
```

**Step 3: 付款和开卡**

```
付款方式（重要！）：
1. 定金制（熟悉客户）：
   • 谈好价格后，企业主先付定金
   • 我们安排资金方开卡
   • 开好卡后，企业主付尾款
   • 我们让资金方存款

2. 全款制（不熟悉客户）：
   • 我们确定好资金后
   • 企业主必须付全款
   • 然后我们才操作

开卡流程：
- 网开：资金方在手机APP操作
- 临柜：资金方去银行柜台
- 我们指导资金方完成
```

**Step 4: 存款和截图**

```
存款操作：
1. 资金方把钱转入指定账户
2. 转入金额=约定金额
3. 转入网点=指定网点/工号

完成确认：
1. 资金方存款完成后截图
2. 截图发给我们
3. 我们转发给企业主
4. 企业主让银行那边核对
5. 银行确认任务完成

资金回流：
1. 第二天（或约定时间后）
2. 资金方把钱转回自己主卡
3. 完成！
```

**Step 5: 结算**

```
我们的收益：
- 企业主支付的费用 - 资金方成本 = 我们利润
- 一般我们赚万1/天

举例：
100万存1天：
- 企业主付：500-1000元（万5-千1）
- 资金方成本：0元（钱只是转账，没成本）
- 我们赚：100元（万1）
- 或者如果市场价高，我们赚更多

100万存7天：
- 企业主付：3500-7000元
- 我们赚：700元（万1×7天）
```
