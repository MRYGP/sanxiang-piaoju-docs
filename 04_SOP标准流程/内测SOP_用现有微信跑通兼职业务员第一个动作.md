## 一、为什么现在可以开始做？

### 1.1 核心逻辑

你现在有 4 个微信，上面本来就躺着一批企业老板 / 财务 / 采购，这一批人本质上是：

> 「未来兼职业务员要去撬的那种关系」的**现实标本**

所以现在让这 4 个号，先去"发海报 + 问一问"，其实就是在做：

* **兼职 SOP 的 0 号内测**
* **话术与海报的 A/B 测试**
* **真实需求方向的验证（到底谁对什么感兴趣）**

比起先去社会上招一堆兼职，再慢慢教，他们肯定乱来一通，  
不如你这边先当"超级兼职 0 号"，把打法跑顺，再交给他们照抄。

### 1.2 执行原则

✅ **可以开始**对这几个微信上的企业客户发海报  
✅ **但建议先小范围、分批、带记录**，当成一个**为兼职打样的项目**来做  
✅ **不是微商乱轰炸**，而是"精益实验"的味道

---

## 二、兼职业务员第一个动作的精确定义

### 2.1 不准确的说法

> "做兼职业务做的第一件事：给用户推荐业务"

### 2.2 更精确的版本

> **兼职业务员的第一件事：  
> 用一条统一的问题，帮我们筛出有无"远期支票 / 资金 / 显账"需求，  
> 然后把有反应的人丢到公司企业微信和中台。**

**重点：**
- 不讲费率、到账时效、收益承诺
- 不解释太多技术细节（银票/商票/云信都算在"远期支票"里）
- 把行动非常具体化："发票面截图给我"、"我帮你问价 + 设计方案"

---

## 三、内测 SOP（5 步走）

### Step 0：先选人，不是对所有人一锅端

**4 个微信上，先挑这一批：**

* 关系相对熟一点的老板 / 财务 / 合伙人
* 至少聊过一次业务 / 项目的
* 行业别太奇怪，正常实体 / 贸易 / 服务都行

**目标量：**
👉 每个微信先挑 10 个左右，"熟+不排斥聊天"的企业客户  
总共大概 30–40 个，**足够验证一轮了**。

**记录方式：**
- 在飞书多维表中建立"内测客户名单"
- 字段：微信号、企业名称、联系人、关系程度、行业、备注

---

### Step 1：统一一个"总入口"，别讲太细

**核心抽象：**

> "远期支票" = 银票 / 商票 / 电子债权凭证 / 云信 / 航信之类  
> 企业和兼职**都不需要懂细分**，只要问：  
> 你有/要不要这种"远期支票"？

**这一轮就用总入口表达，不讲 A/B/C/E/F 各种业务名，**  
用一句话把"收 + 出"都包住：

> **有"远期支票"要变现吗？**  
> **或者你这边需要这类"远期支票"来付款 / 理财吗？**

这就天然跟你后端"白名单+票面拍照→冷部/姜部看"的模式对上了。

---

### Step 2：朋友圈海报 + 文案（通用版）

**先发朋友圈，再用同一套素材去一对一私聊。**

#### 朋友圈文案（示例，可微调语气）：

```
最近在帮几家企业老板处理「远期支票 / 电子债权凭证」这类事情：

• 有票，想尽快、合规地变成现金的
• 要付款，又想尽量保留现金流的
• 或者账户上阶段性需要"显账、好看一点"的

可以把票面截图 / 大概需求发给我，
我这边有固定合作方，可以帮你做个初步方案和价格参考。

✅ 合规路径，不搞虚假贸易 / 走流水
❌ 不承诺"稳赚""无风险高收益"
有需求再聊，没有需求就当我打个招呼。
```

#### 配图（简单文字海报即可）：

**标题：**
> 企业有「远期支票」要变现 / 付款？

**三个 bullet：**
> ✅ 银票 / 商票 / 云信 / 航信 等  
> ✅ 合规通道，票款走公账  
> ✅ 发票面截图，先帮你问价

**底部：**
> 你的名字 + 微信

**注意：**
- 等有运营 / 外包后，再升级设计就行
- 现在先用简单文字海报，重点是验证话术和需求

---

### Step 3：一对一私聊话术（这个就是以后兼职第一句话）

**可直接用、也可以后给兼职照抄的私聊话术：**

```
X总，打扰一下，最近这边在对接几家银行和资金方，
专门处理企业手上的「远期支票 / 电子债权凭证」这类票据，
想直接问一句：

您公司现在有没有

• 这类票据要变现，
  或者
• 近期有比较大的付款，想看看能不能用票据方案的？

如果有，我可以先帮您问下价格和大概操作方式，
没有也没关系，当我打个招呼，
以后手上有这类票据，也可以发给我帮您一起看看。
```

**重点：**
- 不讲费率、到账时效、收益承诺
- 不解释太多技术细节（银票/商票/云信都算在"远期支票"里）
- 把行动非常具体化：
  - "发票面截图给我"
  - "我帮你问价 + 设计方案"

---

### Step 4：对接流程，要简单到兼职能照抄

**你这次用 4 个号做的是"内测"，但流程最好就按兼职版来走：**

1. **客户说"有票 / 有需求"**
2. **让他们发：票面截图 / 付款金额 / 大致时间**
3. **你这边直接塞进：**
   - 【远期支票收单 checklist】（在知识库里）
   - 或者一个飞书多维表模板（企业名 / 票种 / 金额 / 到期日 / 要求）
4. **冷部/姜部/后端服务商看完，给出：**
   - 能不能收 / 找不找得到
   - 大致价格区间
   - 大致流程（公账走法，不讲细节）

**以后兼职就是把第 1~3 步做了，4 由你们中台来。**

**对接工具：**
- 飞书多维表：《远期支票收单表》（见《04_SOP标准流程/TODO_待创建/SOP03_远期支票收出操作清单.md》）
- 或直接拉群：你 + 客户 + 总部/冷部

---

### Step 5：记数据，这才是"精益"

**建议你顺手建一个非常简陋的表（飞书多维表就行）：**

#### 数据记录表字段：

* **微信号**（4 个号中的哪个）
* **企业名称**
* **联系人**
* **是否发送朋友圈**（是/否）
* **是否私聊**（是/否）
* **客户反应**：
  * A = 有票或短期内大概率有
  * B = 暂时没票但不排斥
  * C = 明确说没兴趣
* **需求类型**（变现 / 付款 / 显账 / 其他）
* **是否进入后续跟进**（是/否）
* **备注**

#### 目标很简单：

👉 一轮下来看到：

* **哪种表达最容易让人愿意聊几句？**
* **真正有票/有需求的占比大概多少？**
* **哪类客户更容易开口？**（行业 / 角色 / 之前关系）

#### 这些结论会直接反哺给"兼职工具包"：

* 朋友圈文案用哪个版本
* 私聊开场用哪句
* 兼职应该优先撬"什么类型的已有客户"

## 四、执行时间表（建议）

### 第1周：准备与选人
- **Day 1-2**：从4个微信中挑选30-40个目标客户，建立"内测客户名单"
- **Day 3-4**：准备朋友圈文案和简单海报
- **Day 5-7**：建立数据记录表，准备对接流程

### 第2周：执行与记录
- **Day 1-3**：分批发送朋友圈（每天1-2个微信号，避免刷屏）
- **Day 4-7**：一对一私聊（每天5-10个客户，避免骚扰）
- **每天**：记录客户反应和数据

### 第3周：复盘与优化
- **Day 1-2**：汇总数据，分析结果
- **Day 3-4**：优化话术和流程
- **Day 5-7**：整理成"兼职工具包v1"，准备给新兼职使用

## 五、预期成果

### 5.1 直接成果

1. **验证话术有效性**：哪种表达方式更容易获得客户回应
2. **验证需求真实性**：真正有票/有需求的客户占比
3. **验证客户画像**：哪类客户更容易开口（行业/角色/关系）
4. **跑通对接流程**：从"问需求"到"移交中台"的完整流程

### 5.2 间接成果

1. **兼职工具包v1**：
   - 朋友圈文案（已验证版本）
   - 私聊话术（已验证版本）
   - 简单海报（可升级设计）
2. **真实案例**：可以讲给新兼职听的案例
3. **数据支撑**：为后续大规模招募兼职提供数据参考

## 六、注意事项

### 6.1 红线

- ❌ **不要承诺**：固定收益、绝对安全、"肯定能做"
- ❌ **不要解释**：太多技术细节（银票/商票/云信的区别）
- ❌ **不要轰炸**：不要对所有人一锅端，要分批、有选择

### 6.2 原则

- ✅ **合规路径**：不搞虚假贸易 / 走流水
- ✅ **真实需求**：有需求再聊，没有需求就当我打个招呼
- ✅ **数据驱动**：所有动作都要记录，用数据说话

---

## 七、后续迭代

### 7.1 如果效果好

- 扩大范围：从30-40个客户扩大到更多
- 优化话术：根据数据反馈，优化朋友圈文案和私聊话术
- 升级设计：找外包升级海报设计
- 复制给兼职：把验证过的工具包给新兼职使用

### 7.2 如果效果一般

- 分析原因：是话术问题？客户选择问题？还是需求本身？
- 调整策略：根据数据分析，调整话术、客户选择、表达方式
- 小步迭代：不要大改，小步快跑，持续优化
