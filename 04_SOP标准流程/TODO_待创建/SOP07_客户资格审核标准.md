# SOP07_客户资格审核标准 ⭐ 高优先级

## 📋 标准概述

本文档描述客户资格审核的标准和流程。

## ✅ 审核标准

### 各业务审核要点

#### A业务：票据/凭证贴现

**审核维度：**

1. **票据/凭证真实性**
   - 票据/凭证是否真实有效（非伪造、非虚假）
   - 票面信息是否完整清晰（承兑人、金额、到期日等）
   - 票据/凭证状态是否正常（未被冻结、未被挂失等）

2. **出票方信用评估**
   - 承兑/付款方是否有显著负面舆情
   - 是否有重大涉诉、被执行严重超标等情况
   - 是否在白名单内（冷部评估）

3. **票据/凭证类型与金额**
   - 票据/凭证类型是否支持（银票/商票/财票/电子债权凭证等）
   - 票面金额是否在可接受范围内
   - 到期时间是否合理

4. **客户需求真实性**
   - 客户是否确实急需用钱（不能等到期）
   - 用途是否正常（非可疑用途）
   - 客户是否理解这是"票据收购"，会损失贴现费用

5. **合规意识**
   - 是否接受全流程公对公操作
   - 是否接受合同+发票对齐
   - 是否理解到账时效为示例区间，不构成刚性承诺

**硬性否决条件：**
- 明显伪造、虚假的票据/凭证
- 有显著负面舆情、重大涉诉的出票方
- 用途本身就高度可疑的情况
- 客户明确要求"固定收益、绝对安全"
- 客户不接受公对公操作，要求私卡/内部秘密/线下结算

#### B业务：承兑/凭证销售（企业付款成本优化）

**审核维度：**

1. **付款需求真实性**
   - 是否有明确的付款需求（付货款、工程款、材料款等）
   - 付款金额是否合理
   - 付款时间是否明确

2. **企业和供应商凭证账户开通情况**
   - 企业是否开通了凭证账户（能接收承兑/凭证）
   - 供应商是否开通了凭证账户（能接收承兑/凭证）
   - 每种凭证有独有的支付平台（需要双方都开通）

3. **供应商接受度**
   - 供应商是否接受承兑/凭证
   - 供应商是否愿意开通凭证账户（如未开通）

4. **企业资金情况**
   - 企业是否有现金先付给我们（核心要求：企业必须先付现金给我们，我们才给凭证）
   - 企业资金来源是否正常（无明显合规风险）

5. **合规意识**
   - 是否接受全流程公对公操作
   - 是否接受合同+发票对齐
   - 是否理解节省成本为示例区间，不构成刚性承诺

**硬性否决条件：**
- 供应商明确不收凭证，且不愿意开通凭证账户
- 企业没有现金先付给我们（核心要求：企业必须先付现金给我们）
- 用途本身就高度可疑的情况
- 客户明确要求"固定收益、绝对安全"
- 客户不接受公对公操作，要求私卡/内部秘密/线下结算

#### C业务：冲存款（银行存款任务撮合）

**审核维度：**

1. **企业主需求真实性**
   - 是否有明确的银行关系维护需求（求银行办事：贷款、授信、其他业务支持）
   - 银行是否要求企业主帮忙完成存款任务
   - 企业主是否愿意买单帮忙，维护银行关系

2. **存款需求明确性**
   - 存款金额是否明确（几十万-几千万不等）
   - 存款时间是否明确（1天、7天、1个月等）
   - 指定网点是否明确（具体支行名称或银行人员工号）

3. **资金来源合规性**
   - 资金来源是否干净（非黑钱、非洗钱等）
   - 企业主资金来源是否正常（无明显合规风险）
   - 是否存在明显不适合做C业务的情况

4. **银行政策合规性**
   - 银行是否明确不允许外部资金冲存款
   - 是否存在银行内部考核作弊等违规风险
   - 是否符合银行监管要求

5. **合规意识**
   - 是否理解这是"存款撮合服务"，需要支付服务费
   - 是否理解服务费为示例区间（市场价万5-千1/天，具体以市场为准），不构成刚性承诺
   - 是否理解资金不过我们的手，全程由资金方和企业主直接对接

**硬性否决条件：**
- 资金来源不干净（黑钱、洗钱等）
- 银行明确不允许外部资金冲存款
- 企业主不愿意买单（没有维护银行关系的需求）
- 用途本身就高度可疑的情况
- 客户明确要求"保证完成存款任务"、"100%安全/零风险/绝对合规"
- 客户不接受公对公操作，要求私卡/内部秘密/线下结算

#### D业务：贸易套利指导

**审核维度：**

1. **真实贸易背景**
   - 企业是否有真实贸易背景（真实发票）
   - 真实发票是否符合银行/平台贴现要求
   - 是否存在伪造发票、虚假贸易等风险

2. **套利需求明确性**
   - 套利需求是否明确（场景1/2/3/4）
   - 套利金额、期限是否明确
   - 企业是否符合银行/平台贴现资质要求

3. **企业配合度**
   - 企业是否愿意配合完成套利操作（开承兑、抵押凭证等）
   - 场景3是否需要A企业配合（A企业可以配合，或者是B企业实际控制的）
   - 场景4是否需要银行协商（银行支持凭证抵押开银票）

4. **资金来源合规性**
   - 企业资金来源是否正常（无明显合规风险）
   - 是否存在明显不适合做D业务的情况

5. **合规意识**
   - 是否理解这是"贸易套利指导服务"，企业自己去银行/平台贴现赚差价
   - 是否理解我们不收取咨询费、服务费，我们赚的是卖票/凭证的差价，或开承兑的服务费
   - 是否理解套利收益为示例区间，不构成刚性承诺

**硬性否决条件：**
- 企业没有真实贸易背景（没有真实发票）
- 企业不符合银行/平台贴现要求
- 用途本身就高度可疑的情况
- 客户明确要求"保证赚差价"、"100%安全/零风险/绝对合规"
- 客户不接受公对公操作，要求私卡/内部秘密/线下结算

#### E业务：债券投资服务（债券配置顾问服务）

**审核维度：**

1. **资金规模**
   - 是否达到最低门槛（通常30万-2000万左右，具体按合作方要求）
   - 资金规模是否与客户企业规模匹配

2. **资金使用期限**
   - 是否适合3-12个月配置
   - 是否有明确的资金使用时间点（如有，需评估是否适合E业务）

3. **风险认知**
   - 客户是否理解"非保本、不承诺收益"
   - 是否接受收益有浮动
   - 是否理解债券投资存在价格波动风险、利率风险、信用风险

4. **资金来源与用途**
   - 资金来源是否正常（无明显合规风险）
   - 资金用途是否正常（非担保、非贷款还款等紧急用途）
   - 是否存在明显不适合做E业务的情况（如资金马上要还贷款等）

5. **合规意识**
   - 是否接受去券商/银行正规开户
   - 是否接受签风险揭示书
   - 对"钱在自己账户，产品由持牌机构提供"是否有基本认同

**硬性否决条件：**
- 资金来源不明或存在合规风险
- 资金使用期限不足3个月或超过12个月
- 客户明确要求"保本保收益"
- 资金用途为紧急还款、担保等不适合配置的情况

#### F业务：摆账（亮资）

**审核维度：**

1. **显账需求真实性**
   - 是否有明确的显账用途（招投标 / 授信 / 评级 / 对外合作等）
   - 是否有明确的时间窗口要求
   - 目标显账金额是否合理

2. **还款能力评估**
   - 企业是否有持续经营收入或确定性回款来源
   - 是否有可用于担保/抵押的资产
   - 是否存在明显资不抵债、恶意逃废债倾向

3. **风险识别**
   - 是否有显著负面舆情、重大涉诉、被执行严重超标等情况
   - 用途是否高度可疑（如明说"就是骗谁一眼"）
   - 是否存在"循环借新还旧"导致实质性资不抵债的风险

4. **资金成本接受度**
   - 是否理解这是真实借款，需要支付资金成本和服务费
   - 是否接受"有成本的短期借款"安排
   - 预期可接受的资金成本范围是否合理

5. **合规意识**
   - 是否理解显账本身不保证一定中标/获批授信
   - 是否接受真实借贷、真实显账、合约化资金安排
   - 是否存在明显欺诈动机

**硬性否决条件：**
- 明显资不抵债、恶意逃废债倾向
- 有显著负面舆情、重大涉诉、被执行严重超标
- 用途高度可疑（如明说"就是骗谁一眼"）
- 客户明确要求"只做个样子，不用担心还款"
- 存在"循环借新还旧"导致实质性资不抵债的风险

#### G业务：专利出资实缴服务

**审核维度：**

1. **企业基本信息**
   - 注册资本是否≥500万（越大越有需求）
   - 实缴比例是否较低
   - 成立时间是否≥1年
   - 行业是否正常（科技、服务、贸易、电商、制造业等）
   - 经营状态是否正常（无大面积经营异常、吊销风险）

2. **实缴需求真实性**
   - 是否有明确的实缴压力（新公司法要求5年内实缴完成）
   - 实缴目的是否明确（融资计划、招投标需求、银行授信需求、上市/规范化需求等）
   - 是否不想减资（担心影响企业形象、合作方观感）
   - 是否现金流紧张，不愿意用大量现金压在注册资本里

3. **企业风险审查（三必审）**
   - 必审企业工商信息（诉讼、失信、异常）
   - 必审股东背景（是否涉及刑事案件）
   - 必审业务合理性（注册资本与业务规模是否匹配）

4. **合规意识**
   - 是否理解这是"专利出资"，不是"零成本实缴"
   - 是否接受有资质的评估机构和会计师事务所出报告
   - 是否理解需要支付服务费（8-12%区间）
   - 是否接受税务处理需由专业税务师/律师确认

**硬性否决条件（三必拒）：**
- 正在重大诉讼/执行中的企业（特别是债务纠纷）
- 明确要求做高评估、仅为转移资产的客户
- 明显资不抵债且无正常经营场景的壳公司
- 明确表示要"转移资产""逃避债务"
- 要求"做高评估、走个流程就行""反正不会查"的客户

#### H业务：贸易"带量"/流水包装（禁止业务）

**审核维度（风险识别）：**

1. **危险信号识别**
   - 是否提到"走流水""做账""做大营收"
   - 是否提到"帮我做点贸易量""帮我冲业绩"
   - 是否提到"货不用真实走""货就在原地"
   - 是否提到"主要是为了好看一点、好审批"
   - 是否提到"做个贸易背景，好去银行那边说事"
   - 是否提到"我需要走一笔流水"
   - 是否提到"帮我做大一点营业额"
   - 是否提到"需要做个贸易背景，好去融点钱"
   - 是否提到"货其实不用动，就按你们的流程过一圈"
   - 是否提到"开票额度不够，你帮我安排一笔贸易开票"

2. **真实贸易需求判断（仅在符合以下前提时，才考虑讨论其他合规方案）**
   - 客户是否有真实的商品交易需求
   - 是否有真实的货物、真实的对手方、真实的合同与发票
   - 利润空间、交易结构是否符合正常商业逻辑
   - 客户的诉求是否是：优化付款方式、现金流节奏、票据结构，而不是"虚增营收/流水"

**硬性否决条件（公司铁律）：**
- 🚫 **任何形式的"贸易带量""流水包装"业务一律禁止**
- 🚫 帮助客户虚构贸易背景
- 🚫 参与"空转""走单""循环贸易"
- 🚫 通过虚假贸易帮助客户获得融资、授信或开票额度
- 🚫 以虚构贸易为基础设计任何票据/资金方案
- 🚫 无真实货物、无真实交易背景的贸易和流水

**处理指引：**
- 遇到明显H类需求：立即用标准拒绝话术明确表达"不做、不碰"
- 不要深度探讨方案细节，不给对方"误以为我们能做"的空间
- 将该客户和谈话记录简要写入内部备注，标记为"高风险需求"，必要时向创始人汇报
- 如果客户有真实贸易需求，可引导至A/B业务（票据/凭证工具）或其他合规方案
