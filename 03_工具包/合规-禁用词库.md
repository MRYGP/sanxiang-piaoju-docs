# 合规禁用词库

**用途**：对外内容发布前，自动检查是否包含禁用词  
**使用方式**：AI工具在生成对外内容时，自动比对此词库  
**更新频率**：发现新的合规风险词时立即更新

---

## 🔴 一级禁用词（绝对禁止）

- 保证
- 承诺
- 确保
- 100%
- 零风险
- 绝对
- 必然
- 一定

### 收益类

- 稳定收益

## 🟡 二级禁用词（需替换为条件表述）

### 时效类
- "10分钟到账" → 替换为 "通常10分钟-2小时（以实际通道为准）"
- "快速到账" → 替换为 "通常当日到账（受银行处理时间影响）"

### 收益类
- "年化X%" → 替换为 "示例：年化约X%（以实际成交为准）"
- "省X%" → 替换为 "通常可省约X%（受市场行情影响）"

### 效果类
- "解决资金问题" → 替换为 "提供资金周转方案"
- "轻松融资" → 替换为 "简化融资流程"

---

## 🟢 三级词汇（需加脚注说明）

凡涉及具体数据、时间、收益的表述，必须加脚注：

```
*以上数据为示例值，实际结果受市场行情、票种、额度、通道等因素影响，具体以成交时为准。
```

示例：
- "示例：半年期银承约省0.2%-0.8%*"
- "通常10分钟-2小时到账*"

---

## 📋 检查流程

对外内容发布前，逐项检查：
1. [ ] 一级禁用词：有无绝对承诺表述？
2. [ ] 二级禁用词：时效/收益表述是否加条件限定？
3. [ ] 三级词汇：具体数据是否加脚注说明？
4. [ ] 整体语气：是否避免夸大和误导？
