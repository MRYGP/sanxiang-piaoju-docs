# 小复盘模板（Excel版）

**版本**：v1.0  
**创建日期**：2025-12-04  
**使用方式**：每天晚上填写，记录当天最有代表性的1-2个客户/对话  
**执行时间**：30分钟

---

## 📋 使用说明

### 为什么要做复盘？

**根据同事建议**：
> 每接完一单/一次深入聊天，就填一份"小复盘"。
> 累积到一定数量，就把这个业务做成：
> - 1页产品说明
> - 3步流程
> - 常见问题Q&A
> - 合伙人版"套件"（话术+素材+分成规则）

**目标**：
- 短期：积累真实案例，优化话术
- 中期：沉淀业务SOP，提高成交率
- 长期：制作"合伙人套餐"，赋能中介

## 📊 Excel表格结构设计

### Sheet1：客户案例复盘表（主表）

| 字段名 | 说明 | 填写示例 | 数据类型 |
|--------|------|----------|----------|
| **A列：案例编号** | 自动编号 | CASE001 | 文本 |
| **B列：记录日期** | 对话日期 | 2025-12-04 | 日期 |
| **C列：客户标签** | 行业/规模/地点 | 制造业/年营业额3000万/深圳 | 文本 |
| **D列：客户原始痛点** | 一句话痛点 | 贷款利率12%太高，每年利息上百万 | 文本（100字内） |
| **E列：我给的方案摘要** | 2-3句话方案 | 推荐B业务-凭证付款降成本，年化能降到6-8%，预计每年省50-80万 | 文本（200字内） |
| **F列：客户最有反应的话** | 客户原话 | "如果真能省这么多，我肯定愿意试试" | 文本（100字内） |
| **G列：可复制的点** | 这个案例最值得复制什么 | 高息客户+有应付账款=B业务高转化 | 文本（100字内） |
| **H列：下次优化方向** | 如果再遇到类似客户怎么做更好 | 开场就问应付账款情况，直接切B业务 | 文本（100字内） |
| **I列：适合推荐的业务** | A-H业务 | B业务 | 下拉选项（A/B/C/D/E/F/G/H） |
| **J列：当前状态** | 跟进状态 | 报价中/已成交/暂无意向 | 下拉选项 |
| **K列：预估成交概率** | 主观判断 | 70% | 数值（0-100%） |
| **L列：记录人** | 谁填的 | 常松阳/杨/廖 | 文本 |
| **M列：备注** | 其他信息 | 客户很急，3天内要答复 | 文本 |

---

### Sheet2：业务复盘汇总表（自动生成）

这个表格通过公式自动汇总Sheet1的数据，方便分析。

| 字段名 | 说明 | 公式/逻辑 |
|--------|------|----------|
| **A列：业务类型** | A-H业务 | 手动输入（A/B/C/D/E/F/G/H） |
| **B列：累计案例数** | 这个业务的案例数量 | =COUNTIF(Sheet1!$I:$I,A2) |
| **C列：成交案例数** | 已成交的案例数 | =COUNTIFS(Sheet1!$I:$I,A2,Sheet1!$J:$J,"已成交") |
| **D列：成交率** | 成交率 | =C2/B2 |
| **E列：平均成交概率** | 平均预估成交概率 | =AVERAGEIF(Sheet1!$I:$I,A2,Sheet1!$K:$K) |
| **F列：高频痛点** | 这个业务客户的常见痛点 | 手动总结（每周更新） |
| **G列：高转化话术** | 哪些话效果最好 | 手动总结（每周更新） |

**效果**：
- 一眼看出哪个业务案例多
- 哪个业务成交率高
- 哪个业务值得重点做

---

### Sheet3：每周复盘总结表

| 字段名 | 说明 | 填写示例 |
|--------|------|----------|
| **A列：周数** | 第几周 | Week 1 (12/02-12/08) |
| **B列：本周新增案例数** | 本周填了几个复盘 | 10个 |
| **C列：本周成交数** | 本周成交几单 | 2单 |
| **D列：主要业务线** | 本周主要测试哪个业务 | A业务、B业务 |
| **E列：主要发现** | 本周最重要的3个发现 | 1. 高息客户对B业务最感兴趣<br>2. 有票据的客户更容易成交A业务<br>3. 征信有瑕疵的客户很难转化 |
| **F列：下周计划** | 下周重点做什么 | 1. 继续测试A/B业务<br>2. 优化B业务话术<br>3. 积累3个A业务案例 |

## 📝 填写流程（每天晚上30分钟）

### Step 1：选择案例（5分钟）

**问自己**：
- 今天有哪些客户对话？
- 哪1-2个最有代表性？
- 什么是"有代表性"？
  - 客户反应最强烈的
  - 对话过程最深入的
  - 接近成交的
  - 遇到新痛点/新场景的

**注意**：
- 不是每个客户都要填
- 只填最有价值的1-2个
- 宁缺毋滥

---

### Step 2：回忆细节（10分钟）

**打开微信聊天记录**：
- 重新看一遍对话
- 找出客户的"原话"（尤其是有反应的那句）
- 回忆当时的感受

**关键问题**：
- 客户为什么有反应？
- 我说了什么打动了他？
- 有哪些地方可以做得更好？

---

### Step 3：填写表格（10分钟）

**快速填写**：
- 不要追求完美
- 不要写长文（每个字段100-200字足够）
- 重点是"可复制的点"和"下次优化方向"

**示例填写**：

| 字段 | 内容 |
|------|------|
| 案例编号 | CASE001（自动生成） |
| 记录日期 | 2025-12-04 |
| 客户标签 | 制造业/年营业额3000万/深圳 |
| 客户原始痛点 | 贷款利率12%太高，每年利息上百万 |
| 我给的方案摘要 | 推荐B业务-凭证付款降成本，年化能降到6-8%，预计每年省50-80万。具体方式是：把应付账款改成我们的凭证付款，既能付货款，又能降低融资成本。 |
| 客户最有反应的话 | "如果真能省这么多，我肯定愿意试试。你们这个是怎么操作的？" |
| 可复制的点 | 高息客户（>10%）+有大量应付账款（>500万）=B业务高转化。开场直接问应付账款情况，比问贷款情况更有效。 |
| 下次优化方向 | 1. 开场就问应付账款，不要等客户说完贷款情况再问<br>2. 准备3个同行业案例，增加说服力<br>3. 提前准备成本对比表（Excel），现场演示更直观 |
| 适合推荐的业务 | B业务 |
| 当前状态 | 报价中 |
| 预估成交概率 | 70% |
| 记录人 | 常松阳 |
| 备注 | 客户说3天内要答复，周五前跟进 |

---

### Step 4：周末汇总（30分钟，每周五）

**查看Sheet2：业务复盘汇总表**：
- 本周8个业务，哪个案例最多？
- 哪个业务成交率最高？
- 哪些痛点出现频率最高？

**填写Sheet3：每周复盘总结表**：
- 本周主要发现（3个）
- 下周计划（3个重点）

**思考**：
- 需要调整内容策略吗？
- 需要优化话术吗？
- 需要补充什么工具/素材？

## 💡 高级用法

### 用法1：快速生成案例文案

**场景**：Week 5-8，需要制作朋友圈案例文案

**方法**：
1. 打开Excel，筛选"已成交"的案例
2. 选择3-5个典型案例
3. 复制到Claude："帮我把这几个案例改写成朋友圈文案"

**Claude会生成**：
```
【案例分享】如何帮制造企业每年省50万利息？

上周接待了深圳一家制造企业张总，年营业额3000万，贷款利率12%，每年光利息就要付120万。

我们帮他做了个贷款体检，发现他们有大量应付账款，推荐用我们的凭证付款服务，年化能降到6-8%。

张总算了算，一年能省50-80万，立即决定试试。

如果您的企业也有类似情况，可以加我微信，免费帮您做个贷款体检，看看有没有优化空间。

回复【体检】即可
```

---

### 用法2：制作"合伙人套餐"

**场景**：Week 9-12，需要给中介制作"傻瓜套餐"

**方法**：
1. 筛选某个业务（比如B业务）的所有案例
2. 总结：
   - 高频痛点（前3个）
   - 高转化话术（前5句）
   - 典型案例（前3个）
3. 制作成：
   - 1页产品说明书
   - 3步操作流程
   - 常见问题Q&A

**输出示例**：
```
【B业务-合伙人套餐v1.0】

## 1页产品说明
**业务名称**：凭证付款降成本服务
**适用客户**：贷款利率>8% + 有应付账款>500万
**核心价值**：年化成本降到6-8%，每年省XX万
**成交概率**：70%（根据10个案例统计）

## 3步操作流程
Step 1：问客户"贷款利率多少？有没有应付账款？"
Step 2：如果利率>8%且有应付账款，推荐B业务
Step 3：发案例+成本对比表，约客户深聊

## 常见问题Q&A
Q1：这个合法吗？
A1：完全合法，基于真实贸易背景...

Q2：客户担心风险怎么办？
A2：告诉客户有合同、发票、凭证...

（共10个常见问题）
```

---

### 用法3：优化话术库

**场景**：发现某些话效果特别好

**方法**：
1. 在Excel中筛选"客户最有反应的话"
2. 找出哪些是你说的话（而不是客户说的话）
3. 提炼成"高转化话术TOP 10"
4. 补充到《展业话术大全.md》

**示例**：
```
【高转化话术TOP 10】（根据30个案例统计）

排名1："如果真能省这么多，您愿意试试吗？"
- 场景：报价后
- 转化率：80%（10个用这句话，8个成交）
- 为什么有效：给客户台阶下，降低承诺压力

排名2："您现在的应付账款大概有多少？"
- 场景：开场问诊
- 转化率：70%（15个问这个，10个有后续）
- 为什么有效：直接切B业务的关键问题

（以此类推）
```

## 📊 效果评估标准

### 个人效果评估

**合格标准**（每周）：
- 复盘数量：≥3个
- 复盘质量：字段填写完整度≥80%
- 有价值案例：≥1个（能直接用的）

**优秀标准**（每周）：
- 复盘数量：≥7个（每天1个）
- 复盘质量：字段填写完整度100%
- 有价值案例：≥3个
- 主动优化话术：≥1次

---

### 团队效果评估

**Week 0-4目标**：
- 累计案例数：≥30个（3人×4周×2.5个/人/周）
- 覆盖业务：8个业务都有案例
- 成交案例：≥5个

**Week 5-8目标**：
- 累计案例数：≥60个
- 主业务案例数：≥20个（聚焦1-2个业务）
- 成交案例：≥10个
- 沉淀SOP：1-2个业务的完整流程

**Week 9-12目标**：
- 累计案例数：≥100个
- 合伙人套餐：1-2个业务的完整套餐
- 中介成交案例：≥5个（中介带来的）

## 🎯 配合其他工具

### 配合"贷款体检7连问"

**联动使用**：
1. 用7连问收集客户信息
2. 用小复盘记录对话过程
3. 7连问关注"客户情况"
4. 小复盘关注"我的表现"

**数据打通**：
- 7连问的"记录模板"可以复制到小复盘的"客户标签"栏
- 7连问的"业务推荐"对应小复盘的"我给的方案"

---

### 配合"每日内容生成模板"

**联动使用**：
1. 晚上填完小复盘
2. 第二天早上把案例交给Claude
3. Claude生成基于真实案例的朋友圈文案

**示例流程**：
```
晚上：填写小复盘，发现一个很好的B业务案例

第二天早上：
"Claude，基于昨天这个案例（复制小复盘内容），生成今天的朋友圈文案"

Claude生成：
【案例分享】如何帮深圳制造企业每年省50万利息？...
```

## 🎓 实战案例：如何用好这个模板

### 案例1：常松阳的Week 1使用记录

**周一**：
- 接触3个客户，填写2个复盘
- CASE001：制造业/B业务/报价中/70%
- CASE002：贸易公司/A业务/暂无意向/20%

**周二**：
- 接触2个客户，填写1个复盘
- CASE003：服务业/H业务/深聊中/50%

**周三**：
- 接触4个客户，填写2个复盘
- CASE004：制造业/B业务/已成交/100%
- CASE005：贸易公司/D业务/报价中/60%

**周四**：
- 接触1个客户，填写1个复盘
- CASE006：建筑业/G业务/暂无意向/10%

**周五**：
- 接触2个客户，填写1个复盘
- CASE007：制造业/A业务/报价中/80%

**周五晚复盘**：
- 本周累计7个案例
- B业务3个（成交1个）→ B业务值得重点做
- 制造业客户占比最高 → 下周重点开发制造业
- 发现：开场问应付账款比问贷款情况更有效

**下周计划**：
- 继续测试B业务，目标成交2单
- 优化B业务话术（提前准备应付账款问题）
- 制作B业务案例文案（用CASE004）
