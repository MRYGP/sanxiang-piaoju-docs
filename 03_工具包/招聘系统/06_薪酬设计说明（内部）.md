## 📐 设计逻辑

### 核心理念

我们的薪酬设计遵循一个核心原则：

**用确定性的钱买执行力，用可能性的钱买野心**

这不是传统的"底薪+提成"，而是**"底薪+过程绩效+结果提成"**三级推进式结构。

------

### 三级推进薪酬结构

#### 第一级：底薪8K（保命钱）

**目的**：让候选人敢入职，不担心饿死

**设计逻辑**：

- 无责任底薪，只要人来了就有
- 在长沙运营岗位中属于中高水平（市场价6-8K）
- 这是"安全感"的来源

**为什么是8K而非10K？**

- 8K足够吸引人，但不会让人躺平
- 留出空间让过程绩效和提成发挥作用
- 控制公司固定成本

------

#### 第二级：过程绩效2-4K（辛苦钱 - 新手保护期特有）⭐ 核心创新

**目的**：降低新人压力，避免"没出单就跑"

**为什么要设计保护期？**

传统业务岗的问题：

- 纯提成制 → 新人压力巨大 → 熬不到出单就跑了 → 招聘成本浪费

我们的解法：

- 前2个月考核"过程质量"而非"业绩结果"
- 降低新人焦虑，让他们有时间跑通模式

**为什么考核"激活率"而非"招募数量"？**

❌ **错误指标**：招募30人

- 问题：容易刷数据，随便拉30个无效合伙人凑数
- 结果：公司付了钱，但渠道是死的

✅ **正确指标**：激活率20%（30人中6人发圈）

- 优势：证明运营能力（培训赋能到位）
- 结果：公司付费买的是"活跃的渠道"，而非人头
- 未来价值：6个活跃合伙人 = 未来的业绩管道

**三个考核指标的深层逻辑**：

1. **激活率20%（核心指标）**
    - 物理本质：让合伙人从"被动听课"变成"主动发圈"
    - 验证能力：培训赋能能力（能不能"洗脑"合伙人）
    - 防刷机制：朋友圈截图 + 随机抽查3人验证
    - S2b2C本质：我们是赋能小b，只有小b动起来了，C端才会来
2. **有效线索3-5条/月（质量指标）**
    - 物理本质：合伙人愿意主动推客户（说明信任度够）
    - 验证能力：激励能力（能不能让合伙人"卖力干活"）
    - 防刷机制：后端电话验证（客户真实存在+有需求）
    - 标准宽松：哪怕最后没成交也算有效（不为运气负责）
3. **SOP执行100%（动作指标）**
    - 物理本质：每天群发早报、每周培训等规定动作
    - 验证能力：勤奋度（能不能坚持做重复的事）
    - 防刷机制：群聊记录可查
    - 保底要求：这是最基础的执行力

**如何防止作弊？**

| 作弊手段             | 防御机制                         |
| -------------------- | -------------------------------- |
| 让合伙人假装发圈截图 | 要求朋友圈公开可见 + 随机抽查3人 |
| 让合伙人推假客户     | 后端电话验证（客户真实存在）     |
| 只做SOP，不干实事    | 激活率和有效线索是硬指标         |

------

#### 第三级：结果提成（发财钱）

**目的**：给野心，上不封顶

**保护期后的收入结构**：

1. **A业务（票据贴现 - 流量品）**：
    - 特点：单笔利润薄（几百到几千），但高频
    - 提成比例：利润的10-15%
    - 长期价值：被动收入
    - 举例：100个合伙人，每天10%的人动，每天都有进账
2. **B-H业务（利润品）**：
    - 特点：单笔利润高（几万到几十万），但低频
    - 提成比例：利润的20-30%
    - 爆发价值：一单顶几个月工资
    - 举例：资产隔离一单，提成可能就是2-3万

**为什么上不封顶？**

- 我们是S2b2C平台，运营赚得越多，说明渠道越活跃，公司也赚得越多
- 双赢，不存在"员工赚多了公司亏"的问题

------

### 新手保护期的本质逻辑（S2b2C视角）

**我们在买什么？**

- ❌ 不是在买"业绩"（那是结果，有运气成分）
- ✅ 是在买**"活跃的渠道"**（合伙人网络）

**为什么愿意为"过程"买单？**

在S2b2C模式下：

- S（我们）的价值 = 渠道网络的活跃度
- b（合伙人）的活跃度 = 运营的赋能能力
- 所以，我们为"运营能力"买单，就是为"未来业绩"买单

**类比**：

- 传统B2B：付费买"成交结果"（一锤子买卖）
- 我们S2b2C：付费买"渠道资产"（长期管道）

**数据验证**：

- 如果运营2个月激活率20%（6个活跃合伙人），但一单没成，我们亏吗？
- 不亏！因为这6个活跃合伙人 = 未来的业绩管道，这是战略投资

## ⚖️ 法律风险防范

### 薪资打包法（合同条款示例）

**核心问题**：单休是否要额外支付加班费？

**答案**：不需要，只要合同写清楚"打包"

**合同条款模板**：

```
甲方（公司）向乙方（员工）支付的月薪构成如下：

- 基本工资：3,000元
- 岗位绩效：4,000元
- 综合补贴（含周六加班费）：3,000元

合计：10,000元/月

双方确认：
1. 乙方同意执行单休制（周一至周六上班，周日休息）
2. 上述"综合补贴"已包含周六加班费及延时工资
3. 乙方理解并同意此薪酬结构
4. 乙方签字确认已阅读并理解本条款

员工签字：__________ 日期：__________
```

**关键点**：

- 把总薪资拆成"基本工资 + 绩效 + 补贴"
- 基本工资设低（3000元），作为计算加班费的基数
- 补贴设高（3000元），且明确"含加班费"
- 员工签字确认

**法律依据**：

- 劳动合同法允许"综合工时制"（需报备）或"打包薪资"（合同明确即可）
- 关键是**合同中明确写清**，且员工签字确认

**风险提示**：

- 如果员工真去仲裁，仲裁员可能不认"打包"（这是灰色地带）
- 建议操作：
    1. 找专业HR或律师审核合同条款（淘宝200-500元）
    2. 保留员工签字的《薪酬确认书》（独立文件，强化证据）
    3. 如有余力，向劳动局申请"综合工时制"（最稳妥）

------

### 单休制度的合规说明

**问题**：单休是否违法？

**答案**：不违法，但要处理好

**合规要点**：

1. **劳动合同中明确约定"单休制"**
    - 不要只口头说，必须写在合同里
2. **薪资中明确标注"含加班费"**
    - 用"综合补贴"或"加班包干费"等名义
3. **确保每周工作时间不超过法定上限**
    - 标准工时制：每周工作40小时，周六算加班
    - 综合工时制：每周工作不超过44小时（需报备）

**建议操作**：

- **最稳妥**：向劳动局申请"综合工时制"（适用于创业公司）
    - 好处：合法合规，周六不算加班
    - 坏处：需要报备，有点麻烦
- **折中方案**：用"打包薪资"（本方案采用）
    - 好处：简单，立即可用
    - 坏处：有一定仲裁风险
- **补充措施**：
    1. 在员工手册中明确"单休制度"
    2. 入职培训时口头说明并让员工签字确认
    3. 保留员工签字的《入职须知》

------

### 社保基数的合规说明

**问题**：按最低档3500交社保是否违法？

**答案**：不违法，但有争议

**法律规定**：

- 社保基数应按员工"实际工资"缴纳
- 但实践中，很多公司按"最低基数"交（特别是创业公司）

**合规边界**：

- ✅ **合法但有风险**：
    - 员工如果去社保局投诉，公司会被要求补缴
    - 补缴金额 = (实际工资 - 3500) × 社保比例 × 月数
- ✅ **低风险操作**：
    - 在合同中把"基本工资"设为3000元
    - 其他部分设为"绩效 + 补贴"（这部分不算社保基数）
    - 这样按3500交社保就有依据

**建议操作**：

1. **合同设计**：

    ```
    基本工资：3,000元（社保基数）
    岗位绩效：4,000元（不计入社保）
    综合补贴：3,000元（不计入社保）
    ```

2. **员工手册说明**：

    - 明确"社保按基础档缴纳"
    - 解释"到手工资更多"的逻辑

3. **协商机制**：

    - 如果员工强烈要求按全额交，可以协商"个人承担超出部分"
    - 或者给员工选择权：全额社保（扣更多）vs 基础社保（到手多）

**风险评估**：

| 风险等级 | 触发条件       | 后果                   |
| -------- | -------------- | ---------------------- |
| 低       | 员工不投诉     | 无影响                 |
| 中       | 员工离职后投诉 | 补缴社保（几千到几万） |
| 高       | 劳动局主动检查 | 补缴 + 罚款            |

**参谋建议**：

- 创业初期，按最低档交是常态，不必过度担心
- 但要做好心理准备：万一被投诉，就补缴
- 随着公司发展，逐步提高社保基数

## 💬 常见候选人异议及应对

### Q1：底薪8K太低，我之前拿10K

**A**： "8K是底薪，不是总包。你的总收入是：

- 底薪：8K（无责任）
- 过程绩效：2-4K（前2个月保护期，只要你勤奋+会运营就能拿满）
- 结果提成：上不封顶

前2个月，只要你做好运营（激活率20%、有效线索3-5条），就能拿到10-12K。

而且这10-12K里，2-4K是考核过程不考核结果，比你之前的纯业绩岗压力小多了。

你之前拿10K，是纯底薪，还是底薪+提成？如果是纯底薪，说明你做的是执行岗，没有上升空间；我们这里是操盘手岗，后期收入上不封顶。"

------

### Q2：过程绩效的指标太难达到

**A**： "我们设计这个指标时，特意咨询了有经验的运营。

招募30人，激活20%（6人），这是正常运营能力的体现。如果你连6个人都激活不了，说明你的培训和赋能有问题，那我们也不能长期合作。

而且我们提供：

- 完整的话术库（拿来就用）
- 素材库（每天更新）
- SOP流程（一步步教你）

你只需要执行就行，不是让你从0开始摸索。

如果你觉得难，说明你之前没做过真正的运营，可能不太适合这个岗位。但如果你愿意学，我们也愿意教，只是前2个月必须拿出结果来。"

------

### Q3：为什么不直接考核业绩？

**A**： "因为业绩有运气成分。

比如你运营得很好，合伙人也很活跃，但因为市场行情不好，客户暂时没需求，这不是你的问题。

我们不希望你因为运气不好而拿不到钱，所以我们考核你的'运营质量'：

- 合伙人有没有被你激活？（证明你培训到位）
- 有没有给你推真实线索？（证明你激励到位）

只要你做好这些，出单是迟早的事。我为你的'过程质量'买单。

而且过了保护期，你照样拿提成，那时候就是纯业绩导向了。保护期只是给你时间跑通模式，不是让你一直躺平。"

------

### Q4：单休太累，我之前都是双休

**A**： "我理解。但我跟你算笔账：

在长沙，双休的运营岗位，一般月薪6-8K。我们单休，给你8-12K，多出来的2-4K，其实就是买你周六的时间。

而且周六的工作强度比平时低，主要是：

- 复盘本周工作
- 规划下周任务
- 团队培训（比如教你用AI）

不是那种高压业务指标。

如果你看重的是'轻松养老'，我们确实不合适；但如果你看重的是'未来3年赚第一桶金'，那这点时间投入其实可以忽略不计。

你是想找个养老的地方，还是想找个打仗分钱的地方？"

**补充话术**（如候选人还犹豫）： "而且我们有调休机制：

- 如果周一到周五晚上加班很晚，可以周六上午不来
- 或者累积调休，攒够一天可以请假

我们不是要压榨你，是希望在创业攻坚期大家一起冲一把，等公司稳定了，福利体系自然会升级。"

------

### Q5：社保按最低档交，我不能接受

**A**： "我理解你的顾虑。但你算笔账：

如果按全额交（假设月薪10K）：

- 你个人扣：10K × 10.5% = 1,050元
- 到手：10K - 1,050 = 8,950元

如果按基础交（3,500）：

- 你个人扣：3,500 × 10.5% = 367元
- 到手：10K - 367 = 9,633元

差额：9,633 - 8,950 = 683元/月

也就是说，按基础交，你每个月到手多683元。一年多8,196元。

对于做业务的人来说，现金为王。你拿着这683元去理财、去生活，比存在社保账户里几十年后拿要实在。

而且等公司做大了，福利体系会升级。但现阶段，我们把预算放在了提成和奖金上，让你能赚到更多的现钱。

如果你真的很看重社保全额，可能我们目前阶段不太匹配。"

**筛选话术**（坚定版）： "坦白说，如果你死盯着几百块的社保差额不放，说明你追求的是'安稳'和'养老'，这反而帮我们筛掉了不适合创业的人。

我们要的是愿意用'少一点的死福利'去博'无限可能的渠道分润'的人。

你是哪种？"

------

### Q6：试用期3个月太长，能不能缩短？

**A**： "试用期合同写3个月，但我们是结果导向的。

如果你第1个月就把合伙人招进来了，或者激活率达标了，你可以申请当月提前转正，直接拿100%薪资加提成。

我不希望你拿试用期工资，我希望你尽快拿全额工资，因为那意味着你已经给公司创造价值了。

所以试用期多久，其实取决于你自己的能力。能力强，1个月转正；能力一般，3个月转正；能力不行，3个月结束就分手。"

------

### Q7：万一我干了2个月，指标没达标怎么办？

**A**： "我们会分两种情况：

**情况1：你很努力，但确实能力不够**

- 比如你每天都在群里发素材、培训合伙人，但激活率就是达不到20%
- 这种情况，我们会给你机会：
    - 延长保护期1个月
    - 或者降低指标（比如激活率15%）
    - 或者调整岗位（比如转后勤支持）

**情况2：你不努力，态度有问题**

- 比如SOP都没完成，群里也不活跃
- 这种情况，我们会直接分手

我们考核的是'过程质量'，不是'运气'。只要你努力了，我们不会亏待你。但如果你只是混日子，那我们也不会浪费彼此时间。"

**目标**：2个月保护期后，80%以上的人达标

**分析方向**：

- 如果达标率低于50%，说明指标设置过高，需要调整
- 如果未达标原因是"能力不够"，说明招聘筛选有问题
- 如果未达标原因是"不努力"，说明激励机制有问题

------

## 🔄 薪酬体系迭代计划

### 第一阶段（前3个月）：验证模型

**目标**：

- 招到1-2个合适的运营
- 验证"激活率20%"是否合理
- 验证"有效线索3-5条"是否合理

**调整方向**：

- 如果指标太难，适当降低（如激活率15%）
- 如果指标太容易，适当提高（如激活率30%）

### 第二阶段（3-6个月）：规模化

**目标**：

- 招到3-5个运营
- 建立标准化培训体系
- 固化考核标准

**优化方向**：

- 根据第一阶段数据，优化薪酬结构
- 增加"优秀运营奖"（如：激活率达40%，额外奖励5K）

### 第三阶段（6-12个月）：体系化

**目标**：

- 建立"运营-主管-总监"晋升体系
- 增加股权激励
- 升级福利体系（如：增加公积金、提高社保基数）

## ⚠️ 风险提示

### 法律风险

1. **劳动仲裁风险**：
    - 如果员工离职后投诉社保基数过低，可能被要求补缴
    - 应对：保留员工签字的《薪酬确认书》，证明员工知情同意
2. **加班费纠纷风险**：
    - 如果员工认为"综合补贴"不能算加班费，可能申请仲裁
    - 应对：合同条款尽量明确，并让员工单独签字确认
3. **过程绩效考核争议**：
    - 如果员工认为"激活率"考核不合理，可能拒绝接受
    - 应对：入职时详细说明考核标准，并让员工签字确认

### 管理风险

1. **考核执行不严**：
    - 如果面试官或管理者心软，不严格执行考核标准，会导致"劣币驱逐良币"
    - 应对：建立考核复核机制，所有绩效考核必须有证据（截图、录音、后端验证记录）
2. **指标设置不合理**：
    - 如果激活率20%设得过高或过低，会导致大量人员流失或公司成本过高
    - 应对：前3个月持续观察数据，及时调整
3. **话术执行变形**：
    - 如果面试官没有按照标准话术执行，可能导致候选人误解
    - 应对：定期培训面试官，统一话术口径

## 💡 参谋长总结

这套薪酬体系的精髓在于：

**用"确定性"的钱（过程绩效），去买他的"执行力"（激活合伙人）**
 **用"可能性"的钱（业务提成），去买他的"野心"（做大渠道）**

这样，候选人会觉得：

1. **保底不低**：只要我努力干活，就能拿到不错的收入（10-12K），不会因为运气不好而饿死
2. **上限很高**：未来还有大单提成等着我

公司会得到：

1. **活跃的渠道**：付费买的是"合伙人网络"，而非人头
2. **可控的成本**：固定成本8K，绩效成本2-4K，只有渠道活了才付费
3. **可持续增长**：运营做得越好，公司赚得越多，双赢

**这才是最健康的S2b2C启动逻辑。**
