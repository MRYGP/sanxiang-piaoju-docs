# 每日内容生成模板

**版本**：v1.0  
**创建日期**：2025-12-04  
**使用方式**：每天早上复制到Claude，生成当天内容  
**执行时间**：30-60分钟

---

## 📋 使用说明

### 如何使用这个模板？

**Step 1：每天早上打开Claude Projects**

**Step 2：复制下面的【每日指令模板】**

**Step 3：填写今天的信息**
- 今日主推业务（A-H中选一个）
- 目标人群（企业老板/财务/中介/合伙人）
- 今日故事/钩子（可选，有真实案例更好）

**Step 4：发送给Claude**

**Step 5：Claude会生成**
- 2-4条朋友圈文案
- 1-2个短视频脚本
- 配图建议

**Step 6：筛选+微调+发布**

---

## 📝 每日指令模板（复制这部分）

```
---【每日内容生成任务】---

早上好Claude！今天是 [2025-12-04 星期三]

**今日主推业务**：[A/B/C/D/E/F/G/H] 业务

**目标人群**：[企业老板/财务总监/会计/代账中介/想做合伙人的]

**今日故事/钩子**（可选）：
[如有真实案例，简单描述；如无，留空]

例如：
- "昨天帮一个贸易公司老板把贷款利率从12%降到6%，省了20万"
- "某制造企业通过票据贴现3小时到账100万，解决燃眉之急"
- 留空（Claude自己设计钩子）

---

**请生成**：

### 1. 朋友圈主文案（2-4条）

**要求**：
- 每条200-300字
- 必须包含：痛点 + 方案 + CTA（引导加微信回复【体检】或【合作】）
- 符合合规要求（不用"保证""确保""100%"等禁用词）
- 自然、不夸张
- 留有余地

**格式示例**：
```
【标题】[一句话钩子]

【正文】
[痛点描述]

[我们的方案]

[具体效果/案例]

[CTA行动号召]
```

---

### 2. 短视频脚本（1-2条）

**要求**：
- 60秒以内
- 口播为主，分镜简单
- 包含：开场钩子 + 痛点 + 方案 + CTA
- 配音稿 + 画面建议

**格式示例**：
```
【视频标题】[吸引眼球的标题]

【时长】45-60秒

【分镜】
- 0-10秒：[开场钩子，吸引注意]
- 10-30秒：[痛点+方案]
- 30-50秒：[案例/效果]
- 50-60秒：[CTA]

【配音稿】
[完整口播内容]

【画面建议】
[简单描述画面，如：办公室、表格数据、对比图等]
```

---

### 3. 配图建议

**要求**：
- 建议用什么风格的图片
- 可以用什么工具生成（Canva/美图秀秀/AI绘图）
- 色调和元素建议

---

**注意事项**：

1. **合规要求**（必须遵守）：
   - 到账时效：用"通常10分钟-2小时（以票种/额度/通道为准）"
   - 收益表述：用"示例：半年期银承约省0.2%-0.8%；具体以成交时为准"
   - 安全合规：用"基于银行承兑/合同化机制，合规边界内可控"
   - 禁用词：不用"保证""承诺""确保""100%""零风险""秒到"等

2. **内容风格**：
   - 真实、接地气
   - 不要太专业（让企业老板能看懂）
   - 多用案例，少讲理论
   - 留有余地，不说满话

3. **CTA设计**：
   - 主推：加微信回复【体检】（免费贷款体检）
   - 次选：加微信回复【合作】（合伙人招募）
   - 避免：直接推销业务

---

**参考文档**：
- `8个业务清单更新版.md` - 了解业务定义
- `展业话术大全.md` - 参考话术风格
- `贷款体检7连问完整版.md` - 体检服务说明

---

**期望输出**：
完整的当天内容包（朋友圈文案2-4条 + 视频脚本1-2条 + 配图建议）

开始生成！
```

## 💡 使用技巧

### 技巧1：结合"1主2辅"节奏

根据同事建议，每天的内容应该是：
- 1主业务（今天重点推的）
- 2辅助内容（贷款体检器 + 合伙人招募）

**示例执行**：
```
**今日主推业务**：A业务-票据贴现

**请生成**：
- 主内容：2条A业务朋友圈文案
- 辅助内容1：1条贷款体检器推广文案
- 辅助内容2：1条合伙人招募文案

总计4条，每天发2-4条。
```

---

### 技巧2：利用真实案例

如果昨天有成交或深度沟通：

```
**今日故事/钩子**：
昨天接待了一个做外贸的张总，他们公司贷款利率12%，每年光利息就要付120万。我们帮他做了个体检，发现他们有大量应付账款，用我们的凭证付款方式，利率能降到6%，一年省60万。张总当场就决定试试。

**今日主推业务**：B业务-凭证付款降成本

请基于这个真实案例，生成今天的内容。
```

---

### 技巧3：追问优化

如果Claude生成的内容不够满意，可以追问：

```
【优化请求】

Claude，刚才生成的第2条文案：
- 问题：钩子不够吸引人
- 优化方向：能不能用数字更具体一点？

请重新生成第2条文案。
```

---

### 技巧4：批量生成储备

如果某天特别忙，可以提前生成：

```
Claude，帮我生成"A业务-票据贴现"的10条朋友圈文案（储备版）。

要求：
- 角度多样化（痛点、案例、对比、FAQ等）
- 每条独立完整
- 我会根据实际情况选用

不用视频脚本，只要文案。
```

## 🎯 配合起盘方案v2.0

### Week 0-4：粗暴测试期

**内容策略**：
- 周一：主推A业务
- 周二：主推B业务
- 周三：主推C业务
- 周四：主推D业务
- 周五：主推E业务
- 周一：主推F业务
- 周二：主推G业务
- 周三：主推H业务
- 如此循环...

**目标**：
- 每个业务都露脸至少3次
- 收集每个业务的咨询数据
- 不追求完美，追求"发出去+记录"

---

### Week 5-8：聚焦期

**内容策略**：
- 主推1-2个业务（根据Week 0-4数据选出）
- 70%内容推主业务
- 20%内容推贷款体检器
- 10%内容推合伙人招募

**目标**：
- 深度打磨主业务文案
- 积累高转化文案模板
- 开始制作视频内容

---

### Week 9-12：中介模式期

**内容策略**：
- 标准化主业务文案（给中介用）
- 制作合伙人招募系列内容
- 开始做视频教程

**目标**：
- 打包"中介内容包"（10条文案+5个视频+素材库）
- 让中介能直接复制使用
