# 合规工具包

**用途**：对外内容发布前的合规检查工具集
**更新日期**：2025-11-25

---

## 一、禁用词库

**用途**：对外内容发布前，自动检查是否包含禁用词  
**使用方式**：AI工具在生成对外内容时，自动比对此词库  
**更新频率**：发现新的合规风险词时立即更新

### 🔴 一级禁用词（绝对禁止）

#### 承诺类
- 保证
- 承诺
- 确保
- 100%
- 零风险
- 绝对
- 必然
- 一定

#### 时效类
- 秒到
- 实时到账
- 立即到账
- 当天必到

#### 收益类
- 固定收益
- 稳定收益
- 保本
- 无风险套利

#### 违规类
- 内部秘密
- 私下结算
- 内部价
- 特殊通道

### 🟡 二级禁用词（需替换为条件表述）

#### 时效类
- "10分钟到账" → 替换为 "通常10分钟-2小时（以实际通道为准）"
- "快速到账" → 替换为 "通常当日到账（受银行处理时间影响）"

#### 收益类
- "年化X%" → 替换为 "示例：年化约X%（以实际成交为准）"
- "省X%" → 替换为 "通常可省约X%（受市场行情影响）"

#### 效果类
- "解决资金问题" → 替换为 "提供资金周转方案"
- "轻松融资" → 替换为 "简化融资流程"

### 🟢 三级词汇（需加脚注说明）

凡涉及具体数据、时间、收益的表述，必须加脚注：

```
*以上数据为示例值，实际结果受市场行情、票种、额度、通道等因素影响，具体以成交时为准。
```

示例：
- "示例：半年期银承约省0.2%-0.8%*"
- "通常10分钟-2小时到账*"

### 📋 检查流程

对外内容发布前，逐项检查：
1. [ ] 一级禁用词：有无绝对承诺表述？
2. [ ] 二级禁用词：时效/收益表述是否加条件限定？
3. [ ] 三级词汇：具体数据是否加脚注说明？
4. [ ] 整体语气：是否避免夸大和误导？

## 二、内容审核清单

**用途**：对外内容发布前的合规自查  
**使用方式**：逐项勾选，全部通过后方可发布  
**适用范围**：所有对外展示的文档、话术、宣传资料

### ✅ 审核清单

#### 第一部分：禁用词检查

- [ ] **承诺类禁用词**：无"保证"、"承诺"、"确保"等表述
- [ ] **时效类禁用词**：无"秒到"、"实时"、"立即"等绝对化表述
- [ ] **收益类禁用词**：无"固定收益"、"保本"、"稳定"等承诺
- [ ] **违规类禁用词**：无"私下"、"内部"、"特殊通道"等表述

#### 第二部分：条件限定检查

- [ ] **到账时效**：是否使用"通常...（以...为准）"的条件句式？
- [ ] **收益描述**：是否使用"示例：约...（以成交为准）"的条件句式？
- [ ] **效果表述**：是否避免绝对化，使用"通常"、"可能"等词？

#### 第三部分：脚注说明检查

- [ ] **具体数据**：所有具体数字是否加脚注说明？
- [ ] **时间承诺**：所有时间表述是否加免责条件？
- [ ] **效果描述**：所有效果声明是否说明影响因素？

#### 第四部分：安全合规检查

- [ ] **结算方式**：是否明确"公对公、合同+发票、凭证可追溯"？
- [ ] **合规边界**：是否说明"合规边界内可控"，而非"100%安全"？
- [ ] **风险提示**：是否包含必要的风险提示？

#### 第五部分：整体语气检查

- [ ] **客观性**：语气是否客观，避免夸大？
- [ ] **真实性**：内容是否基于真实业务，避免虚假宣传？
- [ ] **专业性**：表述是否专业，避免过度营销化？

### 🚫 发现问题怎么办？

如有任何一项未通过：
1. **立即暂停发布**
2. **修改不合规内容**（参考禁用词库和风险提示模板）
3. **重新走完审核清单**
4. **全部通过后再发布**

### 📝 审核记录模板

每次重要内容发布前，建议填写审核记录：

| 审核日期 | 内容标题 | 审核人 | 审核结果 | 修改说明 |
|---------|---------|-------|---------|---------|
| [日期] | [标题] | [姓名] | ✅通过 / ❌修改 | [说明] |

## 三、风险提示模板

**用途**：对外内容的标准化风险提示语  
**使用方式**：根据内容类型选择对应模板，直接使用或微调  
**更新频率**：监管政策变化时更新

### 📋 标准模板

#### 模板1：通用业务说明

```
*以上业务说明为一般性介绍，实际操作中受市场行情、票据类型、交易金额、银行通道等多种因素影响。具体业务细节、操作流程、费用标准、时间要求等，以实际签订的合同条款为准。
```

**适用场景**：业务介绍、服务说明、产品描述

#### 模板2：数据示例说明

```
*以上数据均为示例值，仅供参考。实际结果受市场利率、票据剩余期限、票面金额、银行政策等因素影响，可能高于或低于示例值。具体以成交时的实际情况为准。
```

**适用场景**：包含具体数字、收益率、时间等数据的内容

#### 模板3：时效说明

```
*到账时间为通常情况下的参考值，实际到账时间受银行系统处理速度、交易金额大小、账户状态等因素影响，可能提前或延后。如有紧急资金需求，建议提前规划时间余量。
```

**适用场景**：涉及到账时间、处理周期的内容

#### 模板4：合规边界说明

```
*本公司所有业务严格在金融监管合规边界内开展，依托正规银行承兑汇票体系和合法商业合同机制。客户资金安全受银行体系和合同法保护，但不排除因市场环境变化、政策调整、合作方违约等不可抗力因素导致的风险。
```

**适用场景**：安全性说明、合规性描述

#### 模板5：综合风险提示

```
【重要风险提示】
1. 本业务说明为一般性介绍，具体以合同为准
2. 示例数据仅供参考，实际结果以成交时为准
3. 时间表述为通常情况，可能因各种因素延迟
4. 业务在合规边界内开展，但不排除市场风险
5. 如有疑问，请咨询专业人士或联系我们详细了解

*三湘票据保留对本说明的解释权和修改权。
```

**适用场景**：重要文档、对外宣传材料的结尾

### 🎯 使用原则

1. **必须添加**：所有对外内容必须包含风险提示
2. **位置明显**：通常放在文档末尾或关键数据下方
3. **字号适当**：不能过小，确保用户可见
4. **不可删减**：不得因美观或篇幅删减风险提示
